# 研究配置与自选边界

在线初始化使用 GET /api/research-config，共享契约位于packages/contracts/src/modules/research-configuration.ts：

```json
{"runs":[{"id":"example_run","start":"2018-01-01","end":"2026-10-23"}],"variants":{"lecture_v3":"整段双买点 V3"}}
```

示例仅说明结构，不代表实际运行ID。日期保留给研究日期默认值及兼容消费者。响应不包含股票、交易日、行情、数据行数或图表SDK说明。后端读取并验证日志、清单和报告，不读取日线；实际分析消费时继续执行原有封存校验，不以轻量配置取代它。

完整GET /api/catalog保留给历史研究。前端切换至历史scope时才读取，并共享进行中的请求；失败不清空现有自选，也不采用过期切换响应。完整目录的其他旧消费者不受影响。

自选首屏只请求/api/watchlists，先本地预览、再服务器缓存、再权威数据。watchlist-bootstrap的数据与管理交互就绪不依赖任何研究接口。名称、分类、顺序属于自选；策略运行ID、策略版本和自动分析结果属于分析消费者。预览不授予编辑revision，保存仍由服务器确认控制。分析未就绪期间主动选择保留，配置出错不清空列表；图表和自动分析仍需要有效配置，不能把分析等待称作自选列表读取。

2026-10-24只完成实现、启动依赖编译与重启，未运行接口/浏览器/性能探针或测试套件。新增的首屏不请求研究接口回归源码待提交执行。待验证：配置返回契约、配置失败时自选管理、历史模式按需加载及快速切换、主动选择交接和实际耗时/响应大小。前端73460/3003，API71344/8010。
