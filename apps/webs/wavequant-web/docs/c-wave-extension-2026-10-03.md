# C 浪等浪满足后的 1.618 延伸目标

Owner：WaveQuant Web。适用范围：图表测幅观察、LONG 和 BUY 详情。最后验证日期：2026-10-03。

## 指标定义与图表类型

沿用同一波段的 A 起点、A 高点和 B 低点：

- A 幅度 = A 高 − A 起点。
- 原等浪目标 = B 低 + 1×A 幅度。
- 延伸目标 = B 低 + 1.618×A 幅度。

当前历史截面中第一次达到等浪目标后才显示延伸。确认当日只用收盘证明达到，后续交易日用最高价，包含等值触碰；四个浮点精度单位的容差只消除运算舍入。确认前的上影、未来行情、未知 B、原起点已失效或不一致的等浪价不能激活。A/B 确认日及买入确认日均参与最早可知时间。

延伸线和价格标签从达标日期开始显示，保留原 0.618 和 1 倍目标。原起点低价与收盘双破后终止新的突破观察；同棒既双破起点又达标时保守终止。已经在有效区间显示的历史目标保留，并记录有效截止日。目标使用现有虚线及边缘标签，远端延伸不扩大价格轴，定位保留缩放。

## 组件与范围

- `public/c-wave-extension.js`：共用纯测幅和激活判定。
- `public/wave-c-projection.js`：自动 ABC、手选 A 高及 A/B/C 证据注释的目标和生效说明。
- `public/annotations.js`：交易 LONG 和 BUY 详情复用同一判定。
- `public/charts.js`、`public/target-level-guides.js`：目标线、价格标签、有效区间和价格轴控制。

本次是 Web 图表目标观察；Core 策略版本仍为 v83，交易撮合和信号数据保持既有规则。
