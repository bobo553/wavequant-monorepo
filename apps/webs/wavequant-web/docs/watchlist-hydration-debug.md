# 自选股闪屏、重复选股与点击拖拽调试

## 实际根因

前端 stderr 中的浏览器转发日志记录：浏览器扩展在主题脚本之后插入 inspector script，React 原本期望下一个是 wavequant-watchlist-first-paint，因此出现 Hydration failed / tree will be regenerated on the client。服务端页面被丢弃重建，缓存预览先显示后消失。不是服务器再次读取自选股必然导致空白。

Chrome 中在主题脚本后插入无害的空注释脚本，旧版本复现同样的 hydration 错误。修复把主题、缓存首屏和开发版本轮询保留在一个稳定启动脚本中，不用新增 suppressHydrationWarning 掩盖问题，也没有禁用或删除用户的扩展。相同插入场景下，新版本控制台无 hydration 错误；帧采样显示109项列表始终保留，research-main未被替换。

正式列表在DocumentFragment中准备完成后一次替换，不先清空可见容器。Schema运行时移到React effect后的动态依赖；拓扑与全局弹层仅打开时加载。研究运行配置/api/catalog（不是全市场股票目录）在HTML启动阶段并行请求，运行时消费同一Response，不重复获取。

## 股票选择与拖拽
