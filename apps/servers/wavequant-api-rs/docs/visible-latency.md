## 两条提示的实际含义

旧的“正在运行策略并生成成交账本”来自 `StockBacktestTasks.start` 的固定默认提示，并不代表后端进入交易阶段。当前STRUCTURE_ONLY分支在趋势与独立行情快照完成后返回，跳过成交账本生成。新提示为“正在读取行情并计算趋势”；运行阶段优先使用后端真实progress_stage，不再把折线/一级进度伪装为二级、三级、B/S和账户全部运行。完成提示依据calculation_mode显示“当前股票趋势计算已完成”和未运行等级。

取数/分析是后端局部时钟，不等于等待视图的总时间。完成提示现增加后端总计；总计仍不包括浏览器请求发起前的界面工作、HTTP和前端绘图。

## Worker传输优化（本轮实现）

管道schema升为4，直接发送有界JSON并保留zlib压缩；移除一次性传输的去重节点表构建/展开。提交端只生成一次请求Value，直接规范化摘要并用于信封；接收端对信封中同一Value校验摘要后转换为类型，省去类型回转JSON。引擎/周期/请求摘要校验、队列字节上限、压缩帧上限、解压上限、取消、超时及容量降级保持。普通JSON在重复引用较多时展开更大，超过原有8MiB请求预算仍走既有容量处理，不放宽边界。持久化产物的indexed格式未改。

相同dataVersion的独立行情快照先走现有带摘要校验的读取，确认可读后复用，损坏/淘汰时同步重建；不能在快照可用前交付索引。结果缓存仍同步写入，没有引入无界后台任务。开发构建对serde_json、flate2、miniz_oxide启用优化，保留应用调试信息和溢出检查。Python、行情/复权公式、趋势和交易规则未修改。传输保值和展开字节上限回归源码已补充，遵循开发节奏未运行测试套件。
