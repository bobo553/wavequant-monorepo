## 不一致的原因及修复

1. **局部突破覆盖了整波关键位。** v31 使用每个局部严格突破证明重设六态背景，产生 Python 没有的较早资格。v32 只用它补齐缺少方向/关键位的初始背景，已有整波关键位继续冻结。
2. **数组快速路径漏了上级回执和开放正式端点的时钟。** 补上原生索引回执，受影响来源版本经同一个趋势核心收敛；普通结束时钟和正式严格端点时钟分别保留。这会改变趋势、六态及 N 的输入，不能声称只有区间展示变化。
3. **资格重开被 ABC 首 N 占用。** 一个首 N 仍有效，不代表它能确认关闭后的新窗口。独立资格候选要求 `max(攻击日, ABC可知日) > 上次结束日`；ABC 首 N 记忆不被关闭清空。首次确认后本轮攻击高点继续冻结。
4. **遗漏折叠 N。** 2024-09-06 对应的 N 是较大组合中的折叠 N。资格来源变化时发现并去重，首次核对结构后按当日 K 线索引推进；破位或超时淘汰。没有恢复每天枚举并重跑所有 N 历史的旧流程。
5. **量价规则误用了整波六态的配对。** 独立量价规则应沿用 Python `polyline_last_fall_pair`，按攻击前一腿判断回撤并冻结折线末跌高/低；整波六态的测幅起点不能替代它。这恢复了 2025-04-03 的确认。
6. **最终数组丢失历史修订时钟。** 共同趋势观察记录起点回接、突破旧边界及被替换的内部回撤点；直接下级正式端点证明提供首次发生日，不能使用之后的最后新高确认日。依赖该点的资格于首次修订日结束，2026-09-15 不再被延后至 2026-09-23 或无限延长。
