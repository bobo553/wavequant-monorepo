维护者：Rust 量化内核维护者。日期：2026-10-31。范围：各级共享 N 的候选替换时钟，正 N/倒 N 使用同一逻辑。

## 原因

已有冻结行情中，A 为 2026-09-01 高点 3995.175，B 为 09-02 低点 3932.252，原 C 为 09-03 高点 3968.112。09-04 最高 3980.202 抬高 C，同时最低 3915.221、收盘 3930.116 跌破 B 的低点和收盘。

## 修改

- `SingleNState::after_invalidation` 的新搜索时钟停在当前日之前，前一日 K 线由实际观察日获取。
- `PathState::advance` 归档失效候选后，当天继续消费新候选；仅使用 `known_index <= now` 的闭合来源点。
- 原候选与替代候选是不同 ABC 身份，同一个共享 N 在同一天仍只维护一次，不重复运行历史。
- 不能只看日线高低同时突破就推断任意盘中路径；C 必须由技术折线实际确认。已攻击 N 防守失效不复活，A/B 来源修订或起点失效不沿用锚点。
- 版本升至 43 隔离旧缓存；新增同日延伸与突破的双方向合成回归。没有按指数、股票、日期或级别设置特例，Python 业务代码未改。
