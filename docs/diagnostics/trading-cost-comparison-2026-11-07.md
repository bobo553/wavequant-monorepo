# 国芳集团交易开关离线性能对照

Owner：量化运行时；测量日期：2026-11-07。

## 方法与边界

用户明确授权真实运行对照。使用同一冻结 Rust debug 探针、同一引擎、同一份国芳集团行情、当前 Rust 默认 SystemConfig，仅切换 analyzer.mode。它是当前版本开关对照，不是历史提交前后对照，也不是原页面设置的精确复现。

行情来自已有离线文件，2018-01-02 至 2026-10-20，共 2132 日；与此前截至 11 月的 2145 日请求不同。已有分钟覆盖 41 日，其中 6 日通过生产 verify_minute_day 校验，35 日成交量不一致而排除，其余日期无分钟数据。两组最终输入完全相同，不补造分钟行情。配置、行情、被排除日期和理由均保存在冻结输入。

生产入口为 run_system_backtest，包含真实策略、模拟账户和进度快照生成；进度回调执行 JSON 编码。每次独立进程、无结构缓存，三次交错次序为 structure/trading、trading/structure、structure/trading。无预热，报告冷进程样本中位数及范围，不宣称尾延迟。单个探针上限 600 秒，只约束该探针。

run_seconds 包含生产函数返回前的计算及进度编码，不含输入文件读取/解析、最终结果 JSON 编码、文件写出、HTTP、取数、Worker 压缩管道和接收端图表投影。progress_encode_seconds 是 run_seconds 的子集，不能重复相加。结果字节为内部未压缩 JSON，不是浏览器实际传输量。Windows 峰值 RSS 返回 null，不能据此给内存结论。

原始证据：`.codex-runtime/trading-cost-20261107-valid/` 下 input.json、hashes.json、各样本 summary/progress/result/common 文件、wall.jsonl；汇总为 comparison.json，体积分解为 payload-breakdown.json。探针源码：`apps/servers/wavequant-quant-rs/examples/trading_cost_comparison.rs`。

最初输入转换遗漏分钟时区，导致全部分钟被拒绝；发现后停止该轮、修正转换并换全新目录。`.codex-runtime/trading-cost-20261107/` 是作废样本，不纳入统计。没有调整生产规则、清空生产缓存或重启业务服务。

## 已确认的行为差异

首个正式样本交易订单、成交、信号均为 0，交易诊断显示 trading_days_skipped=interval_skipped_days=2132。关闭区间买卖并没有消除其前面的逐日结构成本。

内部交易结果约 110.5 MB，其中 analysis 约 108.8 MB，levels 与 lastExecution 分别约 54.4 MB；账户约 0.278 MB。高层趋势点嵌套来源信息及历史事件庞大，并在最后执行结果中重复携带。字节大小不能直接当作该阶段 CPU 耗时。

关闭/开启交易的点数分别为：折线 1428/1428、一级 236/168、二级 16/14、三级 2/2。一级首个点记录差异位于第 49 个点；二三级还存在可知时钟差异。导出的二级资格区间为 7/0，共享 N 记录为 212/0。后两者必须区分导出缺失与内部状态差异，不能仅据空数组宣称交易路径从未计算过资格或 N。

调用路径已定位：structure 使用 run_polyline_arrays → advance_polyline_index / finish_level_array / finish_qualification_arrays；trading 使用逐日账户调度 → process_next → compute_structure / prepare_trading_day。后者每天附加历史确认，使用非数组结构和重复展开结果。两路径输出不等价，不能把耗时差解读为相同结构上纯账户撮合的成本；精确导致结构偏差的规则/时钟仍需另行定位，本次不修改。

## 结论及后续边界

已实测：零成交且交易日门控跳过的样本仍慢数百秒，主要时间不是实际下单成交；进度及最终编码也不足以解释差距。源码显示交易路径逐日重放确认、复制/展开嵌套结构，而结构模式走数组和索引输出。这些是下一步优先定位对象；没有函数级采样，不把某个函数宣称为已量得占比最高。

须先解决两条路径结构/资格消费一致性，再增量化历史确认、复用结构状态，并消除 levels/lastExecution 重复嵌套输出。账户应消费同一时点结构，不能用最终结构倒推历史交易。测量任务没有修改趋势、资格或买卖规则，也没有把测量完成当作性能修复完成。

执行命令：cargo +stable build --locked --offline -p wavequant-quant-rs --example trading_cost_comparison；.codex-runtime/run-trading-cost.ps1；python -X utf8 .codex-runtime/inspect-trading-cost.py；python -X utf8 .codex-runtime/summarize-trading-cost.py。Rust 执行全部分析与账户计算，Python 仅整理离线 JSON 报告，原 Python 业务代码未改。没有运行测试套件、浏览器、Git 检查或提交推送。首次读取报告遇 Windows 默认 GBK 解码错误，显式 UTF-8 后完成汇总，不涉及重新回测。
