# 国芳集团：复用行情校验后的性能与数据对照

核对日期：2026-10-27。归属：MONOREPO-362。责任模块：wavequant-quant-rs；生产 VO 和隔离缓存测量涉及 wavequant-api-rs。

同一份 2135 根日线，分析中位耗时 **170.2282 → 90.5433 ms**，减少 **79.6849 ms / 46.8%**，旧/新 **1.88 倍**。四级结构、六态时钟、N 记录、资格区间及前端 VO 全部逐字节一致。

## 修改内容与原因

优化前：TrendAnalyzer 入口已经验证整份行情，FoldedNs 每发现一个新候选，又调用 observe_n 校验从第一根至当前日的 OHLCV、股票和日期顺序。多个候选会反复遍历相同前缀。

优化后：ValidatedCandles 拥有已校验的原行情数组，只提供不可变切片；ValidatedBarSlice 将校验凭据绑定到该数组和借用期限。四级资格复用只读前缀，每个候选通过 observe_n_validated 缩小到当前日。没有全局跳过校验的标记，也没有复制行情或改变全局下标。追加行情只校验新增部分及旧尾部边界；历史修订须建立新的分析器并重新校验。

N 结构本来就从 A 点检查至 C 点，再检查 C 确认、攻击、防守和目标区间；本轮保留这些区间与所有判断规则。不能随意按一个更晚的当前趋势起点截断，否则可能遗漏 N 起点或确认前破位。外部 observe_n 接收原始数组时仍完整校验当前可见前缀，两种入口调用同一个业务核心。

来源收敛、资格重开、折叠 N 组合、共享首 N、量价/缺口/普通回撤、结束规则均不改；旧 Python 业务代码不改。
