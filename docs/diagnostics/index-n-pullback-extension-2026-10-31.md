## 通用修复

- `SingleNState::after_invalidation`：未攻击、A 未破且 A/B 来源未修订，保留两个索引，等待新的已确认 C；正 N/倒 N 对称。等待期间若 A 被触及或突破，清除锚点。每次只消费新增点，不反复扫描历史。
- 新 C 形成新的共享记录，旧候选失效记录仍保留；新 C 的可知时钟不得提前。
- 已攻击 N 破防守后仍失效重找，不借回撤延伸复活。
- 共享结构不执行买点质量过滤；资格和买点消费者保留原过滤条件。
- 算法版本升至 42，隔离旧分析缓存；折线和一至三级趋势判定本身未修改。
