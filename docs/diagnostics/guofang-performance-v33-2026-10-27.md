# 国芳集团 Rust v31 / v33 性能对照

核对日期：2026-10-27。维护者：量化内核与 API 维护者。范围：用户授权的国芳集团离线同输入测量。

本次回退已纳入[待解决事项：Rust 资格对齐后的性能回退](../pending-issues.md#rust-v31-v33-regression)，记录背景、原因的证据边界、后续定位方向及必须保留的正确性要求；本报告保留原始测量口径与数值。

纯分析中位耗时 **43.1350 → 139.1438 ms**，增加 **96.0088 ms / 222.6%**。新耗时为旧版 **3.23 倍**；旧/新为 0.3100。

## 对照条件

- 基线 f8a19fc / v31；最终 v33 为 v32 资格对齐加本轮发展端时钟修复。旧 Python 业务代码不变。
- sh.601086，2135 根日线，2018-01-02 至 2026-10-23，因果复权等价数据。四级结构全开，仅二级资格开启，买卖/账户停用。
- Rust 1.98.1，dev profile，quant/API opt-level=2，默认 features。Cargo.toml、Cargo.lock、toolchain、计时探针源码相同。
- 每版预热3次，交替采样9次；独立进程及隔离SQLite。保留全部慢样本，未选择性剔除。
- 输入 SHA256：22459b66408b0ac28470ddf91ad62ad664307448f73d996016deb24869fe4d06；有效配置 SHA256：4dd3bf3a2686c6f66ce97129d1f8a7bcbce89da310f93c3d9261d59631ee839c。

## 增量原因

1. 资格消费者补充独立重开候选和折叠N。FoldedNs 只在来源变化时发现组合，但每个新组合仍调用 observe_n；它会 validate_bars(bars[..=end]) 并扫描N结构/攻击范围。当前没有独立微计时，不能把全部二级资格耗时都算给其中某一循环。
2. 上级严格突破回执改变下级正式来源，finish_hierarchy_arrays 会重新计算受影响层级直至不再变化；普通/正式来源通道也分别处理。新结果点数和状态发生改变，并非完全相同工作量。
3. 下一步优化应优先减少新N初始化的重复历史校验及来源重算。本轮只统计并修复时钟，未改变资格规则。
