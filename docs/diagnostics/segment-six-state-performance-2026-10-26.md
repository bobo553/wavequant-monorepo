## 方法

- 修改前使用上一轮封存的 v27 最终 exe（after-v27-final.exe）；修改前源码另存 source-before/。修改后为当前 v28。没有切换、重置分支或修改旧 Python 业务源码。
- 两版探针源码相同，rustc/Cargo 1.98.1，stable/default dev、默认 features、两应用包 opt-level=2。每版预热一次、交替采样五次、每次独立进程和隔离空 SQLite 目录。最终采样在 Rust 与前端编译结束后执行。
- 四级结构、仅二级资格、lecture_causal、strict_n_attack_quality=false、volume_filter=false。保留既有正 N/倒 N 与资格规则，不执行账户、SDK、Redis 请求、HTTP 或浏览器。
- 输入 SHA256 `d32ccd9dab40e67dcd647eab585f436cbaba1d57d8979efaae807d1ae3d05fd7`；有效配置 SHA256 `4dd3bf3a2686c6f66ce97129d1f8a7bcbce89da310f93c3d9261d59631ee839c`。
- v27 引擎 `9dca694dd16a8ea8e7a48a22df41cd0f771d6d02829a6726c2c90894471287b9`；v28 引擎 `a81eb1aee5bdc3a43ef675a35530a7b97c1afa3f27ed808b426c59b745b2b2e6`。
- analysis_ms 含初始化、折线、一二三级、N/资格及索引输出；不含输入读取解析、RuleCandle 准备、前端投影、编码压缩、缓存读写或 Worker 管道。
- 原始输入、exe、编译日志及全部样本位于 .codex-runtime/perf-segment-state-v28/，不提交这些产物。
