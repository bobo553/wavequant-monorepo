# 交易资格路径性能定位（2026-10-25）

用户要求先跳过交易调用作对照，再要求趋势函数返回资格区间，买卖规则必须同时满足本级开关与本级有效资格。Python 未修改。

## 测量边界

海洋王 sz.002724，冻结行情2018-01-02至2026-10-23，共2133根。配对测量取相同前1000根，使用同一debug配置、单进程串行运行；不经过SDK、Redis、HTTP或前端。配置采用AnalyzerConfig默认值，仅二级买点开关为true，账户不开启。实际页面选择其他策略参数时，耗时与资格结果可能不同。

| --- | ---: |
| 原最终结构数组路径 | 0.0102 |
| 原逐日路径跳过交易调用 | 63.304 |
| 原逐日路径含资格与买卖规则 | 75.669 |

## 确认的热点

旧版来源指纹约49.981秒：每个交易日、每个级别都把点及递归证据打包为传输节点表，再序列化做哈希。它不是趋势比较大小本身，也不由趋势偏移量覆盖。新内存缓存键使用不可变点版本号，字段或证据写入即换版本；键不跨进程持久化，避免错误复用。配对后来源指纹合计约0.094秒。

旧资格与买卖消费者耦合，区间外仍准备N候选、证明和仲裁。现在趋势确认阶段单独生产区间；规则消费必须满足enableSecondaryReversal[level]且本级inQualificationRange。区间外只推进连续时钟、来源失效及持仓风险，不搜索买点。暂时跳过买卖调用的诊断开关保留，默认关闭隔离，服务正常使用门禁。

## 当前限制

完整2133根仍用97.599秒，其中逐日结构89.865秒，资格0.534秒，规则/状态维护3.360秒。剩余瓶颈是逐日前缀的结构确认、许可发布和生命周期处理；本次没有将它们全部改为增量，不能宣称已经秒级。

默认参数的这份样本未产生有效资格或买点。1000根启用/跳过规则的最终趋势坐标哈希一致，资格天数一致；此样本不能单独证明有效区间内候选规则正确，另用受控开闭区间场景验证。

## 2026-10-25 单股五阶段计时口径

本轮只补计时，不修改趋势和交易判定。`profile_trading full`的`analysis_seconds`从分析器初始化至逐日处理完成；输入文件读取/解析在计时之前。`output_seconds`单列最终结果物化及诊断坐标哈希，不混入分析。

五类：折线、一级、二级、三级、买卖。前四类汇总互斥的`stage{level}.*`：结构入口、来源变化重放、确认/失败突破、下级来源退出、生命周期、资格计算。买卖使用`daily.buy_rules`，包含候选规则和区间外必要状态/风控维护，不代表实际有成交。

`extra_seconds = analysis_seconds - 五类之和`，其中单列`overhead.promotion_dispatch`和`overhead.structure_comparison`；其余差额记为`unattributed_seconds`，不凭估计分摊。旧`level*`与`daily.structure_total`是嵌套诊断明细，不能与stage再次相加。此口径针对逐日full模式，array模式不是等价的历史资格分析。

“只有五类业务计算”不等于程序只允许五个函数：索引/缓存、结果装配、调度有必要成本；反复扫描历史证据等高占比附加成本需单独定位，不能仅按函数数量判断异常。

### 本轮实测
