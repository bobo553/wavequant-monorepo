# 模型数据、微调与交付专项规范

本文件用于训练/微调数据集、模型产物、推理服务、灰度发布和图像/音频等多模态能力。使用外部模型 API 时也要遵守其中的数据和媒体安全边界。

## 数据集与训练决策

- 先建立 Prompt/RAG/现有模型基线并定位误差；只有行为、格式、领域表达或成本需求无法通过更简单方案解决时才微调。
- 数据必须有来源、授权、许可证、用途、保留和删除记录；个人、未成年人、版权、商业秘密和生物特征数据单独评审。
- 训练、验证、测试按主体或时间正确隔离，执行去重和泄漏检查；不得从评测答案反向污染训练集。
- 样本记录生成/标注流程、质量、版本和过滤原因；合成数据需标明来源并检查模型自我强化偏差。
- 数据集、训练代码、基础模型、参数、随机种子、环境和产物建立可追踪 Lineage，使结果可复现或解释。

## 评测与产物

- 评测覆盖目标任务、边界、偏见、安全、隐私、拒答、鲁棒性、延迟、吞吐、显存/内存和单位成本。
- 与基线在同一数据和条件下比较，报告区间、分群和退化样本；平均分提升不能掩盖高风险能力下降。
- 模型产物保存格式、版本、摘要、来源、许可证、兼容运行时和安全扫描结果；加载未知序列化产物前隔离验证。
- 模型卡或等效记录说明适用/禁用场景、数据限制、评测、已知失败和人工兜底。

## 推理与发布

- 推理服务定义输入大小、并发、队列、批处理、超时、取消、资源和费用上限，防止长输入或突发请求耗尽容量。
- 模型预热、加载失败、GPU/CPU 降级、自动扩缩容和依赖限额进入容量与恢复设计；不能以无界排队维持表面可用。
- 新模型先离线评测，再影子/金丝雀，比较质量、错误、尾延迟、资源和成本；保留可快速回退的模型与 Prompt 版本。
- 记录版本、参数、延迟、用量、结果状态和安全分类，避免记录原始敏感输入/输出；监控数据漂移和性能退化。
- 微调改变行为而非可靠知识库；需要更新事实、权限或引用时仍使用受治理数据源和 RAG。

## 多模态与媒体安全

- 上传先校验文件签名、MIME、大小、像素/时长、页数和压缩炸弹风险；处理器在沙箱与资源上限中运行。
- 图片 Metadata、文档文字、字幕、语音转写和模型描述都可能携带恶意指令或敏感信息，进入模型前按不可信数据处理。
- 生成/编辑媒体确认素材授权、人物同意和用途；人脸、声纹、声音克隆、未成年人和合成冒充属于高风险能力，需额外限制和人工审核。
- 按产品和法规要求标识合成内容、保留来源/生成参数并支持投诉删除；不得暗示未经证实的真实事件或身份。
- 原始与派生媒体使用私有对象、签名短链、最小权限和明确保留期；删除要求需传播到缩略图、转写、Embedding 和缓存。
- 为音频/视频提供字幕或转写，为关键图片提供替代文本；模型失败时提供可访问的人工输入和修正路径。
