# 数据分析、可视化与实验专项规范

本文件用于分析查询、业务看板、指标解读、数据可视化和 A/B 实验。指标事实仍以受治理的数仓模型为准。

## 分析方法

- 分析前写明问题、决策、总体、时间范围、粒度、分母、过滤、对照和数据新鲜度；不能先跑查询再挑有利结论。
- 平均值需结合中位数、分位数、分布和样本量；总量变化要区分流量、结构和单体行为变化。
- 漏斗明确进入条件、步骤顺序、窗口和去重单位；留存明确 Cohort、起点、回访事件和观察完整性。
- 分群和切片应有业务假设并防止小样本误导；多次探索得到的相关性不能直接解释为因果。
- 报告同步记录数据缺口、口径变化、异常处理和结论适用边界，不隐去与预期不符的结果。

## 可视化与看板

- 图表按任务选择：比较用条形，趋势用折线，分布用直方/箱线，关系用散点；饼图仅用于少量互斥部分。
- 坐标轴、时间范围、单位、币种、样本量、口径版本、数据来源和最后更新时间必须可见。
- 柱状图默认从零开始；截断坐标、双轴、面积和 3D 效果只有不误导且必要时使用，并明确标注。
- 颜色具有语义且满足对比度，不只依靠红绿区分；状态同时使用文本、形状或图标，兼顾打印与色觉差异。
- Dashboard 围绕受众决策组织：核心指标、趋势、异常和下钻路径清晰；不把所有可用指标堆在同一屏。
- 空数据、延迟、部分失败和口径变更要显式展示，不能用零或上一批数据伪装正常。

## A/B 实验设计

- 实验开始前登记假设、目标人群、分流单位、主指标、护栏指标、最小可检测效果、样本量、持续时间和停止规则。
- 分组使用稳定哈希或受控随机，确保互斥、可复现和跨端一致；同一用户不能因刷新、重装或多设备频繁换组。
- 指标定义、数据清洗和排除规则在看结果前冻结；中途修改必须新建版本并记录影响。
- 检查 Sample Ratio Mismatch、曝光污染、数据缺失、机器人、并发实验干扰和新奇/学习效应。
- 未达到预定观察窗口不得因短期显著提前停止；多指标、多分组和反复查看需要控制多重检验与误报。
- 统计显著不等于业务重要，结论同时报告效应大小、区间、成本、护栏和适用人群。

## 发布与复盘

- 实验能力需要 Kill Switch、逐步放量和回滚；支付、权益、安全等高风险变化不能只依靠统计结果自动全量。
- 发布后持续观察长期效果、分群差异和护栏，识别回归均值、季节性和迁移成本。
- 实验记录保存配置、代码/Schema 版本、分流、实际曝光、查询和结论，使第三方能够复算。
- 无显著结果和失败实验同样归档，避免团队重复试验或只保留正向结论形成偏差。
