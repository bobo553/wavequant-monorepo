# A、B、C 波段规则

本规则按 MONOREPO-263 的用户确认执行，适用于全局波段识别、目标观察及已有 C 浪入场路径。价格以同一次回测的复权口径比较，不混合展示价和原始价。

| 项目         | 判定                                             | 后续处理                                                     |
| ------------ | ------------------------------------------------ | ------------------------------------------------------------ |
| 普通 A       | A 高点 ≥ 一饱，且 < 二吐                         | 继续识别 B 和后续 C；一饱相等算达到                          |
| 强势 A       | A 高点 ≥ 二吐                                    | 继续识别 B 和后续 C；二吐相等算达到                          |
| 未达一饱     | A 高点 < 一饱                                    | 不归入这两类合格 A                                           |
| A 仍有效     | 后续各 K 线最低价 ≥ 原 A 起点                    | 最低价相等仍有效                                             |
| A 失效       | 任一后续 K 线最低价严格 < 原 A 起点              | 当日失效优先；即使收盘收复也不复活，原组没有后续 C，等待新 A |
| B 跌破轧空低 | 最低价 < 内部正 N 的轧空防守位，但仍 ≥ 原 A 起点 | 强势 A、普通 A 都允许，继续跟踪回调和整理；不据此取消整个 A  |

A 的强弱使用归属的正式正 N 的一饱、二吐目标。整段 A 的起点、A 顶由已确认波段确定；内部正 N 的起点和突破棒单独保存。内部正 N 不替换整段 A 的起点，也不能覆盖已经失效的旧 A。

设整段 A 起点为 L、A 顶为 H，B 底为 B，则 A 幅度为 H − L，C 的测幅位置为 B + 0.618×A、B + 1×A、B + 1.618×A。普通 A 保留既有三档观察；强势 A 的 1.618 延伸仍须等浪达成后发布。测幅位置是条件目标，不表示必然到达或自动买入。

突破 A 顶前，已确认的更低 B 可以更新该段锚点。B 极值日期和 B 可知日期分别保留，目标在结构可知后生效。已确认 C 顶结束该段测幅；后来的新波段不会抹掉已完成历史段，也不会用其行情补达旧目标。

B 跌破轧空低后，回调整理可能拉长，系统保留首次破低日期并持续跟踪实际交易日：A 顶至 B 低为回调天数，B 低至结构确认或入场观察截面为整理天数，两者相加为完整过程。这里不新增固定等待天数或按比例延期；正式端点、抵抗突破、量能及原有入场条件仍负责确认时机。A 结构有效性与具体交易的防守、止损、持仓及执行资格分别判断。

新华传媒的已确认整段 A 为 2024-02-08 至 03-25；内部正 N 为 02-29 起点、03-05 突破。08-28 的 B 低在 09-03 可知：该 B 已跌破内部轧空低，但仍守住整段 A 起点，A 有效。A 顶至 B 低为 106 个交易日，B 低至确认为 4 个交易日，共 110 个交易日；后续 C 的目标按整段 A 幅度测算。

Core 与 Web 的分类边界共用测试夹具；最低价跌破、等价触及、旧 A 不复活、新 A 独立、真实行情锚点及历史前缀分别验证。策略版本为 V3 v92。浏览器端到端和完整单元套件另行验证。
