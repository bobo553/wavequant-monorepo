# A、B、C 波段规则

本规则按 MONOREPO-263 的用户确认执行，适用于全局波段识别、目标观察及已有 C 浪入场路径。价格以同一次回测的复权口径比较，不混合展示价和原始价。

| 项目         | 判定                                             | 后续处理                                                     |
| ------------ | ------------------------------------------------ | ------------------------------------------------------------ |
| 普通 A       | A 高点 ≥ 一饱，且 < 二吐                         | 继续识别 B 和后续 C；一饱相等算达到                          |
| 强势 A       | A 高点 ≥ 二吐                                    | 继续识别 B 和后续 C；二吐相等算达到                          |
| 未达一饱     | A 高点 < 一饱                                    | 不归入这两类合格 A                                           |
| A 仍有效     | 后续各 K 线最低价 ≥ 原 A 起点                    | 最低价相等仍有效                                             |
| A 失效       | 任一后续 K 线最低价严格 < 原 A 起点              | 当日失效优先；即使收盘收复也不复活，原组没有后续 C，等待新 A |
| B 跌破轧空低 | 最低价 < 内部正 N 的轧空防守位，但仍 ≥ 原 A 起点 | 强势 A、普通 A 都允许，继续跟踪回调和整理；不据此取消整个 A  |

A 的强弱使用归属的正式正 N 的一饱、二吐目标。整段 A 的起点、A 顶由已确认波段确定；内部正 N 的起点和突破棒单独保存。内部正 N 不替换整段 A 的起点，也不能覆盖已经失效的旧 A。

设整段 A 起点为 L、A 顶为 H，B 底为 B，则 A 幅度为 H − L，C 的测幅位置为 B + 0.618×A、B + 1×A、B + 1.618×A。普通 A 保留既有三档观察；强势 A 的 1.618 延伸仍须等浪达成后发布。测幅位置是条件目标，不表示必然到达或自动买入。

突破 A 顶前，已确认的更低 B 可以更新该段锚点。B 极值日期和 B 可知日期分别保留，目标在结构可知后生效。已确认 C 顶结束该段测幅；后来的新波段不会抹掉已完成历史段，也不会用其行情补达旧目标。

B 跌破轧空低后，回调整理可能拉长，系统保留首次破低日期并持续跟踪实际交易日：A 顶至 B 低为回调天数，B 低至结构确认或入场观察截面为整理天数，两者相加为完整过程。这里不新增固定等待天数或按比例延期；正式端点、抵抗突破、量能及原有入场条件仍负责确认时机。A 结构有效性与具体交易的防守、止损、持仓及执行资格分别判断。

新华传媒的已确认整段 A 为 2024-02-08 至 03-25；内部正 N 为 02-29 起点、03-05 突破。08-28 的 B 低在 09-03 可知：该 B 已跌破内部轧空低，但仍守住整段 A 起点，A 有效。A 顶至 B 低为 106 个交易日，B 低至确认为 4 个交易日，共 110 个交易日；后续 C 的目标按整段 A 幅度测算。

图表在当前历史截面已知的 ABC 范围内，悬停、点击 K 线、日期定位和端点选择共用同一组波段。点击或定位固定目标与端点，鼠标离开后仍保留；临时悬停结束后恢复固定焦点或已选成交。焦点先于理论数据加载时，加载完成后重新匹配；换数据清理旧焦点，关闭 ABC 隐藏该层，移窗移出固定日期清理范围焦点。显式选中标识和成交按各自来源保留，内部正 N 的一饱、二吐可以与父 ABC 的 C 目标同时出现。

目标标签使用独立显示位置，不修改原始 B 锚点、可知日期、首次触及日期或已归档状态。历史光标移动不会改变回测截面；尚未被该截面确认的 B、C 不会提前发布。新华这组 C 目标为 5.371010663884799、6.4621916579306、8.227505412695798 元，第三档依照强势 A 的等浪条件发布。

Core 与 Web 的分类边界共用测试夹具；最低价跌破、等价触及、旧 A 不复活、新 A 独立、真实行情锚点及历史前缀分别验证。上述分类规则于 V3 v92 引入，当前策略版本为 V3 v96。浏览器端到端和完整单元套件另行验证。

V3 v95 引入五顶后的低开长上影退出：有效正 N 在此前交易日已达到五顶或十满，当前开盘严格低于前收、收盘不高于开盘，且上影占正振幅至少 50% 时，按 100% 退出目标清空余仓。上影等于最高价减去开盘与收盘的较高值；50% 相等允许，开收相等的十字线也允许。不要求放量、先前减仓或收盘跌破前日开盘。目标当天才到位、尚未来到或已经失效时，不沿用该规则。日线统一收盘动作中整仓退出优先于减仓；分钟退出确认后阻止当日后续新买与加仓，确认前已发生的交易及费用保留，T+1 仍生效。同时触发既有全清时沿用原原因和对应证据。

V3 v96 在完整同源分钟数据上，使用截至已完成五分钟线的累计日内开高低收判定上述形态，下一根五分钟线开盘按当刻已观察到的交易权限模拟卖出，不借用当天尚未发生的日线高低。分钟线的时间戳表示结束时间，成交时间取下一棒实际开始时间；午间休市等间隔分别按交易时段处理，不能把下一棒结束时间当作开盘成交时间。缺少完整分钟时明确回退日线收盘检查。既有 `nonflat_limit_close_fill` 模型启用、来源证明当日曾在跌停价以上成交时，允许非一字跌停按原始收盘价、零滑点模拟卖出，并标明未验证跌停排队；该模拟不要求普通收盘可卖标志为真，关闭模型或一字跌停不采用该假设。T+1、当刻不可卖与流动性条件仍可造成递延。

分钟模型启用且判定时已观察到成交价高于跌停价时，下一根分钟开盘回到跌停价也允许按该开盘原价、零滑点模拟卖出，标记 `observed_nonflat_limit_intraday_sell_without_queue_verification`。该权限来自已完成分钟内实际观察到的打开，不来自最终日线长上影；日线回退使用 `nonflat_limit_close_sell_without_queue_verification` 单独标明收盘撮合假设。

国芳集团（sh.601086）2025-04-25 的展示价为开盘 17.12、最高 19.54、最低 17.12、收盘 17.12 元，同口径前收为 19.02 元；上影为 2.42 元，占全天振幅 100%，开收相等不排除这一类退出。真实历史重算选取 2024-08-30 正 N 在 2025-04-11 已达到的十满，4 月 25 日产生 100% 退出目标。该日曾在跌停价以上交易；缺少完整同源分钟时，启用上述非一字限价收盘模型按原始收盘 12.53 元模拟清仓，零滑点并保留未验证排队的假设。此日线回退结果没有真实盘中成交时刻。若退出递延，形态说明仍引用原判定数据；原始价不得与展示价或复权目标混合比较。
