# 一级趋势线

一级趋势线定义为：以原始高低折线为输入，提取已确认的正反转低点与负反转高点，按时间依次连接的波段实线；一段可以跨越多个原折线高低点。原始高低折线是基础层，不改名为一级趋势线。数据输出以 `trend_level: 1`、`name: 一级趋势线` 标识本层；命名不改变既有提取和确认规则。

本层基于 `lecture_drawing` 已输出的路径，不改变原折线、母子线规则或买卖策略。连续三个不等价点的几何转向只构成输入的小拐点，不自动成为实线端点。等价平台保留最早极值。原折线仍保留未解断点；一级层在断点两侧的波段端点都确认后，可以用期间真实、已确认的原折线极值正式衔接，且把衔接点提供给二级趋势。

## 波段聚合口径

用户给出的短期转向未指定数值幅度门槛；本实现采用高低点结构确认，不另加任意百分比或固定间隔抽点：

1. 原折线最近两高与两低同时抬升（HH + HL）建立向上方向；同时降低（LH + LL）建立向下方向。
2. 高低点不同向或相等时保持原方向，等待新证据；不能把一次小回档或反弹直接当作波段反转。
3. 上行过程追踪整段最高点，直到下行结构确认，才把这个最高点定为负反转 H；下行过程追踪最低点，直到上行结构确认，才定为正反转 L。
4. 下一段从前一个已选极值之后开始追踪，按 L → H → L 依次连实线。一条实线可跨过多个原折线高低点。没有足够初始结构时不凭空补起点；未确认尾端不画成已确认实线。
5. 每个端点保存确认它的两高两低及确认时间。小折线的方向转换与更高一级的“翻空为多／空多交替”分层计算，不能混为一次确认。

## 跨原折线路径的正式衔接

- 前后一级端点类型不同且价格方向成立时，直接组成一条连续趋势腿。
- 前后都是高点时，使用期间最低的已确认原折线低点组成 `H → L → H`；前后都是低点时镜像使用期间最高点。
- 类型不同但价格方向错误时，只能使用期间真实、已确认的两个交替极值补成四点结构；没有合法来源点就保持断开。
- `seed`、`developing` 和在右侧端点确认时仍不可知的点不能参与。相等极值保留较早点。
- 衔接极值的发生日期保持不变，但一级确认时间取两侧一级端点均已知的日期，防止把事后完成的跨段结构提前用于二级趋势。

该规则在 Python 领域层执行。Web 不再另外生成一级业务点，因此一级实线、一级末跌高、二级和三级趋势使用同一份正式数据。

## 绘制与时点

- 正反转低点 L → 负反转高点 H → 下一低点 L，按 `(index, ordinal)` 绘制连续实线。无端点圆圈；只在放大后显示 H/L 编号。编号按本路径内时间顺序，不借用图 008 的 H0/L0 特殊命名。
- 实线开启时底层虚线的路径、样式、子母编号保持不变。原 N 字实线独立保留。一级趋势线当前只用于“讲义绘图”口径。
- 每个反转保存实际位置 `time` 与转向可知时间 `available_at`；发展端点延伸不是已确认反转。同棒坐标沿用原折线，不能把同日高低合并。
- “已反转”仅指上述波段结构确认转向；母子单极值解释仍非次级日内真实路径，更不等于严格策略确认。实线端点画回极值发生位置，但其可知时间是后续确认日，不能据此提前交易。原封存交易、策略判定未更改。

## 关键价位与趋势

选定低点的末跌高是同路径左侧最近的负反转高点；选定高点的末升低是左侧最近的正反转低点。点击 H/L 后才画其关键位实线，从该点可知日开始，避免向历史提前画未知水平线。

末跌高水平虚线的突破终点按以下优先级确定：

1. 选定低点已经可知后，市场收盘价首次从关键位下方或等于关键位，严格穿越到关键位上方的 K 线；盘中最高价越线或收盘恰好等于关键位都不算收盘突破。
2. 如果图窗内没有上述收盘突破，但 Python 领域层后来确认了一个价格严格高于末跌高的同级 H，则该 H 是正式结构突破。H 的发生日作为虚线终点，只有其 `available_at` 不晚于图窗截止日时才允许显示，避免使用当时尚未确认的未来信息。
3. 两种证据同时存在时始终采用更直接的首次收盘突破，不让更晚确认的结构点覆盖它。

例如民生银行一级末跌高 `2026-06-15 H293 3.65` 之后，`2026-08-03` 收盘仍为 `3.65`，不构成收盘突破；但该日最终被确认成同级 `H294 3.67`，确认日为 `2026-08-11`。因此从 8 月 11 日起，虚线可以回画并结束在 8 月 3 日这根结构突破 K 线。

视窗摘要取当前窗口内最低反转 L、最高反转 H，并引用它们左侧同路径的最近反转（可能在屏幕左侧之外）。视窗包含断点时只总结最后一个可见路径，不拼接两段。视窗趋势要求窗口内每一组高／低同时严格抬升或降低；“最新局部”只比较最近两高、两低，二者分开显示。相等不算严格多头／空头。

## 转换观察

复用 `observe_structure` 的高低比较和 `retracement_evidence` 的十进制阈值。依据是已确认折线极值，不是原策略的收盘突破时间：

1. 已形成多／空结构后冻结当前极值及前一反转为参考位。原方向出现新极值时更新对应参考位，不随较小反弹／回档滚动替换。
2. 空头反弹后的低点不再创新低、反弹仍未越末跌高 → 底部疑虑；多头回档后的高点不创新高、回档仍守末升低 → 头部疑虑。
3. 之后确认的折线高点越末跌高 → 翻空为多／底部成形；低点破末升低 → 翻多为空／头部成形。触碰不算突破。
4. 随后的已确认反向波幅必须满足 `0 < 比例 < 0.67`，才显示空多／多空交替。恰好 67% 不通过；小于 33% 另记强弱分级。超过原趋势极值时取消尚在观察的转换。
5. “通常三波、abc 至少等浪”不从日线单段反弹推断为已完成 abc。转换观察附在选中反转点的详情，不新增满屏事件标签，不产生买卖指令。

测试分两层：图 008 已是波段图，仅验证关键位对应与转换观察，不强求其每个节点都对应一个原折线节点；另外用多小拐点的序列验证波段合并、混合状态保持、前缀稳定性和原输入不被修改。另覆盖 67% 边界、同棒投影、空状态及发展尾端稳定性。合成夹具只用于绘图测试，不混入回测。
