## 固定样本与口径

- 通达信本地数据，2018-01-01 至 2026-09-07，原费用场景。
- 固定此前已使用的 11 股票：上海机场、上汽集团、贵州茅台、恒瑞医药、长江电力、中国平安、招商银行、美的集团、格力电器、五粮液、海康威视。
- 每股独立账户；四组只改变两个幅度参数，其他信号、执行、成本、起止时间一致。
- 胜率按扣费后盈利的已平仓交易数 / 已平仓交易数统计。未平仓不计入胜率。

信号可能因为已有持仓或执行约束未形成新成交。上述合并胜率不是共享资金的组合收益，也不是全市场扫描匹配率。

## 能与不能得出的结论

第一类门槛提高后，信号从 3 个减少到 1 个，证明该选项实际改变候选资格。第二类两种上限在这 11 股上产生相同最终信号，并不说明参数无效；边界单元测试单独验证了 1/3 与 1/2 会得到不同判断。

只有 6—7 笔平仓，且股票为此前已见样本，不能据此选择“最佳参数”或证明策略有效。下一步效益研究需要预先固定未见股票/时间、滚动样本外测试，并同时关注净收益、回撤、费用和容量，不能只最大化胜率。

对每股早期截面、首个/最后 LONG 附近进行历史截断重跑，178 次前缀检查全部通过：追加未来行情不会改变这些已测试截面的过去信号。
