# N 形理论与代码契约

本页依据用户提供的正 N、倒 N、等浪和一饱二吐四张图，明确理论定义、图示解释与工程边界。实现位于 `wavequant/domain/market_structure/n_shape.py`，使用之前的 `price_action` 基础接口。它是形态与测幅模块，不是盈利策略。

## 1. 标准 N 的结构

为避免不同图中 a、b、c、d 重复命名，统一使用：

- A：第一段起点。
- B：第一段终点，也是所选前波颈线极值。
- C：反向调整的终点。
- K：完成实、虚双条件的攻击棒。
- X：一饱二吐另用的箱体锚点。

标准正 N 为 A 低、B 高、C 低且 `A<C<B`；倒 N 为 A 高、B 低、C 高且 `B<C<A`。本实现严格采用这类“推进后部分回撤”结构。C=A 的 W/M 边界、C 穿过 A 的变异形态不强行归入这个标准版本。

A、B、C 都有所在索引和确认索引，确认时间不得早于所在时间，并保持 A、B、C 及其确认顺序。默认从全部已确认之后的下一根判断完成。V3 倒 N 显式启用 `allow_confirmation_bar`：B 在此前已经确认，C 来源于更早一根 K 线，且当前收盘确认 C 时也首次满足双破条件，可于当前收盘确认倒 N；成交仍在下一可交易开盘。C 就在当前棒或 B 也到当前才确认时，不启用此分支。算法不会自动挑三个有利的拐点，不会用未来 ZigZag 补写早期信号。

调用方负责在统一周期和价格口径下识别拐点。代码会检查 A 的边界、B 是否为该段极值、C 是否为回撤段极值，但这些检查不等于一个完整的拐点识别算法。

## 2. 实过与虚过必须分别定义

图 003 下半图画了两个不同高度的参考。沿用前一轮基础定义，本模块采用以下明确解释：

| 条件        | 正 N                  | 倒 N                  |
| ----------- | --------------------- | --------------------- |
| 实过 / 实破 | K 收盘 > B 棒收盘参考 | K 收盘 < B 棒收盘参考 |
| 虚过 / 虚破 | K 最高 > B 棒最高参考 | K 最低 < B 棒最低参考 |
| 完成        | 同一根 K 同时满足两项 | 同一根 K 同时满足两项 |

**这是双锚点的图示量化解释。** 不把两种参考自动合并成“收盘必须超过旧最高”；也没有从整段另外搜索一个最高收盘来替换 B 棒收盘。如果以后指定了另一种颈线选法，应新建明确规则，而不是默默改变这两列。

例：B 收盘 11、最高 12；K 收盘 11.5、最高 12.2，满足两项。若 K 最高 12.2、收盘 10.8，仅虚过；下一根最高 11.8、收盘 11.5，仅实过。两根的部分证据不能拼成一根完成棒。等于阈值也不算越过。

算法取结构可用后的**首次同棒双条件攻击**。上根已同时在两个参考之外、当前继续保持，不能重复完成；拐点较晚确认时，也不能把更早的完成行为延迟重播。实现复用基础层的越过事件，并额外检查双条件是否刚出现。

## 3. 轧空低与杀多高

完成棒 K 的虚拟值：

```text
虚拟低 = min(K.low, 前一根.close)
虚拟高 = max(K.high, 前一根.close)
正 N 的轧空低 = K 的虚拟低
倒 N 的杀多高 = K 的虚拟高
```

这两个值在完成时冻结。例：前收 10.5，完成棒跳空后最低 12，则轧空低仍是 10.5，不能只取当天最低 12。

未完成时没有完成棒防守位。完成后另行记录首次严格越过防守位的时间；触及相等不算跌破/突破。新形成的防守位不追溯用于完成棒更早的高低。

防守位被破坏是后续盘态的重要输入，**不是这个基础模块发出的卖出指令，也不抹掉已发生的 N 字完成事件**。

## 4. 测幅公式和锚点

### 等浪：图 005

第一段涨幅与第二段测量幅度相等：`B-A=D-C`，所以：

```text
等浪目标 = C + B - A
```

例如 A=8、B=12、C=10，等浪目标为 14。不是 16。

### 一饱、二吐：图 006

图中给出 `d-c=c-b=b-a`。在这里将图中 b 改名为 X，以免与前图的波段颈线 B 混淆：

```text
箱体幅度 = X - A
1P = X + (X - A) = 2X - A
2T = 1P + (X - A) = 3X - 2A
```

图旁写“虚过的虚高 b”。本轮按“完成攻击棒的虚拟极值”解释，提供 `BoxAnchorMode.ATTACK_VIRTUAL_EXTREME`：正 N 的 X 为 K 虚拟高，倒 N 的 X 为 K 虚拟低。倒 N 是对应的对称数学扩展。

旧研究按颈线极值做箱体测幅，保留为 `NECKLINE_EXTREME` 显式替代口径。创建 `NSetup` 必须选择箱体口径，没有隐式默认值；两种解释不能在结果表里混为同一策略。

例：A=8、B=12、C=10，完成棒虚拟高 X=12.6：

| 目标 | 计算结果 |
| ---- | -------: |
| 等浪 |       14 |
| 1P   |     17.2 |
| 2T   |     21.8 |

显式改为 X=B=12 时，1P/2T 才分别是 16/20。所有目标在完成时冻结，不随之后创新高漂移。

## 5. 逐阶段观察

“潜在目标价”和“目标已达到”分别存储。完成时算出全部潜在价位，随后按顺序记录：等浪、1P、2T。每条记录包含目标、首次观测索引、时间和价位判断口径。

### 达到口径必须显式选择

- `MilestoneBasis.EXTREME`：完成之后的 K 线，正 N 看最高、倒 N 看最低是否达到目标。
- `MilestoneBasis.CLOSE`：看收盘是否达到目标。
- 达到包含相等，与突破的严格不等号区别开。

完成当根只使用**收盘**检查目标。原因是 N 到收盘才确认，整根最高/最低可能早于确认；不能拿那段未知先后的高低追溯认定“完成以后已达到目标”。

如果同一后续棒跨过多个目标，记录同一观测时间并标记 `shared_bar_with_previous`，不声称知道逐笔顺序，更不产生多次理想成交。跳空越过也只表示观测价位超出目标，不保证在目标价格成交。

`next_target` 告诉上层下一测量阶段。达到 2T 后，`measured_wave_complete=True` 表示本测幅流程完成，`stacking_precondition_observed=True` 表示讲义所述的叠箱前置测幅已观察到。

这两个字段不等于确定识别出艾略特某浪，也不授权下单。基础 N 观察器只处理等浪、一饱、二吐，因此这里的 `stacking_rule` 不自行定义五顶/十满。用户补充后的 V3 转浪策略在独立观察器中实现五顶/十满，按二吐、五顶满足日期逐步发布；公式、失效与显示规则见 [V3 策略说明](strategy_lecture_v3.md#二吐完成后的转浪目标)。

## 6. 结构变化和不确定路径

为了避免事后改写，采用以下显式工程约定：

| 情况                                | 输出                                                           |
| ----------------------------------- | -------------------------------------------------------------- |
| 尚未确认完整 A/B/C                  | await_anchors，不暴露未来锚点价格                              |
| 结构已知但双条件未完成              | forming，返回当前实/虚证据                                     |
| 完成前跌破正 N 的 A / 突破倒 N 的 A | origin_breached_before_completion                              |
| 完成前 C 被进一步延伸但 A 未失守    | pullback_extended_new_anchor_required，需确认新 C 并创建新结构 |
| 已完成                              | completed，并永久保留完成棒和防守位                            |

完成前继续延伸 C 时，不偷偷更新等浪目标。上下包 K 若既突破颈线又越过 C/A，没有分钟路径证明其顺序，本版本不把旧 C 继续当作标准结构完成。

完成后守不住防守位，只记录 `first_defense_breach_index`。如果进一步穿过 A，记录 `first_origin_breach_index`，停止给同一个结构添加新目标达到记录。该棒同时触及远方目标也不假设先触目标，采用暂停测量的保守工程约定。之前已经完成的历史测量不会被删掉。

更长未来数据不能改变历史完成棒、防守位和冻结目标。查询 `asof_index` 时，计算只读取此前缀。

## 7. 指标 N、均线 N 的复用范围

形态和测幅的数学关系可以复用，但不能把不同输入假装成同一种市场价格。

`project_n_targets` 有明确数值域：

- `ValueDomain.PRICE`：价格输入必须为正，倒 N 投射到零或负数的目标返回 None，并说明不可用。绝不据此预测底部。
- `ValueDomain.INDICATOR`：允许零和负值，可用于指标或均线的明确 A/B/C/X 值计算几何目标。

`observe_n` 当前只处理真实价格 OHLC。指标/均线通常只有一条数值线，没有交易 K 棒那样的“最高、最低、开收”；未定义采样与实虚条件前，不伪造 K 线来套完整状态流程。RSI 等有界指标的数学目标可能越界，不能解释为可达到的预测。

## 8. 调用与运行

```python
from wavequant.domain.market_structure.price_action import Direction
from wavequant.domain.market_structure.n_shape import (
    NSetup, PivotRef, BoxAnchorMode, MilestoneBasis, observe_n,
)

setup = NSetup(
    symbol="EXAMPLE", timeframe="1d", direction=Direction.UP,
    origin=PivotRef(index=0, confirmed_index=0),
    neckline=PivotRef(index=1, confirmed_index=1),
    pullback=PivotRef(index=2, confirmed_index=2),
    source="manually_identified_example_ABC",
    box_anchor_mode=BoxAnchorMode.ATTACK_VIRTUAL_EXTREME,
)
result = observe_n(
    bars, setup, timeframe="1d",
    milestone_basis=MilestoneBasis.EXTREME,
)
```

上例的确认索引只表示人工教学样例中何时已知，不能在实际自动拐点算法里一律填写成拐点当天。运行完整正倒 N 和分阶段例子：

```powershell
.venv\Scripts\python.exe -m examples.n_shape_theory
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

## 9. 与后续模块的边界

依赖方向是基础价格行为 `price_action`、本层 `n_shape`，再由盘态/量能/交易模块读取观测。N 的完成不要求成交量放大，不自动限制 1/2 或 2/3 回撤，不等待第三棒抵抗结果才算完成；那些属于后续独立条件。

本次未修改 `structure.py` 旧研究策略、历史协议或旧回测报告。旧 `foundations.n_break_evidence` 和 `measured_targets` 保留兼容接口，但它们不具备本模块的拐点确认、完成事件和分阶段时间跟踪。新开发应优先使用本层，而不是混用旧函数的输出名称。
