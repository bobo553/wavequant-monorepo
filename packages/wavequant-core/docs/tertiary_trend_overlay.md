# 三级趋势线

依赖顺序：原高低折线 → 一级趋势线 → 二级趋势线 → 三级趋势线。

三级线只使用已确认的二级点，复用二级线的结构突破算法；不重新从 K 线或一级线抽点，也不更改前三层的规则。

- 二级线最近两高、两低同时抬升／降低后建立初始多／空背景。
- 下跌段追踪最低二级低点及其左侧最近二级高点（末跌高）。后续二级高点严格突破末跌高，确认整段最低点为三级低点。
- 上涨段追踪最高二级高点及其左侧最近二级低点（末升低）。后续二级低点严格跌破末升低，确认整段最高点为三级高点。
- 依次连接三级 L → H → L，可跨多个二级拐点。没有新极值时不滚动替换关键位；触碰不等于突破，不额外等待 67% 交替条件。
- 输入断点分别处理。点太少时允许没有正式三级实线，不用较低级点补成正式三级反转。

## 完整发展路径

正式三级点确认后，新方向已经成立，但下一端点仍需等待反向二级关键位被严格突破才能成为正式三级反转。若只连接到第一个候选极值，较宽的三级关键位可能多年不破，之后已经确认的二级结构会全部从三级检查图上消失。Python 因此额外返回 `developing_strokes` 完整发展路径：

- 起点固定为最后一个正式三级点；只读取确认该点的二级突破证据及其后的正式二级点，不回到 K 线或一级数据另算三级结构。
- 正式三级点的新方向先保留对应二级候选极值；其后复用既有高低点同向/反向检查，串联已经完成确认的二级内部转折。最后一个内部转折之后仍未完成确认的尾部不再压缩，按顺序保留所有正式二级点，直到当前最新二级点。
- 每个点使用自己的 `available_at`，且不得早于正式三级起点的可知日。相等极值保留最早发生点，因此历史回放不会使用未来信息。
- 发展路径使用橙色虚线并标记 `display_only=true`、`state=developing`。内部转折只是三级尚未完成期间的二级演化证据，不写入正式 `strokes[].points` 或 `confirmed_wave_count`，也不参与更高级别、策略和回测。

上海电力中，`2007-05-30` 的三级 H1 12.97 后形成 `2008-11-06` 的三级 L2 2.68；`2015-06-02` 的已确认二级 H12 34.50 突破前述末跌高并在 `2015-07-15` 使三级低点可知。正式三级点仍截止于 L2；橙色虚线则从 L2 经 H12，继续串联 2018、2019、2020、2021、2022、2024、2025 年已确认的二级内部转折，再按顺序覆盖 `L25 → H26 → L26 → 2026-05-29 H27 22.35` 的待决尾部。

## 图表与可知时间

正式段使用橙色实线，完整发展路径使用橙色虚线；均无端点圆圈并受同一个三级图层开关控制。隐藏一、二级层只改变显示，不影响三级计算。点击正式三级端点查看被突破的**二级**关键位和确认突破的二级点；点击发展路径查看内部二级转折数量、当前候选点及“仅显示”边界。

接口 `tertiary_trends` 标识 `trend_level=3`、`source_level=2`。各点保存 `source_level2_position`、`confirmed_on_level2`、`source_level2_available_at`、`confirmed_by` 和 `broken_key`。

`time` 是极值发生日，`available_at` 是确认突破的二级点可知日，可能显著晚于极值日。历史回放逐级计算，不提前显示尚未确认的三级点；水平关键线从可知日开始。三级线仍为讲义可视化，不加入订单或回测信号。
