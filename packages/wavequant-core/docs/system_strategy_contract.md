# 主控理论量化系统：集成策略与回测协议

本文件保留 v1 历史规则。**当前默认入场已更新为 v2：翻空为多 → 空多交替 → 多头趋势 → 后续新 N 的轧空／强轧空**，见 `transitioned_squeeze_contract.md`。下文盘坚入场仅适用于旧版对照，执行与退出规则继续沿用。

版本 `integrated_v1_frozen_20260908`。代码 `integrated_strategy.py`、`system_research.py`，入口 `wavequant.interfaces.cli system-research`。本协议在集成回测前冻结，不对结果做参数择优。

## 1. 系统分层

| 层       | 消费的数据／理论                             | 输出与策略用途                                     |
| -------- | -------------------------------------------- | -------------------------------------------------- |
| 数据     | 通达信日线、除权事件、历史成交量、可交易标志 | 统一因果复权等价价格和份额；不自动补缺失交易日     |
| 折线     | 六基本术语、普通连接法、确认时间             | 严格段落内的确认高低点；或独立标注的日线拐点代理   |
| 波段结构 | 高低点、末升低／末跌高、局部与窗口趋势       | 已知支撑压力；末升低收盘跌破用于风险退出           |
| N 字     | 已知 A/B/C、实／虚双条件                     | 正倒 N 事件、轧空低／杀多高、等浪／1P／2T          |
| 攻击质量 | 主控 K、次笔抵抗、三分／六分力度             | 攻击相对量、回档比、防守失守、六态确认             |
| 特殊路径 | 洗盘后再次 N；盘势扭转与次级线               | 为合格 N 入场提供路径来源；不绕过基础确认          |
| 组合执行 | 资金、风险、流动性、整手、费用、T+1          | 下一开盘成交、止损／目标观察后下一开盘退出         |
| 研究验证 | 冻结历史分段、简单基准、消融、成本压力       | 交易、拒单、持仓、净值、覆盖率和门槛，不自动选赢家 |

不是“所有理论条件永远同时满足才交易”。N 延续是基础通道，洗盘和正扭转是特殊来源；负面信号优先做风险管理。缺少证据的理论分支保持未知，而不是补成 True。

## 2. 两种结构模式不可混报

### strict_full：固定主策略

普通棒严格遵守已定义的高低连接法；内包／外包若没有次级路径，当前段立即终止，发出风险退出观察。下一根棒建立新的独立段；不跨未解决的棒连接拐点或 N。

每段初始方向按首棒 C>=O 为 UP，否则 DOWN，作为明确的初始化种子；不宣称该首棒是确认反转。必须形成足够的确认高低点后才能识别 N。

因此日线存在频繁内外包时，覆盖率可能很低。这是实际输入限制和保守协议的代价，不能偷偷切换代理继续画“严格折线”。

### confirmed_fractal_proxy：单独的日线可行性对照

左右各 2 根棒均严格不超过候选高点／不低于候选低点，才在右侧第 2 根收盘确认局部极值。同一棒同时满足高低极值不纳入；相等不纳入。

连续同类点出现更极端者时，仅更新当前结构视图；以前的每日 tuple 快照、N setup、事件及信号不改写。它是一种有确认延迟的日线代理，不是讲义已经解决了母子线的证明。代理获得更多成交也不能据此宣称严格理论有效。

## 3. N 候选与信号时序

- 每次最近三个确认点变化时冻结一个 NSetup，标准 A/B/C 几何由既有 N 模块重新核验。
- 初始 A 距发现日不超过 120 根；候选的形成／六态观察最多延续发现日起 60 根，并不得越过严格段落边界。
- 相同方向、同一攻击棒只保留最早发现的有效候选，避免多个拐点版本重复计数。
- 观察器可以批量计算带时间戳的事件，但入场只读取截至当棒已知的事件、目标达到时间和防守状态。截断历史输入与全量输入的历史信号保持一致。
- C 当棒才确认，不允许把更早已经发生的越线倒灌成已知 ABC 之后的新 N；复用 N 原有规则。

## 4. 做多条件与三个来源通道

默认只有以下共同条件齐备才发 LONG：

1. 正 N 已完成，且本棒确认强轧空、轧空或盘坚中的一种；当前段完整。
2. N 的 B→C 回档占 A→B 幅度严格小于 2/3。原文模糊分级不影响这个明确数值过滤。
3. N 攻击棒成交量至少为此前 20 棒均量的 1.2 倍，历史不足则不合格。攻击棒不放进均量分母。
4. 有未失守的结构止损，且存在尚未被观察触及、仍高于当前收盘的等浪／1P／2T 目标。
5. 本棒没有退出事件。同一 N 只发一次 LONG；若次日拒单，不追价重发同一事件。

来源命名优先级：

- `washout_reattack`：此前同段、同方向初始 N 的严格洗盘路径已经由本次新 N 完成；再等待本次 N 的六态确认。配对只回看 120 棒内的历史事件。
- `positive_turn_then_n`：有次级线证据的正扭转先确认，60 棒内形成此新 N，仍满足共同条件。
- `n_continuation`：普通 N 延续。

这些来源是分类，不作为互相竞争的事后参数选择，也不同时加仓三次。洗盘配对不产生独立于新 N 的提前买点。

当前通达信导入只有日线，未提供次级结构；正扭转确认分支因此不交易。程序可在 `generate_system_signals(..., minor_points=...)` 接收调用方提供、明确映射到同一棒索引轴的次级点。没有提供时，仅记录符合背景及幅度的疑虑／待线状态。

## 5. 风险与退出

当棒任一条件触发 EXIT，优先于当棒所有 LONG：

- 倒 N 完成：下跌攻击风险，而非直接开空仓。
- 跌破在前一棒已经可知的末升低，使用收盘越线。
- 有真实次级确认的负扭转。
- 严格模式遇未解决的内外包，当前结构不可继续确认。

此外持仓引擎负责以下风险：

- 强轧空／轧空入场：用冻结轧空低为止损。
- 盘坚已经失去原攻击防守：用仍守住的 N 波段起点，不虚构一个更近的止损以放大仓位。
- 选择尚未触及的**第一个**等浪／1P／2T 目标，不为了通过盈亏比跳过较近目标去挑最远目标。达到时间只按截至当前已观察的极值，首次 N 完成棒仅看收盘。
- 新合格 LONG 出现且已经持仓时，不重复买入；复用原引擎，只能将止损向更有利方向提高，原持仓目标不自动更换。
- 最大持有 40 根；期末不强制卖出。

退出止损、止盈均是观察日 OHLC 后生成下一开盘退出请求，不模拟盘中止损价精准成交。止损和目标同棒触及，止损优先；跳空、跌停、容量约束可能导致更大损失或延迟退出。

## 6. 组合与成交参数

初始资金 100 万；最多 5 股；单股权重最多 20%；单次结构风险预算 0.5%；买入量还受现金与此前均量 1% 的容量限制。按复权等价份额换算实际 100 股整手，仍是近似现金／股份记账。

信号收盘才知道，最早下一开盘执行；开盘上跳超过信号参考价 5% 拒单；挂单存活一日；止损侧开盘或目标已耗尽拒单。在实际滑点后开盘价、实际整手数量和双边费用下，重新要求净收益／风险至少 1.5。

每边佣金 3bp、滑点 5bp，最低佣金 5 元，加原引擎历史税费假设。T+1、当日可交易标志和共享现金继续生效。成本压力将佣金、最低佣金、滑点翻倍，法定税率不随压力参数翻倍。

这些是事前固定的研究参数，不是已经找到的最优值或券商真实报价。未模拟竞价排队、全部历史 ST／退市、红利税、配股现金或停牌复牌风险。

## 7. 固定实验与评价

协议 `configs/system_protocol.json` 在本次回测前冻结，固定主策略 strict_full，不从代理、消融中选择赢家。

- 训练描述期：2018—2021。
- 验证描述期：2022—2023。
- 历史诊断期：2024—2026-09-07。
- 四组：严格完整、代理完整、代理关闭量能过滤、代理关闭六态确认。
- 基准：同执行约束的简单突破、同股票篮子的无费用等权持有。
- 各组额外跑诊断期两倍成本；严格与代理完整组另做每年空仓重置的年度诊断。

每段均独立起始资金与空仓，不携带段外挂单；指标和结构保留过去热身。不是一条跨分段持仓连续净值，应分别解读。

预设研究门槛：训练至少 20 笔平仓、验证正收益、诊断正收益且至少 20 笔、Sharpe>=0.5、最大回撤<=20%、成本压力后正收益。没有成交或没有 Sharpe 不能视为通过。

这些数据之前已经用于研究，没有新的真正样本外锁箱；所谓训练／验证日期不改变这一事实。无多重检验校正，不将参数未改当成统计显著性证明。无论哪组收益高，均不自动认定可实盘。

## 9. “完整”的范围

本次完成的是从可用数据到定义、信号、执行、诊断报告的闭环。不是所有理论分支在当前日线数据上都有证据：真实次级线、内外包日内顺序、主力意图、70% 断言仍不具备。系统把这些缺口显式关掉或记录，不用未来信息补齐。
