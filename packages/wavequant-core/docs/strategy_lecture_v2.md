# 分级双买点 V2

旧规则对照文档。当前默认版本为 [V3 整段幅度双买点](strategy_lecture_v3.md)，以下 V2 定义保留，不代表当前默认门槛。

更新时间：2026-09-09。策略 ID：`lecture_v2`，执行策略：`hierarchical_two_buy_points`。

本次只修改买点规则与展示，不重画原折线或一、二、三级趋势线，不覆盖 V1 和旧封存实验。
“大于等于一级趋势线”按现有 1 / 2 / 3 级实现，任一级满足即可，不要求三级同时满足。
未明确指定的“回撤小”，暂按前文弱势回档定义为 **严格小于 1/3**，参数为 `mature_shallow_ratio`。

## 两类买点

| 项目     | 第一类：交替后正 N 轧空                | 第二类：成熟多头浅回撤后正 N 轧空（重点）             |
| -------- | -------------------------------------- | ----------------------------------------------------- |
| 趋势来源 | 一级及以上，至少一个级别成立           | 一级及以上，至少一个级别成立                          |
| 前提     | 翻空为多 → 空多交替已知                | 翻空为多 → 空多交替已知 → 后续收盘再超过冻结翻多高点  |
| 回档要求 | 不使用 1/3、2/3 比例过滤               | 成熟之后形成新上涨段及回撤，回撤 / 该上涨段幅度 < 1/3 |
| N 与盘态 | 交替确认后的新正 N 完成 → 轧空或强轧空 | 浅回撤后的新正 N 完成 → 轧空或强轧空                  |
| 信号标识 | `system_transition_squeeze`            | `system_mature_shallow_squeeze`                       |
| 优先级   | 普通                                   | 同股票同日候选优先，同日筛选结果优先展示              |

第二类优先不是收益承诺，也不增加仓位或单笔风险预算。不同股票目前仍为独立回测账户，不能把列表排序当成共享资金的组合分配。

## 无歧义定义

1. 高级别反转点必须来自原绘图递推器的已确认点。一级使用原 HH/HL 与 LH/LL 方向转换；二级依赖一级关键位突破；三级依赖二级。界面为了连续而补的显示连线不进入策略。
2. 某级别已形成空头结构，冻结该下跌段低点之前最近的高点为末跌高。随后该级别已确认高点严格超过末跌高，记为翻空为多。
3. 冻结翻多这段上涨的起点和高点；接着确认的回档低点高于起涨低点、低于翻多高点，记为 V2 空多交替。**这里取消旧 2/3 幅度门槛**。跌回起点不是有效交替；这是结构定义，不是另设一个浅回撤过滤器。
4. “完整多头”不能回填到历史最高点：空多交替已知之后的后续日收盘，必须再次高于冻结翻多高点，才登记成熟日期。使用收盘再确认，不要求前一日一定收在高点以下。
5. 第二类幅度取新正 N 的 A→B 上涨和 B→C 回撤：`r=(B-C)/(B-A)`。A 不早于该级别交替低点，B 不早于成熟日期，C 在 B 与成熟日期之后；`0 <= r < 1/3`。这里不是从任意更远低点取幅度来把回撤比例做小。
6. 正 N 继续使用既有日线讲义因果拐点和实过+虚过定义，不把同一根 K 棒的三个日内点拼成日线 N。攻击必须晚于交替的可知日，盘态确认晚于攻击。
7. 分级趋势必须在攻击时已经具备资格，在实际信号日仍属于同一有效结构。成熟之后，同一级不能退回第一类免幅度过滤。成熟当根是阶段边界；从下一根起，之前的早期 N 即使后来才恢复轧空，也不能继续走第一类，须等待新的成熟后浅回撤 N。
8. 结构防守仍有效：全幅回撤至翻多起点，或收盘跌破交替低点，撤销原许可；已确认反向关键位突破、结构路径重置也撤销。后续新结构重新建立资格。

## 没有取消的条件

- 盘态只能为轧空 / 强轧空。原“守住轧空低后压回恢复”观察保留，但仍受两类买点时序约束，不会自动放行。
- 攻击棒相对量 ≥ 1.2（若开启既有量能过滤）。
- 收盘参考盈亏比 ≥ 1.5；使用最近尚未达到的结构目标，不跳过较近目标抬高盈亏比。
- 次可交易开盘重新检查含费盈亏比、跳空、流动性、现金、一手数量、仓位与风险预算。
- 只做多，原倒 N、末升低跌破、结构未解、止损/目标观察、持仓期限等退出规则保持原样。
- 行情、信号、成交仍统一为因果复权等价价格；原始价格与复权因子留在账本中。

## 界面与证据

刷新页面，在“通达信 · 当前股票回测”选择默认的 **分级双买点 V2**，运行回测。
点买入信号或 B 标识，可查看买点类型、级别、翻多高价、交替日期、成熟日期、回撤幅度与 N 攻击日期。
“符合买点”列表保留历史/当日、成交/拒单/待次开盘的区别，第二类标记“重点”，同日优先展示。
第一类账本回档比例显示为“仅展示／未启用”，不会再显示旧 `<2/3` 检查失败。
原图形的旧理论注释保持原版本含义；V2 入场判断以分级事件和信号证据为准。
兼容参数 `max_counter_ratio` 保留给旧策略，不参与 V2 的第一类或第二类过滤；第二类只读 `mature_shallow_ratio`。
