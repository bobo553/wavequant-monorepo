# 主控 K 棒、轧空低／杀多高与波段洗盘

实现为两个独立观察模块：`wavequant/control_bar.py`、`wavequant/washout.py`。依据本次用户提供的正文、图 009，以及已建立的突破、N 字、六态和折线结构契约。本层不改动原有回测策略或历史报告。

## 1. 先区分价格事实与讲义解释

| 可以从输入数据计算                           | 不能仅凭 OHLCV 证明                          |
| -------------------------------------------- | -------------------------------------------- |
| 正／倒 N 何时完成，攻击棒的虚拟高低点        | 某位主力真实进货／出货成本                   |
| 攻击棒是否较前棒或过去均量放量               | 拉高进货、拉高出货、压低进货或出货的真实意图 |
| 次笔是否出现列举的抵抗形态，防守位何时被越过 | 价格变化由主力洗盘、诱空或特定空头平仓造成   |
| 1P／2T 目标区、后续回档区及独立新 N 的顺序   | “70% 在目标区出货”的真实概率或策略胜率       |

主控、洗盘、杀多诱空等名称在这里是**理论命名和价格模板标签**。返回 `participant_intent/intent=unknown`、成本不可识别、概率未知；不将原文 70% 写成统计结果。

## 2. 轧空低、杀多高和主控 K 棒

本接口的主控 K 棒限定为已经通过 `n_shape.observe_n` 的 N 完成棒，而非随意选一个大阳／大阴棒或滚动新高／新低。

| 方向 | 完成条件来自既有 N 层 | 冻结防守位                       |
| ---- | --------------------- | -------------------------------- |
| 正 N | 同棒实过＋虚过        | 轧空低 D = min(完成棒 L，前棒 C) |
| 倒 N | 同棒实破＋虚破        | 杀多高 D = max(完成棒 H，前棒 C) |

`ControlBarObservation.completion` 直接返回已有 `NCompletion`，不再维护第二套虚拟价算法。两个虚拟价都保留在完成证据中；对应方向的防守价另转成通用 `KeyLevel`，正 N 是支撑、倒 N 是压力。源棒与确认棒均为 N 完成当棒。

虚拟价是单个结构参考点。讲义称其“成本区”，但并没有区间宽度或真实成交筹码，代码不虚构一个成本范围，也不等同于成交量加权成本。

## 3. 量增只是证据，不是 N 的必要条件

`observe_control_bar(..., volume_lookback=k, shadow_policy=...)` 中，k 必须显式给出：

- `increased_from_previous`：攻击量 > 前棒量，严格比较。
- `trailing_mean`：攻击棒之前 k 根的平均量，不包含攻击棒。
- `relative_volume`：攻击量／过去均量。
- `increased_from_mean`：攻击量 > 过去均量。
- 历史不足 k 根：均量、相对量及均量比较未知，不用不足样本悄悄替代。
- 均量为零：相对量未知，不返回无穷大。

“大都是量增”没有给定阈值或统计样本；不擅自设置 1.5 倍等筛选门槛，也不因未放量而取消已经完成的 N。上下棒的量必须采用一致单位；拆并股、份额变动等量口径问题要由数据层处理。本次仅增加攻击量证据，并未代替后续完整量能体系。

## 4. 防守位的观察与六态关系

完成棒之后，逐棒返回 `DefenseFrame`：

- `intrabar_beyond`：正向 L < 轧空低；反向 H > 杀多高。
- `close_beyond`：正向 C < 轧空低；反向 C > 杀多高。
- 盘中、收盘首次失守的索引分别记录，相等仅为触及。
- `recovered_on_close`：此前已有收盘失守，前棒仍在失守侧，本棒收回防守位或更强一侧。
- 以后收回不会删除此前的首次失守事实。完成棒不拿来判断自己的新防守失守。

次笔抵抗直接消费 `price_action.observe_resistance`，没有影线阈值时保留未知；不能把“未知”说成完全没有抵抗。

原文描述的是后续盘态的**可能路径**，不是 D 被越过就立即硬分类：

- 正 N 的 D 跌破后，守住更大波段边界且后来再上攻，才可能符合已有六态口径的盘坚。
- 若要判为追杀／盘跌等空方盘态，还必须有相应倒 N 和后续六态证据。
- 倒 N 的 D 被突破同理，不自动等于多头趋势成立、强轧空或进货完成。

新一轮攻击必须建立自己的 N 防守位，旧 D 不会随着新棒被悄悄替换。折线正负反转、末跌高末升低突破、头底疑虑、六态仍分别保留自己的层级和确认规则。

## 5. 图 009 的价位与显式解释

图 009 的 A 是**原颈线**，B 是 1P，C 是 2T；不要与 N 几何 A／B／C 拐点混淆。

本模板冻结：

- 原颈线 A：首次 N 的 `anchors.neckline_extreme`。
- 1P、2T：首次 N 的 `targets.one_p/two_t`。
- 波段根本边界：首次 N 的起点 `anchors.origin`。

1P／2T 不重新发明公式：继续使用首次 `NSetup.box_anchor_mode` 指定的箱体锚点。完成棒虚拟极值与旧颈线箱体两种解释已有独立定义；不要为了套图 009 在事件中途换箱体锚点。

下行镜像的数值排列为 `2T < 1P < 原颈线`。若反向投射出现非正价格目标，本模板返回 `UNAVAILABLE`，不把负价格当成必达目标。

## 6. 波段洗盘的严格价格模板

规则版本 `figure009_strict_open_bands_separate_bars_v1`，这是图示的一种保守、可复核解释，不声称穷尽所有主观“洗盘”。

| 阶段       | 底部洗盘价格路径         | 头部洗盘镜像             |
| ---------- | ------------------------ | ------------------------ |
| 首次攻击   | 正 N 完成                | 倒 N 完成                |
| 目标区     | 1P < 观察价 < 2T         | 2T < 观察价 < 1P         |
| 后续反向区 | 原颈线 < 回档观察价 < 1P | 1P < 反弹观察价 < 原颈线 |
| 再次攻击   | 独立新正 N 完成          | 独立新倒 N 完成          |
| 返回结果   | 底部洗盘价格模板完成     | 头部洗盘价格模板完成     |

目标区和反向区是开区间，采用“之上／以下”的严格口径。等于 1P 不算进入其上方目标区；等于原颈线不算进入反向区内部，但触及颈线仍算未失守。

`WashoutPolicy.zone_basis` 必须选择：

- `CLOSE`：目标与反向区均看收盘价。
- `EXTREME`：目标区看同向极值（上涨看 H、下跌看 L），反向区看反向极值（上涨后的回调看 L，下跌后的反弹看 H）。
- 首次 N 完成棒一律只用收盘观察：其早先高低可能发生在 N 成立之前。

目标区到达与回档／反弹必须位于不同棒；进入反向区与新的 N 完成也必须满足后续确认时序。日线范围同时覆盖两个区，不会被算成依次走完两个阶段。跳空越过整个区间也不等同于确认曾在区内交易。

## 7. 严格模板的退出和歧义

模板尚未完成时，按以下顺序判断：

1. 首次 N 的原始起点边界被不利极值越过：`INVALIDATED`。
2. 同向极值达到或越过 2T：`OUTSIDE_TEMPLATE`。本版本只研究图示的“1P 以上、2T 以下”再回档路径，不将更大幅度走势事后塞回模板。
3. 目标区观察后的后续棒失守原颈线：`OUTSIDE_TEMPLATE`，即使还没有打破整个原始波段。
4. 同棒既到目标区又失守原颈线，无法分辨先后：退出严格模板，标注顺序未知。
5. 再攻击棒同时失守上述边界：先处理退出／失效，不宣告洗盘完成。

除首次完成棒外，退出边界总用极值，不因选择收盘进区而忽略盘中的结构破位。先完成 N 才能定义出的价位，不追溯用于首次完成棒内的早先影线。

退出该模板**不等于趋势必反转，不等于主力出货，也不取消历史已经完成的 N**。单纯跌破轧空低／突破杀多高不自动退出洗盘模板：这里更关心原颈线与原波段边界，各价位角色不能混为一谈。

## 8. 再次 N 必须是独立结构

`reattack_setup` 是调用方明确选择的一个新 `NSetup`，可由前一层确认折线构建，不能复用首次 setup：

- 同股票、同周期、同方向。
- 新 N 起点属于本次已观察到的回档／反弹棒或更后面的结构。
- A/B/C 的来源及确认时间完整，几何仍由 `observe_n` 核验。
- 新 N 完成需要自己的实＋虚条件，不是收回轧空低、涨一天或任意突破就成立。
- 尚无新 setup，或新 N 尚未完成：保持待确认。
- 新 N 的 C 延伸／起点失效会提示其状态，需要新的结构判断；不会静默重选“更好看”的三点。

目前每次调用接受一个固定的新 N 候选，不扫描未来多个候选挑成功者。未确认拐点不提前暴露，历史快照中不会提前出现未来的新防守价。

## 9. 完成事件、后续跟踪与只做多约束

`frames` 记录原攻击、目标区、反向区和新 N 的观察索引；新 N 完成时冻结 `reattack_index/new_n_defense`。完成是历史事实，后面的下跌不会抹掉“该价格模板曾经完成”。

因此 `CONFIRMED` **不是永久有效的买点，也不说明当前仍然安全**。完成之后应将新 N 交给 `observe_control_bar` 和六态层继续跟踪；这个已结束的洗盘事件不负责新一轮止损、持仓或风险状态。

股票只做多、不新开空仓：

- 底部路径返回 `long_setup_review_not_order`：供后续多头候选审核，尚非买入指令。
- 头部镜像返回 `long_risk_review_not_short_order`：供现有多头风险审核，不是空仓指令。
- 两个模块均不创建 `Signal`／订单，不连接交易端，不改变旧策略。

即使出现候选，后续交易模块仍须独立核验量能、六态、趋势结构、风险收益、收盘可知性、次日可成交性、T+1、涨跌停和费用。本文不把讲义的空头平仓叙述变成实际做空行为。

## 10. 调用和验证

```python
from wavequant.control_bar import observe_control_bar
from wavequant.washout import WashoutPolicy, observe_washout
from wavequant.n_shape import MilestoneBasis
from wavequant.price_action import ShadowPolicy

control = observe_control_bar(
    bars, initial_setup, timeframe="1d",
    volume_lookback=5, shadow_policy=ShadowPolicy(0.5),
    asof_index=len(bars)-1,
)
washout = observe_washout(
    bars, initial_setup, timeframe="1d",
    policy=WashoutPolicy(MilestoneBasis.CLOSE),
    reattack_setup=second_setup,  # 也可以为 None，等待独立结构
    asof_index=len(bars)-1,
)
```

例中 5 根均量和 0.5 长影阈值只是显式示例，不是讲义给定或经过收益优化的参数。

```powershell

.venv\Scripts\python.exe -m unittest discover -s tests -p test_control_washout.py -v
```

示例用合成 OHLCV 跑通正倒镜像，并继续把新 N 接入六态观察。测试涵盖虚拟价跳空、量基准、防守盘中／收盘与恢复、开区间、2T 超越、同棒歧义、独立 N、方向约束、未来前缀不变及完成事件保留。这是代码和定义的验证，不是通达信盈利回测。
