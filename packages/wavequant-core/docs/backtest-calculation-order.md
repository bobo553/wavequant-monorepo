# 回测的变化联动计算

2026-10-14 修改，尚未运行验证。适用于当前分支的根日线回测。

## 执行关系

```text
当天 K 线 → 原 lecture_drawing 折线算法
                 ↓ 有效折线来源变化
              一级趋势及六态
                 ↓ 一级有效来源变化
              二级趋势及六态
                 ↓ 二级有效来源变化
              三级趋势及六态
                 ↓ 保存当天结果后处理下一交易日
```

一次 `calculate_trend_line(3)` 注册所需的三级状态，然后启动折线计算。
每个绘图回调在返回之前把当天变化向上传递，不等待全部折线历史完成，
也不先算完全部一级历史才启动二级。每层仅消费紧邻下层。

首次空来源会初始化空状态。新增确认点、旧点/确认信息修订、路径关闭或切换
都属于更新；不能只比较点数。有效来源完全相同时跳过该级几何计算，
也不把显示发展尾当作可递归来源。几何没有变化的日期仍按原行情规则推进
收盘确认、跳空及量能候选，不把“趋势不变”误当作“价格条件不变”。

## 最近翻向之后继续计算

当直接下级出现首次可知的空翻多/多翻空事件时，在当前级别保存该路径的
计算检查点。一级使用折线翻向，二级使用一级翻向，三级使用二级翻向。
检查点包括已处理来源身份、普通归并状态、升级关键位、候选证明和原来源位置。

正常新增直接追加到当前状态，不反复扫描整个翻向区间。尾部修订优先恢复
最近翻向检查点，仅把检查点之后的来源重新交给状态机；没有翻向检查点时
尝试已有尾部检查点。检查点之前的证据修订、迟知插入或内存准入失败时，
回退到受影响路径的完整判断。不能把翻向日之前的数据直接丢掉，因为旧关键位
及确认依据仍可能被后面的判断引用。翻向锚点按首次可知时刻保存，不回填到
更早的价格日期。

来源校验、结果导出、注释和证明归并仍可能读取保留的历史前缀；这次改动
减少的是状态机重放和层间整段历史传输，并未把所有处理都改成常数时间。

## 函数与数据源

| 职责 | 入口 | 数据源 |
| --- | --- | --- |
| 技术折线 | `calculate_polyline()` / `lecture_drawing()` | 原始行情及包含关系规则 |
| 一级趋势和六态 | `calculate_trend_line(1)` | 当天可知折线峰谷；六态量价确认使用当天行情 |
| 二级趋势和六态 | `calculate_trend_line(2)` | 一级已结束的正式高低点；六态量价确认使用当天行情 |
| 三级趋势和六态 | `calculate_trend_line(3)` | 二级已结束的正式高低点；六态量价确认使用当天行情 |
| N 测幅 | `calculate_n_targets()` | 已保存的因果折线历史及原有目标达成规则 |
| 交易输入 | `prepare_strategy_inputs()` | 所选级别已保存的交替结束事件，生成有效区间 |
| B/S 与账户 | 原策略及回测入口 | 有效区间、共享市场事实、量价及成交数据 |

六个独立状态函数及外部发布/读取步骤已取消；六态在趋势入口内部同步生成、
归档。只有实际消费者需要时，才读取 `history_events(level)`；一级至三级在
尚未计算时读取会报错，读取不会触发补算。折线保持独立入口，
`history_events("折线")`（也支持 `"polyline"` / `0`）可按需生成折线自身六态；
完整三级流已算过的折线六态直接复用。

```python
from wavequant.domain.strategies.market_calculations import market_calculations

with market_calculations(bars) as calculation:
    tertiary = calculation.calculate_trend_line(3)
    secondary_events = calculation.history_events(2)
```

只调用 `calculate_polyline()` 不会提前算三级。如果先请求折线或一级，再请求
更多级别，读取已有日期流补齐缺失级别，不重算已有级别。默认回测一次请求
三级，因此没有这些补齐遍历。退出作用域后临时历史不可使用。

N 测幅目前在联动市场流之后执行，随后才进入有效区间、B/S 和账户计算。
没有改动 N、买卖规则或账户风控。交易阶段复用市场流生成的六态事件及稀疏
检查点，不再次扫描六态；分钟部分行情继续从已有交易检查点推进未处理后缀。
