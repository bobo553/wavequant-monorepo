# 当前股票回测与 B / S 复盘

## 使用方法

启动现有服务：

```powershell
pnpm --filter wavequant-api python -- -m wavequant_api.cli --root ../../../packages/wavequant-core/results/operations_v1 --port 8765 --tdx-root D:/TDX
```

打开 `http://127.0.0.1:8765/`，刷新加载新界面。

1. 在右侧股票列表搜索并选股。默认仍是原始行情浏览，不偷偷运行回测。
2. 设置“回测起点”，终点取当前回放日期，点击“运行当前股票回测”。
3. 策略、执行风控与成本参数继承所选实验快照。默认严格折线版；日线代理版必须单独选择，只是研究对照。
4. 图上红色 B / 绿色 S 是模拟成交；黄色退出信号不是卖出。可点“仅看成交标识”减少遮挡，原折线和趋势线逻辑不变。
5. 点击图上标识，或下方 B / S 账本的“查看入场条件 / 查看退出原因”。该账本包含未平仓买入；“成交复核”表只列已平仓交易。
6. “定位最近成交”仅平移图窗，不改变回测终点。要审查某日当时已知信息，应移动历史回放滑块，服务按前缀重新计算。
7. “导出回测账本”下载完整 JSON：参数、数据与源码指纹、行情、信号、委托成交、已平仓交易、未平仓状态、筛选审计、绘图数据。没有发出券商订单。

## 策略约束与执行顺序

本次不放宽原有入场条件，不使用讲义显示层的补线代替严格策略确认。

- 先冻结空头结构的末跌高，再发生翻空为多、空多交替、多头确认。
- 必须满足 `flip_index < alternation_index <= bullish_index < attack_index <= signal_index`。
- 攻击与当前许可属于同一多头结构段；结构破坏后撤销旧许可。
- 只做轧空 / 强轧空，包含原有“守住防守位后的轧空回压恢复”入口。
- 回档比例小于 2/3、攻击相对量至少 1.2、原有最近未达目标与结构止损有效。
- 收盘参考盈亏比预检至少 1.5；次日真实模拟开盘价、滑点、双边费用与数量确定后，再检查净盈亏比。
- 仓位同时受现金、单股仓位、单笔风险预算、历史流动性和原始整手约束。
- 风险退出包括倒 N、负扭转、末升低跌破、严格结构未解；执行层还处理结构止损、目标触及和最长持有期。
- 所有日线观察在收盘可知，随后可交易开盘执行；目标 / 止损触及不等于在目标 / 止损价成交。同日同时触及仍按原执行器的保守止损优先顺序。
- 不可卖、T+1 或容量不足时延迟退出，并保留原决定日期、原退出原因及当时止损 / 目标，不能把延迟日伪装成触发日。
- 期末不强制平仓。没有成交时展示候选评估拒绝原因、结构中断、订单拒绝与未执行信号，不生成占位 B / S。

上述阈值是目前最新快照的固定研究参数，不是经独立样本证明的最优值。选其他快照时以导出参数为准。

## 复权和可追溯契约

`GET /api/tdx-backtest` 只接收 `run, variant, symbol, asof, scenario, start`；目录固定由服务启动参数提供，客户端不能传任意文件路径。

同一响应一次返回行情、成交与理论绘图，三者使用 `causal_adjusted_equivalent`：

```text
图表 OHLC = 原始 OHLC × 当日因果累乘因子
模拟原始成交价 = 账本 / 图表等价成交价 ÷ 成交当日因子
原始份额 = 等价份额 × 成交当日因子
等价成交价 × 等价份额 = 模拟原始成交价 × 原始份额
```

起点固定，未来除权事件不得重算过去因子。不是前复权到最新价的显示口径，不能与原始行情混用。

只有 `status=filled` 的订单生成 B / S，标记复用账本的日期和成交价，不用信号参考价。每次成交附原始价格、因子、份额、费用、决定日期；B 附趋势链、盘态、量能、回档、净盈亏比；S 附风险观察与触发原因。同一次买卖使用相同 `trade_id`。

响应附 `.day`、`gbbq`、解码后的该股除权事件、Python 源码指纹和确定性运行 ID。行情 / 除权文件运行中更新则拒绝返回混合结果；源码改变要求重启服务。无外部行情请求，不修改通达信目录。

## 不能隐藏的限制

- 当前执行模型只支持沪深主板非 ST 研究假设，创业板、科创板、北交所仍可浏览，但暂不生成回测成交，避免套用错误涨跌幅 / 手数规则。
- 跳过本地最早 20 个交易日，之后仍需策略自身结构和量能积累，不模拟新股初期规则。
- 当前名称为 ST / 退市的股票拦截；`.day` 没有历史 ST / 退市状态，历史非 ST 假设不能当作点时可交易性证明。
- 必须有本地 `gbbq`；不支持的拆并股类型直接报错，不降级为未复权回测。因果等价份额是收益近似，并非分红税、配股缴款的真实现金账本。
- 日线缺次级高低路径时严格版会拒绝结构。连续的讲义显示折线，不说明策略已取得盘中确认信息。
- 无成交、少数盈利成交、工程测试通过均不能证明策略有效；选股幸存者偏差、独立样本外评估与历史证券状态仍需单独解决。
