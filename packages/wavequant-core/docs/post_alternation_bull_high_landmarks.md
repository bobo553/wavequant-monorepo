# 空多交替后的首段多头高点

图上的“交替后多头段高点”是一个已确认空多交替低点之后，同一路径中第一段同级上涨趋势的终点。它不是空翻多时突破末跌高的高点，也不是当前图窗或后续行情中的最高价。

## 计算规则

1. 起点必须已经进入 `bear_bull_alternation_lows`，即空翻多严格突破冻结末跌高，随后完成严格小于 `2/3` 且未跌破原空头低点的已确认回档。
2. 按同一路径的 `(index, ordinal)` 顺序，交替低点之后紧接的第一个同级点必须为 `H`，且价格严格高于交替低点。
3. 不能跳过同类点、反向点、价格不成立或证据缺失的下一点去选择更远的高点；不读取原始 K 线猜测高点。
4. 高点必须已经携带自己的 `available_at`。地标的最终 `available_at` 取交替低点完整证据链与高点确认日的最晚日期。
5. 只读取正式 `strokes`；发展中路径、浏览器显示桥和未确认尾端不生成该地标。

每个 `post_alternation_bull_highs` 元素包含高点自身字段，以及：

- `confirmed_alternation_low`：该段上涨的已确认空多交替低点；
- `confirmed_flip_high`、`confirmed_bear_low`、`broken_key`：交替低点继承的完整空翻多证据；
- `retracement_origin`、`retracement_ratio`：此前空多交替回档证据；
- `source_path`、`source_available_at`、`available_at`：路径及因果可用日期。

## 展示边界

Web 只按图窗、回放截止日、趋势级别和独立开关显示 Core 返回的一级、二级、三级地标。关闭“各级交替后多头段高点”不会修改趋势线、末跌高、空翻多高点、空多交替低点、策略信号或回测结果。

中大力德一级示例为 `2022-09-01 H71 33.89`：它紧接在 `2022-08-30 L71 29.75` 之后，价格方向为上涨，并在 `2022-09-08` 完成确认。因此 `2022-09-07` 的历史回放不得显示，`2022-09-08` 起可以显示；后续更高的 `H72 38.28` 不会替换这一个首段终点。
