# TradingView 研究工作台

使用 TradingView **Lightweight Charts 5.2.1**（Apache 2.0），不是需要单独授权的 Advanced Charts。SDK 由 `apps/webs/wavequant-web` 的 pnpm 依赖提供，不依赖 CDN、不接入 TradingView 行情或实盘下单。

## 启动

在项目根目录的 PowerShell 中执行：

```powershell
pnpm install --frozen-lockfile
pnpm --filter wavequant-api dashboard
```

浏览器访问 `http://127.0.0.1:8765`。终端保持运行，Ctrl+C 停止。只绑定 loopback，不要通过反向代理暴露到公网。

## 已接入的页面

| 页面       | 可复核内容                                                                                                                   |
| ---------- | ---------------------------------------------------------------------------------------------------------------------------- |
| K 线复盘   | 通达信日 K、成交量、信号与成交分层标记、已确认折线、最近 5 个 N 字结构、点击事件的颈线／防守／目标参考线、事件字段、交易定位 |
| 策略绩效   | 费用后组合净值、含初始资金基准的回撤、仓位曲线；所有图均使用 TradingView SDK                                                 |
| 订单与信号 | 全组合委托/成交/拒单、当前证券信号、截至所选日期的 JSON 明细导出                                                             |
| 系统状态   | 封存运行、数据和研究门禁、恢复演练、当前本地告警；不提供确认告警或下单按钮                                                   |

支持实验、严格版/日线代理版、4 个成本/容量场景切换，以及逐根前后移动、日期滑块、返回最新截面。严格版默认开启，零交易明确为空状态，不替换成代理结果。

### 图上规则、信号与成交标识

- 紫色方块：现有引擎记录的 N 字突破／跌破、翻空为多、空多交替、多头许可确认、六大盘态、洗盘再攻击、盘势扭转和许可撤销等。规则标在 `available_at`，不是回写到此前拐点。未被引擎记录的独立理论不伪造触发标识。
- 青色圆点：封存的买入信号；金色圆点：封存的退出信号。退出观察可以在空仓时发生，不等于卖出。
- 红色 B 箭头／绿色 S 箭头：实际买入／卖出成交，SDK `atPriceBottom/atPriceTop` 使用原始记录的复权等价成交价定位，文字显示价格；不是把箭头任意贴到 K 线最高／最低点。
- “筛选 / 中断”默认关闭，开启可查看严格结构未解、候选筛选未通过、盈亏比预检等，以及未成交委托原始状态。候选未通过、委托延迟和实际成交分别保留，不能混称拒单。
- 所有图层可单独开关。规则同日合并为一个方块并保留全部事件；密集区域仅隐藏冲突文字，图标和点击详情不丢弃。图窗平移／缩放时右侧列表同步，仅列窗口内最近 100 项，更多事件通过放大或图上点击查看。
- 悬浮标识显示标题／价格；点击标识、当天 K 线或右侧记录显示来源、原因、点位与原始字段。同日合并事件可在详情中切换。
- “选中点位线”从所选事件可知日向当前截面绘制，不在此前绘制未知支撑压力。N 事件显示颈线、轧空低／杀多高、等浪及 1P／2T；复用现有 `project_n_targets` 和攻击棒虚高／虚低箱体口径。信号和买入成交可显示原始失效位／目标；不冒充当前移动止损或保证成交。超出轴范围的目标不拉扁 K 线，数值保留在详情。

纯标注测试：`pnpm --filter wavequant-web test:unit`。此层只转译和展示已有事件，没有放宽策略条件。

## 数据与时点契约

1. 仅发现 `operations.sqlite` 已登记为 `COMPLETED` 且包含 `research/report.json` 的封存运行。启动时验证完整文件清单及日志记录的清单哈希；首次读取再校验所用文件的字节。缓存保留已验证字节，不跟随文件被替换。新增运行需要重启服务。
2. 当前三个可视运行是 `acceptance_20260908`、`acceptance_20260908_final`、`acceptance_20260908_verified`。冻结行情为 10 只证券、21,011 根日线、2018-01-02 至 2026-09-07。独立的 62 只扩展实验尚未适配此工作台，不能把这里称为全市场视图。
3. 回放按上海交易日收盘截面过滤；K 线、权益、信号、委托不得超过截止日。仅当退出日已到达才返回已平仓交易，未平仓交易不返回未来卖价、卖日或最终盈亏。
4. 理论覆盖层使用冻结的策略参数，以**当前代码**在所选行情前缀重新计算，不把未来 K 线隐藏后冒充历史计算。接口输出引擎文件哈希与 `computed_from`。封存交易表仍是原实验产物，未来升级引擎可能造成理论与旧交易差异，需另登记实验，不能把覆盖层当作原引擎逐事件重放。
5. 默认“讲义绘图”独立于策略拐点：黄色普通高低折线保留发展中高／低端点，不接收盘；四种子母三点规则直接接入同一主路径，母线末端继续延伸／反转，不再单独绘制。原始三点留在 teaching_paths 供复核，发展端点延伸不改写原始依据。全部虚线且无端点圆圈。使用 SDK 自定义图元保留同一天的多个顶点；微小横向偏移仅帮助辨认顺序，不代表盘中时刻。普通段以第一对有方向的高低关系初始化，不按阴阳实体判断上涨／下跌；起点取相反侧极值，上涨只延伸最高端点，下跌只延伸最低端点，移除同向中间点，尚无方向的单棒／相等区间不画假定线段。初始点不冒充已确认反转。已知方向的先母后子采用基础单极值绘图：上涨缩头连接原高点至子低，下跌缩脚连接原低点至子高，不清空路径；这属于绘图口径，不代表次级日内顺序已解，来源保留在 inside_connections。十字星外包和未知初始方向仍显示待确认数量，不跨未知段补线；青色强调可独立关闭但不删除线段，尚不能宣称整段连续路径已完整定义。可切换“策略已确认拐点”查看原严格版／代理版结构，绘图不进入交易计算。仅渲染与图窗相交的段。N 字几何线是事后已知结构说明，事件确认日期单列；历史防守线不等于当前有效止损。教学连接不冒充实测盘中顺序，1P/2T 投影不冒充成交或保证目标。
6. 股价为因果复权等价价格；悬浮信息同时显示原始收盘。成交数量是等价份额，成交量为原始股数。组合指标不是所选股票单独收益；严格版与代理版不拼接。
7. 系统状态是运行时管理信息，不属于历史回放结果；股票中文名称仅为显示标签，不是 point-in-time 证券主数据。

## 验证

当前样式更新：讲义普通段、子母教学路径和策略已确认折线采用虚线；N 字轮廓以 A → B → C → 攻击点四点、三段连续实线呈现（正 N 青色、倒 N 棕金色）。取消折线端点圆圈及策略折线十字光标圆点。发展中／已确认状态通过悬浮详情区分。买卖信号圆点和成交箭头不受影响。

```powershell
.venv/Scripts/python.exe -m unittest discover -s tests -v
```

`tests/test_visualization.py` 使用独立封存夹具测试时点隔离、未来收益剔除、初始回撤、布尔口径、篡改检测、只读/同源/路径白名单。

浏览器验收脚本 `apps/webs/wavequant-web/tests/e2e.cjs` 对运行中的本地服务器执行，不写策略和回测产物。需要 Playwright 与 Chromium；可设置 `PLAYWRIGHT_MODULE` 为已有的 Playwright 包绝对路径，以及 `CHROMIUM_PATH` 为已安装浏览器绝对路径，然后执行：

```powershell
pnpm --filter wavequant-web test:e2e
```

`DASHBOARD_URL` 可覆盖默认地址。验收包含真实数据、成本切换、跨股定位、历史时点、失败重试、导出和 390px 窄屏。截图、报告和失败时的 trace 保存至 Web workspace 的 `results/visualization_v1/<UTC时间>/`。浏览器脚本使用当前已封存小样本的 0/2 笔验收基准；引入新的默认实验后需同步更新基准。

图表和工程测试通过只表示数据展示与交互符合契约，不证明策略盈利或达到实盘上线标准。
