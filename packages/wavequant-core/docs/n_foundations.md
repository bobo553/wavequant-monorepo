本页是项目的基础教材和实现约定。讲义描述、代码采用的工程定义、尚需验证的交易假设分开记录。学会识别形态与证明交易优势是两个不同的验收目标。

## 1. 基本价格语言

令 H、L、O、C 为本根最高、最低、开盘、收盘，前缀“前”表示上一根。比较使用同一周期、同一价格口径。严格大于/小于不包含相等。

| 名称                   | 明确条件                              | 讲义页码 |
| ---------------------- | ------------------------------------- | -------- |
| 缩头                   | H < 前 H                              | 16       |
| 缩脚                   | L > 前 L                              | 16       |
| 出头                   | H > 前 H                              | 16       |
| 落尾（旧笔记也称出尾） | L < 前 L                              | 16       |
| 日出                   | H > 前 H，L > 前 L，C > 前 H 同时成立 | 16       |
| 日落                   | H < 前 H，L < 前 L，C < 前 L 同时成立 | 16       |
| 虚拟低点               | min(L，前 C)                          | 6、28    |
| 虚拟高点               | max(H，前 C)                          | 6、28    |

跳空不能遗漏。例如前收 10 元，今日最低 12 元，虚拟低点仍是 10 元；前收 10 元，今日最高 8 元，虚拟高点仍是 10 元。两者是价格结构参考点，OHLC 数据不能证明它们就是某位主力的真实成本。

对应函数：`wavequant.foundations.bar_relations`。另保留等高、等低、严格内包、严格外包标志，避免把边界硬塞进上述四种比较。

## 2. 突破、跌破与正倒 N 字

讲义第 1–2 页强调，转强需要突破关键压力，转弱需要跌破关键支撑。突破/跌破本身尚不足以证明完整趋势已反转。

正 N 的结构可写为低点 A、颈线 B、回撤点 C，随后向上攻击颈线。倒 N 则为高点 A、颈线低点 B、反弹点 C，随后向下攻击。

第 4–7 页区分两种证据：

- 实过/实破：收盘价越过对应收盘参考。
- 虚过/虚破：最高/最低价越过对应极值参考。
- 正 N 同时完成两项，才取突破当根的虚拟低点作为“轧空低”。
- 倒 N 同时完成两项，才取跌破当根的虚拟高点作为“杀多高”。

**图 003 下半图的两个参考高度不同。** 本项目据图采用“双锚点”解释：`neckline_close` 为已知颈线的收盘参考，`neckline_extreme` 为其高/低参考；两者由调用方明确提供。此处属于图示的量化解释，讲义没有完整定义如何自动挑选所有颈线。不能任取一个滚动最高价，就声称已经识别出正 N。

例如颈线收盘参考 11 元、最高参考 12 元；攻击棒收 11.5、最高 12.2，满足实过和虚过。若统一要求收盘 >12，会得到更严格的另一种假设。若最高 >12，但收盘仅等于 11，则缺少实过，不完成。

对应函数：`n_break_evidence`。此函数输出证据和防守位，**不自动选择颈线，不发买卖订单**。

## 3. 攻击、抵抗、确认

第 3 页给出观察顺序：攻击当根、次根抵抗、第三根确认。代码必须等第三根收盘才能给出该三棒模型的结论，不能把第三根的信息写回第一根。

向上突破后的空头抵抗例子：阴线、低开、较长上影。向下跌破后的多头抵抗例子：阳线、高开、较长下影。这是可观察的形状证据，不是对交易者身份的判断。

`resistance_evidence` 的具体工程约定：

- 反向实体：向上攻击后 C<O，向下攻击后 C>O。
- 反向开盘：向上攻击后 O<前 C，向下攻击后 O>前 C。
- 长影线：对应影线长度至少占全根范围的 50%，阈值可显式调整。
- 三项任一成立，记为抵抗形状；一字 K 不记为长影。

讲义没有给“长影”统一比例，50% 是待检验的实现参数。抵抗形状与抵抗成功也不同：后者需要检查关键价位及之后的延续。

## 4. 六大盘态

| 多头盘态 | 基本含义                                   | 空头对应                             | 关键参考           |
| -------- | ------------------------------------------ | ------------------------------------ | ------------------ |
| 强轧空   | 没有明显空头抵抗，连续向上                 | 强追杀：没有明显多头抵抗，连续向下   | 虚拟低/高          |
| 轧空     | 有抵抗但失败，守住攻击防守位后继续向上     | 追杀：反弹受阻后继续向下             | 轧空低/杀多高      |
| 盘坚     | 压回消化攻击，但未破波段支撑，之后再创新高 | 盘跌：反弹未破波段压力，之后再创新低 | 更大一层的波段边界 |

来源：第 11–15、26–28 页。第 14 页追杀段落写“持续出现上涨的走势”，与段首、强追杀和图 007 的下行图矛盾，按疑似笔误记录，代码采用向下延续，不照抄“上涨”。

### 三棒分类函数的范围

`three_bar_state` 接受前一根、已被调用方确认的攻击根、回应根、确认根，以及已知波段边界。它提供一个明确、对称的三棒代理：

1. 多头向上延续要求第三根收盘超过攻击根和回应根的最高价；空头对称。
2. 两根后续 K 均守住攻击虚拟防守位，且没有抵抗、连续同向收盘，归强轧空/强追杀。
3. 有次根抵抗，守住虚拟防守位并完成延续，归轧空/追杀。
4. 有抵抗、突破了攻击防守位，但守住更大波段边界并完成延续，归盘坚/盘跌。
5. 波段边界失守记“结构失效”；缺少延续或条件含混记“未确认”。

这里将“抵抗成功”具体化为攻击防守位被越过，是工程代理，讲义没有规定所有盘坚都必须如此。真实盘坚可能需要更多根 K 线，因此这个函数不覆盖其全部形态。六大盘态也并非一套强制覆盖每天的互斥标签；有些交易日应当保持未知。

示例：攻击根虚拟低点 10，波段低点 8。压回最低 10.8 后再创新高，可符合轧空；压回至 9.7、没有跌破 8，再创新高，可符合本代理的盘坚。不能把“低于颈线”直接等同于“整个波段已经失败”。

## 5. 高低折线、趋势和关键转折点

更新：新独立层 `wavequant/domain/market_structure/polyline.py` 与 `wavequant/domain/market_structure/trend_structure.py` 已实现下述术语、连接法和分阶段交替证据，完整口径见 `docs/polyline_trend_contract.md`。本节旧 `swing_context` 描述保留用于历史复现；它取最近高低点前驱，不等同于新层按显式窗口极值选取并冻结关键位的规则。

第 16–23 页的基础关系：

- 正反转是一个短期由跌转涨的低点，负反转是一个短期由涨转跌的高点。单个反转不必然改变主趋势。
- 多头趋势要求同层级高点和低点都逐步抬高，空头趋势要求两者都逐步降低；一高一低的混合关系不应硬判多空。
- 末跌高：所分析低点之前最近的负反转高点。
- 末升低：所分析高点之前最近的正反转低点。
- 突破末跌高出现“翻空为多”的证据；跌破末升低出现“翻多为空”的证据。随后回档/反弹的力度决定后续判断。
- 头部疑虑：反弹不过前高，之后再跌；跌破末升低才完成更强的头部证据。底部疑虑对称。

`SwingPoint` 同时记录拐点所在索引和确认索引。`swing_context` 只读取截至查询日已经确认的交替拐点，比较最近两组同类高低，给出 bull/bear/mixed/unknown，并提供最近低点之前的高点、最近高点之前的低点。它依赖输入拐点的正确性，不实施讲义全部手绘折线法。

讲义从“画面最高/最低点”回看。用于历史研究时，不能先拿全段最终高低点再追溯标记早期市场状态；分析窗口与确认时间必须明确。

### 母子、子母线

第 23 页明确说原则上应利用次级线图划线；第 24、25 页四种阳阴子母规则完全重复，没有独立补全全部情形。项目目前把内包、外包记为需要次级数据澄清。不能在只知道日 OHLC 时，捏造一天内高、低的准确先后。

讲义给出的四种规则现已在 `child_mother_path` 中实现为显式教学路径，不自动注入严格研究折线。新层十字星保留未知，相等高低不归严格内外包；未解决的内外包会暂停后续折线，并可接收调用方声明来源的高低顺序证据。它不自动加载次级行情，也不凭母棒颜色假定日内真实路径。

## 6. 等浪、一饱和二吐

三个目标必须分别命名。

### 等浪（第 8 页，图 005）

第一段从 A 涨至 B，回撤到 C；图中 `B−A=D−C`，所以 `D=C+B−A`。

例：A=8、B=12、C=10，等浪目标 D=14。旧项目使用的 `2×颈线−起涨低点` 是箱体类目标，不能把它改称等浪。

### 一饱、二吐（第 9–10 页，图 006）

该图另用 a、b、c、d 标注，并明确 `d−c=c−b=b−a`。因此：

- 一饱 1P：`c=2b−a`。
- 二吐 2T：`d=3b−2a`。

图旁将 b 标为虚高参考。为避免与图 005 的 B 混用，`measured_targets` 要求显式传入 `box_anchor` 才返回 1P/2T；不给该锚点，只算等浪。若 a=8、b=12，则 1P=16、2T=20，与前例的等浪 14 不同。若虚高参考改为 12.5，1P 就是 17。

下行公式可作符号对称的数学扩展，但不能把算出的零或负价解释为必然见底。代码将非正目标返回 None 并标注不可用。

讲义建议先看等浪，达到后再看 1P/2T，完成后才谈更高层的叠箱。“五顶十满”缺少完整算法定义，本次未编造。函数预先算出的是潜在参考价，不代表这些阶段已经发生，更不代表能成交在该价。

## 7. 三分力道与六分力道

更新：独立 `wavequant/domain/market_state/wave_strength.py` 已实现本次精确定义，契约见 `docs/wave_strength_turn_contract.md`。新层保留字面区间缺口、边界及精确六分／印刷小数两种尺度，图 011 的价格高度与回档深度分开。下文旧 `force_profile` 不修改，以保持历史复现。

统一先算反向幅度占原波段幅度的比例 r。

上涨后的回档：`r=(上涨高点−回档低点)/(上涨高点−起涨低点)`。

下跌后的反弹：`r=(反弹高点−下跌低点)/(起跌高点−下跌低点)`。

| 观察                   | 趋势含义                     | 来源  |
| ---------------------- | ---------------------------- | ----- |
| 回档很小，例如小于 1/3 | 回档自身弱，原上涨相对强     | 33    |
| 回档达到约 2/3         | 回档自身强，原上涨相对弱     | 33    |
| 反弹超过 2/3           | 反弹较强，原下跌力量可能减弱 | 32–33 |
| 六分刻度               | 1/6、1/3、1/2、2/3、5/6      | 33    |

原稿对 1/3 至 1/2 的部分回档区间、边界相等情况没有完整覆盖；“超过”“达到”“以下”也不完全统一。图中的百分数位置还可能表示价格高度，而非从最高点量出的回档比例。因此代码 `force_profile` 保留比值、精确边界和六分区间，不对空白区间硬贴作者的强中弱标签。

工程口径采用精确分数 2/3；讲义其他段落的 67% 是近似写法，不能在敏感边界处假装完全相等。若后续研究要用 0.67，应另列参数。比例相等时既不满足严格大于，也不满足严格小于。

## 8. 盘势正扭转、负扭转和洗盘描述

更新：`wavequant/domain/market_state/market_turn.py` 现提供四个已确认拐点、六态背景、末跌高／末升低及可计算次级斜线的完整分阶段接口，保留负扭转破末升低的 OR 分支。明确使用组合之后的新越线、严格阈值和冻结点延伸检查，不再依赖旧 `turning_evidence` 的单个外部布尔值；旧代理行为保持不变。

第 34–35 页强调分阶段证据：

- 正扭转：较强反弹带来疑虑，接着非强势回档，再结合次级下降线突破。
- 负扭转：较深回档带来疑虑，接着无力反弹，再结合次级上升线跌破。

`turning_evidence` 用第一段反向比率 >2/3、下一段反向比率 <2/3 表示比例组合，并要求调用方提供次级趋势线突破证据才返回 confirmed。该趋势线未知时保留 None，不按“已经突破”处理。这是比只看比例更严格的基础组合，不能声称覆盖所有负扭转路径，特别是直接跌破末升低的情况。

第 29–31 页把底部洗盘描述为突破、达到目标区、回撤消化、再次 N 字攻击，头部则对称。项目可描述这些价格阶段，但没有资金身份和订单数据，不能把“洗盘”“诱空”或“进货出货”当作已观测事实。

更新：`wavequant/domain/market_state/control_bar.py` 已提供 N 主控棒、量增证据与冻结防守跟踪；`wavequant/domain/market_state/washout.py` 已实现图 009 的独立新 N 时序模板及头部镜像。详细开区间、退出、同棒歧义和只做多边界见 `docs/control_washout_contract.md`。这些新观察层没有改写旧策略或历史收益。

讲义中的 80% 抵抗概率、70% 目标区出货概率未提供样本、统计口径和可复核来源，本项目不将它们作为胜率或模型先验。

## 10. 实际运行

在项目根目录使用已有通达信数据快照：

```powershell
.venv\Scripts\python.exe -m wavequant.interfaces.cli foundation-audit data/tdx_rerun_20260908_01.csv --output-dir results/foundations_lecture
```

命令先运行全部自动测试，再输出基础关系计数、每股逐日虚拟高低点及形状明细。相邻棒的抵抗形状仅是基础证据，不能脱离先前攻击上下文来分类六大盘态。

结果有 `report.md`、`report.json`、`test_log.txt` 与每股明细，源码和输入数据 SHA-256 可复核。这个命令不下单、不做收益优化，也不覆盖原有回测报告。
