# 高低折线、结构趋势与多空交替

实现：`wavequant/polyline.py`、`wavequant/trend_structure.py`。依据用户提供的图 008、基本术语和折线连接文字；本次不改动旧策略、旧报告或旧 `foundations.swing_context` 的行为。

本层描述可观察的价格结构，不证明筹码已被某个主力吸纳、真实成本、趋势必然持续或买卖收益。原文的买卖提示没有直接变成订单。

## 1. 基本知识的精确定义

同一股票、周期及复权口径的相邻已收盘 K 棒，今为 t，昨为 t−1。

| 名称       | 条件                          | `BarRelations` 字段 |
| ---------- | ----------------------------- | ------------------- |
| 缩头       | H[t] < H[t−1]                 | `shrinking_head`    |
| 缩脚       | L[t] > L[t−1]                 | `shrinking_foot`    |
| 出头       | H[t] > H[t−1]                 | `extending_head`    |
| 落尾／出尾 | L[t] < L[t−1]                 | `falling_tail`      |
| 日出       | H 抬高、L 抬高、C[t] > H[t−1] | `sunrise`           |
| 日落       | H 降低、L 降低、C[t] < L[t−1] | `sunset`            |

所有不等号都严格；相等高低单独记录，不等于出头、缩头、缩脚或落尾。日出／日落不是只看红黑 K 棒。入口为 `observe_bar_relations(previous, current)`。

## 2. 折线、暂定端点和正负反转

折线是一串交替的高低拐点及一个尚未结束的端点。

- 上行中，不落尾且不缩头：只更新更高的高点。
- 上行中，出现落尾或缩头：连接高到低；原上行端点成为**负反转高点**。
- 下行中，不出头且不缩脚：只更新更低的低点。
- 下行中，出现出头或缩脚：连接低到高；原下行端点成为**正反转低点**。
- 严格内包／外包优先进入特殊处理，不直接套上述普通棒规则。

`observe_polyline` 要求显式 `initial_direction` 和 `start_index`。起始方向只是初始化条件，不是模型已确认的趋势；首根端点不会被伪造为一个已确认反转。价格相等保留原端点，零长度连接不产生反转。

每个 `ReversalPoint` 保存：

- `point.index`：高低点实际所在的源棒。
- `point.ordinal`：同棒内显式路径的顺序。
- `point.kind/price`：H／L 和价格。
- `confirmed_index`：后续转向何时已经可知。
- `source`：普通棒规则或调用方提供的路径证据来源。

因此“低点画在第 3 棒”不意味着第 3 棒已知道它是正反转；如果第 4 棒才转向，确认时间就是 4。`frames[].candidate` 是可延伸的暂定端点，不能拿去充当已确认 N 拐点。已确认拐点只追加、不回写。

**正反转、负反转描述当前折线段的转向，不等于主趋势翻多、翻空。**

## 3. 母子、子母与日内路径

严格内包：今高 < 昨高且今低 > 昨低；严格外包相反。等高／等低不自动归入严格母子关系，仍按普通严格比较处理，这是明确的边界约定。

默认遇内包／外包就记录 `blocked_at`，停止这个折线运行继续生成拐点；不会略过该棒后假装结构连续。后续快照保留暂停位置。若需恢复，补齐路径证据后作为有新证据的重新运行，不能冒充旧运行原本已知。

可以传入 `paths={index: BarPathEvidence(index, (HIGH, LOW), source)}` 或相反顺序，明确该棒两个极值的顺序。证据必须在这根棒收盘时已经可用；该接口保存调用方声明的来源，**不自动核验某个字符串真的来自逐笔数据**。如果晚到数据改变顺序，应保留两次运行及各自来源，而不是静默改写研究结果。

次级 OHLC 如果高低仍出现在同一根次级棒，顺序仍可能未知；必须继续细分或保持暂停。两个极值的顺序也只是折线所需的压缩路径，不声称还原全部日内波动。

原文实际提供的是“先子、后母”的四种颜色规则，重复段落不是另四条规则：

| 子棒 | 后续母棒 | 教学折线路径       |
| ---- | -------- | ------------------ |
| 阳   | 阳       | 子高 → 母低 → 母高 |
| 阴   | 阳       | 子低 → 母低 → 母高 |
| 阳   | 阴       | 子高 → 母高 → 母低 |
| 阴   | 阴       | 子低 → 母高 → 母低 |

`child_mother_path` 完整返回以上顶点，并标注 `teaching_convention`。它**不自动注入**严格折线或回测。十字星返回 `undefined_doji`；“先母后子”的全部规则并未给出，不倒序套用这张表。这样既定义了讲义连接法，也不拿 K 棒颜色冒充实际高低先后。

## 4. 多头趋势与空头趋势

`observe_structure` 只消费截止查询时已经确认、同层级、交替且时间有序的拐点。

- 多头：高点严格高于前高，低点严格高于前低。
- 空头：高点严格低于前高，低点严格低于前低。
- 高低不同向，或必要比较相等：`MIXED`，不硬分多空。
- 少于两个已确认高点或两个已确认低点：`UNKNOWN`。

返回两种范围，避免混淆“每一个”：

- `trend`：最近两组高低比较所描述的局部结构。
- `window_trend`：选定窗口里**所有**相邻同类拐点都同向，才判整个窗口单调多／空趋势。

窗口先跌后涨时，局部可以已经多头，但整段不一定是多头。不同级别的折线应分别调用，不混入不同周期的点来拼出趋势。

## 5. 末跌高、末升低及图 008

“画面最低／最高”在代码中改为显式 `window_start` 至 `asof_index` 内**已确认拐点**的最低／最高。不是完整未来样本中的终极低点／高点；没有确认的实时新低只在折线候选端点中呈现。

- 末跌高：所分析低点左侧，最近的已确认负反转高点。
- 末升低：所分析高点左侧，最近的已确认正反转低点。
- `preceding_turn(points, target)` 可查询任一指定拐点，而不局限于窗口极值。
- 缺少左侧拐点时返回未知，不补画一个前高／前低。
- 同价极值选最早一个，触及相等不暗中替换参考。

图 008 中 L0 的末跌高是 H1；后面形成 H2、H3 并不改变“L0 所对应的 H1”。同理 H0 对应 L4，指定 L7 对应 H6，指定 H4 对应 L3。若要以 L7 所在后半段为当前分析窗口，应显式修改窗口，不能以全图最低的 L0 偷换 L7。

返回的 `last_fall_high/last_rise_low` 是基础层 `KeyLevel`，其来源棒保留原高低点位置，确认时间保守记录为当前窗口选择时点。选择窗口极值也是一次信息使用，不能把今天选出的参考位追溯成昨天已经选择。

## 6. 疑虑、翻转和交替是不同阶段

`observe_trend_transition` 接收一个已冻结 `StructureContext`。背景必须已有局部多／空结构，且对应窗口关键位完整；未知或混合背景不擅自补成空／多趋势。

冻结空头背景，寻找向上转换：

1. **底部疑虑**：低—高—低中，反弹高点仍低于冻结末跌高，后低不低于前低及冻结低点，并且后低已经确认正反转，即确已再次向上。不能只在低点出现时就回标疑虑。
2. **翻空为多／底部成形证据**：越过冻结末跌高。调用方必须选择 `AttackBasis.CLOSE` 或 `INTRABAR`，复用统一突破函数，相等不算。
3. **空多交替**：突破后第一段上攻高点已经确认，其后的回调低点也确认；回调幅度为上涨幅度的严格 67% 以下，且是非零、未完全回吐的回调。

冻结多头背景则镜像：

1. **头部疑虑**：高—低—高中的反弹高点不高于前高，回调低点仍高于冻结末升低，后高已经确认负反转，即确已再次下跌。
2. **翻多为空／头部成形证据**：跌破冻结末升低。
3. **多空交替**：首次下攻低点与随后反弹高点均确认，反弹严格小于下跌幅度的 67%。

这是“成形的价格证据”，不代表此后必涨／必跌。突破可以直接发生，不强制必须先有头底疑虑。疑虑与突破同棒时不编造日内顺序，也不补记先前疑虑。

疑虑允许等低／等高测试，因为“不再创新低／不过前高”并不要求严格抬低／降低；而**多空趋势的同类点比较仍是严格的**。

## 7. 幅度、33%、67% 与 abc

向上突破后的回调：`r=(上攻高点−回调低点)/(上攻高点−该上攻段起涨低点)`。

向下跌破后的反弹：`r=(反弹高点−下攻低点)/(该下攻段起跌高点−下攻低点)`。

分母不是整个分析窗口的跨度，而是破位所在上攻／下攻段的幅度。段的起点、极值和反向点都带确认索引；同一根日棒内的多个段不强行投影成日线交替。

`retracement_evidence` 保留原始幅度和比率，使用十进制计算严格阈值：

- r < 0.67：符合正文交替的幅度条件。
- r < 0.33：符合注释“小回档自身弱、原方向相对强”的条件。
- r = 0.67 不满足“小于 67%”；r = 0.33 不满足“小于 33%”。
- 不把 0.67／0.33 偷换成精确 2/3、1/3。旧 `force_profile` 的分数口径仍保留，不混报。
- 零回调虽算术小于 67%，但没有形成回调，不能据此宣告交替。

“通常三波 abc”不等于每次反向运动已经被证实为 abc。独立 `observe_abc` 要求传入恰好四个已确认、同层级的交替顶点，形成三段反向／恢复／反向路径；中间恢复必须部分回吐首段。返回第三段长度是否至少等于第一段，不把“小于等浪”删掉，也不凭单段低点伪造 a、b、c。

当前交替判据不强制 abc，因为原文用的是“通常”；若未来要作为交易过滤，应显式消费 `ABCEvidence`，另行测试。

## 8. 失效与不回写

冻结底部转换事件若跌破其原始窗口低点，或顶部转换事件若突破其原始窗口高点，该事件失效，不随着后续价格恢复而复活。若同棒又越过转换关键位，优先失效，不猜日内顺序。

后来失效可以保留此前已知的突破和交替确认时间；失效后才确认的极值／回调不能倒灌成历史交替。想研究新的极值，应冻结新上下文。

一个转换事件只观察第一次破位及其第一组完成的反向结构，不事后挑第二次、第三次更浅的回调使其“通过”。深回调返回独立状态，不等同于已经交替或立即反向下单。

`ALTERNATION` 描述这组冻结事件曾满足交替条件，不保证后续始终维持该趋势；使用方还须查看确认时间、当前结构及失效状态。它不是自动永久持仓指令。

`asof_index` 限制所有价格与确认点读取；截断数据与全量数据按同一 asof 查询结果相等。反转、疑虑、突破、交替分别记录它们真正可知的时间。

## 9. 与突破、N 字和六态接通

两条用途相关，但不能混为一条推断：

- 折线 → 已确认高低点 → 结构趋势／末跌高末升低 → 统一突破跌破 → 交替证据。
- 折线 → 已确认 A/B/C → `n_shape.observe_n` → `market_regime.observe_market_regime`。

`n_setup_from_polyline` 只使用最近三个已确认反转；拒绝暂停中的折线、拐点不足、多个拐点落在同一根日棒。N 层继续独立核验正倒 N 几何、确认时间、双锚点实／虚条件和防守位，不把任意三个点都判为 N。

C 在当前棒才确认时，这根棒的历史越线不能被下一棒重放成已知 ABC 后的攻击；必须满足 N 层既有因果时序。六态仍从完成 N 的当笔、次笔、第三笔起独立观察，不因为局部已多头就自动标强轧空。

使用方若从 `PolylineObservation.reversals` 构建趋势上下文，必须先检查 `blocked_at is None`；暂停前的旧拐点不能拿来冒充暂停后的完整结构。次级数据解析、自动周期聚合、自动处理全部母子线和旧策略迁移不属于这次已完成接口的能力。
