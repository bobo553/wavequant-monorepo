# 股票列表与搜索

列表来自当前封存快照 `/api/catalog` 的 `symbols`，展示该快照中每只可查询股票。不是全市场实时行情列表，不自动导入新股票或改写股票池。当前已有中文名沿用 `web/labels.js`，可由股票元数据 `name` 覆盖；未知名称显示“名称待补充”，代码仍可选择和搜索。

搜索支持中文名、代码、交易所前缀、空格分隔的多个关键词，不区分大小写，并兼容全角数字。回车选择首项，Escape 或清空按钮恢复全部股票；空结果有提示。按钮可通过键盘选择，当前股票高亮。

列表与原下拉框共享同一选择流程，选中后加载个股 K 线、三级趋势线、结构事件、买卖标记和信号。下拉选择和交易定位会同步列表高亮。列表跨页面保留，点击返回 K 线复盘；切换股票保留正在请求的回放截止日，取消旧行情请求，并用请求序号拒绝过期返回。

摘要显示所选历史截面的原始收盘、成交量和个股信号数。收益、回撤、仓位与交易账本跟随“结果口径”：默认个股独立回测，可切回原封存组合；两者明确区分。列表中的行情根数、覆盖终日仅为快照覆盖信息，不显示未来价格；摘要、图表仅使用回放日前的行情。

新选择加载时摘要显示股票与截止日，失败时隐藏旧图并显示错误。搜索保留完整股票池，不改变接口、策略或封存结果。桌面采用网格卡片，手机为双列可滚动列表。
