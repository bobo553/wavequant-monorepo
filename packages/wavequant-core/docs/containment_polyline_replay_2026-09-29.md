# 母子与子母折线历史回放（2026-09-29）

## 计算口径

对比基线为本地 `main` 的 `1e7f402`，新版为 `feat-折线连线`。两版读取相同的 `tests/fixtures` 日线 OHLC，逐日重建讲义折线、一级至三级趋势、正 N、策略信号，再调用 `single_stock_result` 计算订单和权益。正式 V3 信号参数取 `whole_wave_profile`；成交使用 `StrategyConfig` 默认日线设置，未加入分钟撮合，因此表中收益仅与这一组参数及样本可比。

## 规则边界

空心阳线按低→高，阴影阴线按高→低；母子和子母各四种组合都按价格方向合并相邻同向段。已知入线方向的内包十字星只接相反极值，保留日内顺序未解标记，避免凭十字星颜色清空已确认的历史结构。严格研究折线仍要求次级顺序证据；此处回放使用 `lecture_causal` 的讲义路径及其收盘确认拐点。
