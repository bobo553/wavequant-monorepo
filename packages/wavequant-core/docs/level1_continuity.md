# 一级趋势线连续显示

基础折线、一级反转判定和二三级派生规则不变。一级已确认节点仍按原路径分组，确认日期不提前，未确认尾端不延伸。

显示层在前一组末端和后一组起点之间增加浅蓝实线衔接，和组内线段共用完全相同的坐标。衔接在视窗筛选前生成，避免两端在屏幕外时中间不画。关闭一级图层时衔接一并隐藏，不重复绘制端点标签或圆点。

跨组衔接标记为 `reversal-connection / display_only`，点击线段显示“跨原路径衔接（仅显示）”。它不是新增反转，也不证明未解区间的方向；同类端点不会被篡改成异类端点。它不写回 `reversal_trends.strokes`，不参与末跌高、末升低、二三级线、策略或回测。缺口中的真实路径仍需次级数据解释。重叠路径不跨接。

同类端点禁止直接连接：L-L 必须经两点之间原折线中已知的最高 H，H-H 必须经已知的最低 L。仅考虑 confirmed/teaching 点，排除 seed/developing、确认日期晚于两端可知日期的点，以及不能构成上/下折返的价格。极值相等时取时间顺序最早者；同 K 线按 ordinal 排序，并保留原折线的投影坐标。缺少这种相反极值时不伪造衔接。

上海机场原始日线回归：2026-07-22 L 23.40 → 2026-07-30 H 24.95 → 2026-08-17 L 22.86。7/30 是原折线已知高点，作为显示衔接依据，并不升级成新一级反转信号。两条衔接线均可点击查看说明。

上汽集团 2026 年 4—6 月本来就是同一路径：4/1 H → 5/28 L → 6/2 H → 6/29 L。此次保留其节点，增加真实浏览器回归检查坐标连续性。6/29 低点到 7/20 才可知，不能以完整历史图上的端点日期代替信号确认日期。

验证：`pnpm --filter wavequant-web test:unit` 与 `pnpm --filter wavequant-web test:e2e`。后者同时检查上汽集团 2024 年 7 月原路径间衔接、图层切换、数据不变和图窗外端点。
