# 策略改进与有效性证据契约

## “证明有效”的准确含义

历史数据只能提供条件性的统计证据，无法保证未来盈利。这里把问题拆成四项：理论事件是否识别正确；费用后是否有经济价值；改进是否优于原策略而非碰巧选中；在未参与开发的新数据上是否复现。工程测试不替代这四项。

协议版本 `squeeze_evidence_v5_fixed_hypotheses_20260908`。候选、样本规则、时间段、统计假设和停止规则先写入配置，再计算结果。该声明仅适用于本轮；此前已做过多轮探索，不能倒签为首次预注册，也不能称完整历史试验记录。

## 可检验的改进

| 候选              | 唯一相对对照的改动            | 为什么值得检验                               | 不允许的解释                                   |
| ----------------- | ----------------------------- | -------------------------------------------- | ---------------------------------------------- |
| proxy_control     | 无，原 v4 日线代理            | 给其他候选提供同一数据、费用、账户下的对照   | 不是讲义严格折线                               |
| proxy_context_252 | structure_window 120 → 252    | 慢趋势的背景可能被固定半年窗截断             | 不允许忽略关键位失守、撤销背景或跨片段连接     |
| proxy_volume_1    | minimum_rvol 1.2 → 1.0        | 1.2 是经验阈值，可检验是否错过并不缩量的攻击 | 不是量能过滤已经无效的结论                     |
| proxy_rr_1        | minimum_reward_risk 1.5 → 1.0 | 盈亏比必须和胜率、持有时间及成本一起评估     | 不缩窄结构止损、不跳过更近目标、不承诺更高收益 |

候选不组合成多维网格，不根据验证／诊断结果继续加阈值。严格折线单独报告。若某候选失败，保留失败；本轮默认策略不变。

## 股票样本

仅扫描现有 SH60／SZ00 主板 `.day` 文件。首条本地记录早于 2018-01-01 的文件进入可抽样集合，按固定种子与股票代码 SHA-256 排序，原十股加另外 54 只。只读取首条日期决定覆盖资格，不用历史收益、波动、成交量或今天市值排序。

这能减少主观挑选“熟悉的好股票”，不能解决本地缺失的退市文件和历史 ST 资料。首条本地日期也不是经认证的 IPO 日期。选中后文件损坏、除权类型不支持等原因必须进入 quarantine，不按结果补入另一只股票。研究报告显示选中／导入／隔离数量。

## 时间与选择规则

开发 2018–2021；验证 2022–2023；诊断 2024–2026-09-07。原十股与这些历史时期已经被查看，不宣称独立锁箱。扩大到额外股票仍有日期、数据供应商与市场环境依赖，不称为完全独立市场验证。

开发段先要求至少 30 笔已平仓、5 只成交股票、基准和双倍费用净收益均为正，才在合格候选中按净收益排序；并列按候选名。无合格者返回 CASH。所有候选及失败原因保留，不能只展示赢家。

滚动窗口沿用 756 观察日训练、252 验证、126 测试，间隔等于 max_hold_bars。每次只按该窗训练数据选择，验证／测试不参与择优。信号可使用当时已知的此前热身历史；空仓开窗，未平仓末日估值，不强平，不把窗口净值拼成可交易的连续账户。间隔仅是明确的隔离设置，不是所有类型标签重叠都已被清除的证明。

## 统计定义

所有候选使用完全相同的日历索引。`equity_returns` 包含开窗首日相对初始现金的收益，空仓日保留；不把单只股票或重复形态观察当成互相独立的市场样本。

`joint_block_test`：

1. 每个候选计算费用后日收益均值。
2. 每次共同抽取同一组循环日期块；当前块长 20，2,000 次固定种子。共同抽样保留候选之间的相关性，块内保留短期自相关。
3. 每次对候选的重采样均值减去其原样本均值，取本组最大值并与零比较。每个候选的单侧调整 p 为 `(1 + 超过观察均值的最大统计量次数) / (B + 1)`。
4. 原始重采样均值的区间使用本组 Bonferroni 尾部水平。它是每日算术均值区间，不是 CAGR 或单笔收益区间。
5. 另对各改进与 proxy_control 的逐日配对收益差做同样的组内诊断；相对原策略更好不等于能盈利。

这是有限候选组、平稳／弱依赖假设下的探索性最大均值块检验，并非完整 White Reality Check／Hansen SPA／Deflated Sharpe Ratio 的认证实现。它不校正此前未完整记录的人工试验、股票池偏差、复权误差或数据窥探。不要把 `1-p` 解释为“策略未来盈利概率”。正的日均值也不代表相对市场因子有 alpha；报告中的等权买入持有仅为无费、非风险匹配的参考。

没有价格变化的现金路径和样本太短的路径返回 unavailable，绝不能因为方差为零而赋予无穷 Sharpe 或显著性。30 笔／5 只／60 活跃日只是防止极稀疏样本误用的本项目门槛，不是统计功效计算，也不是世界通用标准。

## 研究门禁与外部证据

研究检查要求：交易及股票分布、活跃日足够，诊断净收益与双倍费用结果为正，本组调整 p < 0.05，均值区间下界大于零。报告逐项展示，不只给一个总分。

以下外部证据未齐时 `validated` 保持 false：真实历史证券状态与股票池、真实次级路径或独立的代理事件人工标注、完整试验记录、冻结后未参与开发的样本。补齐这些材料后还需要设计新的独立验收协议，而不是手工把输出字段改成 true。

本轮没有创建自动交易或持续监控任务，没有伪造未来数据。若没有候选通过，下一步应补数据、确认理论映射或否决假设，而不是不断试到一个赚钱参数。
