# V3：整段幅度双买点与五组方案对比

本版本实现用户最新定义，旧 V2 保留作历史对照。不改变底层折线和一、二、三级趋势线画法。默认第一类仅允许二级或三级交替提供背景，两级为任选其一；第二类保留既有级别范围。这里只定义研究规则，不把价格形态解释为可验证的主力意图。

## 锚点与时序

- L0：翻空为多对应下跌段的最低点，即整个翻多上涨段的起点，不是局部 N 字前一低点。
- H0：翻空为多这一波的高点。
- A：随后已确认的空多交替低点。
- H1：空多交替之后，收盘突破 H0，再上涨形成的最高点；只能使用 N 攻击之前已观察到的最高价，不能使用未来最终最高点。
- Cmin：H1 所在 K 棒至当前信号确认日之间的最低收盘价。

折线极值发生时间和被确认时间分开记录。必须在 N 攻击前已经确认翻空为多、空多交替，不能事后把买点标回尚未确认的日期。

## 默认第一类：二级或三级交替后的正 N 轧空

1. 二级或三级已完成翻空为多、空多交替；使用与图表相同的已确认结构证据。
2. 整个 L0 起点至信号确认期间，实际最低价不得小于 L0；触及等于 L0 允许。
3. 回撤比例 `r1 = (H0 - A) / (H0 - L0)`。
4. 交替允许原浅回档、随后已确认高点再次突破，以及下述“合格 b + 正 N 轧空”路径；默认不另设深于 1/2 的过滤。显式深回撤对照只保留各自幅度门槛，结构识别全部与图表统一。
5. 正 N 确认轧空或强轧空；用于确认 b 的那个 N 只完成交替确认，不可同时作为该交替后的买入 N。必须等交替已确认后再出现新的合格正 N。

在 N 攻击日固定所属类别，交替许可必须在该日之前已确认，不能用后来的轧空确认追认旧 N：此前尚未完成收盘突破 H0，则按第一类检查；N 攻击当天突破 H0 仍属于第一类。等待抵抗/轧空确认期间刚好突破 H0，不会把这个既有候选误删；结构已经失效则仍拒绝。

所有 V3 方案的正 N 突破棒另有不可关闭的质量门槛：成交量严格大于前一交易日，收盘高于开盘，阳线实体至少占开盘价 2% 且至少占当日最高最低振幅 50%（等于门槛允许）。该门槛与可选的 20 日相对量能过滤不同；关闭后者不会放宽突破棒。纯几何 N 与非 V3 策略不受此门槛影响。

## 第二类：完全多头后的浅回撤正 N 轧空（优先）

1. 空多交替后，后续某日收盘大于 H0，确认完整多头；仅上影越过不算收盘突破。
2. 再上涨至已知最高 H1，随后回撤形成 N 低点，再出现新正 N 攻击。
3. 时序必须为：交替确认 < 收盘突破 H0 ≤ H1 < N 回撤低点 < N 攻击 ≤ 轧空确认。
4. `r2 = max(0, H1 - Cmin) / (H1 - L0)`。
5. 选择 `r2 ≤ 1/3` 或 `r2 ≤ 1/2`，等于上限允许。
6. 正 N 后确认轧空或强轧空。若同时有多级候选，优先第二类，再优先较高趋势级别。

r2 不使用局部 N 波幅作分母，不用最低价替代收盘价；但最低价跌破 L0 仍是独立结构失效条件。最低收盘覆盖 H1 当棒和整个等待确认期间，防止用后来收盘恢复掩盖曾经超限。将 H1 当棒收盘纳入是日线无法获知盘中顺序时的保守约定。

## 默认方案与四组深回撤对照

| 策略 ID                  | 第一类深回撤                             | 第二类收盘回撤上限 |
| ------------------------ | ---------------------------------------- | ------------------ |
| lecture_v3（默认）       | 二/三级交替后正 N 轧空；无附加深回撤门槛 | ≤ 1/3              |
| lecture_v3_d67_c33       | 交替低点 > 2/3                           | ≤ 1/3              |
| lecture_v3_d50_c50       | 交替低点 > 1/2                           | ≤ 1/2              |
| lecture_v3_d67_c50       | 交替低点 > 2/3                           | ≤ 1/2              |
| lecture_v3_close_d50_c50 | H0 至 A 期间最低收盘价 > 1/2             | < 1/2              |

收盘对照方案第一类 `r1_close = (H0 - min(Close[H0日..A日])) / (H0 - L0)`，严格大于 1/2；它在交替低点确认时冻结第一段收盘区间，不把后续收盘下跌倒灌进第一类。第二类仍使用上述 `r2` 的 H1 至信号确认日最低收盘价，但严格小于 1/2；两类恰等于 1/2 都不通过。跌破 L0 的结构失效条件和其他过滤保持不变。四组显式深回撤对照保留各自幅度门槛；所有 V3 方案均使用图表统一交替证据。全部第一类限定二级或三级。

门槛使用精确分数比较，避免浮点数使“刚好 1/3”误判。不同方案进入策略配置、信号/成交缓存键和选股上下文，不能互相混用旧结果。

满足上述结构、强制突破棒质量、可选相对量能开关和有效止损/目标条件后，V3 在轧空确认日触发 LONG 买点，不再用收盘毛盈亏比预筛选隐藏该买点。当前股票回测新增“启用次开盘含费净盈亏比过滤”选项，默认关闭；勾选时才按策略最低净盈亏比（通常 1.5）拦截下一开盘买单。关闭只跳过比例不足这一项，仍计算含费收益风险并保留仓位、目标耗尽、止损和成交约束；LONG 不等于成交，未通过执行条件时保留信号及拒单原因。

讲义折线 N 的起点取该 K 线的终端低点（倒 N 为高点），起点 K 的另一端影线属于前一段，不参与后续 A-B 颈线极值校验；起点之后的 K 线仍严格校验。旧严格折线/分形口径不改变。旧版瑞凌股份 2026 年案例曾以 7 月 27 日 N、8 月 4 日轧空同时确认交替和买点；现在该 N 若用于确认交替，只保留确认，不得形成买点，须等后续合格 N。

瑞凌股份 2019-10-14 几何正 N 突破棒成交量 2,832,300 股，低于前一交易日 2019-10-11 的 3,231,602 股；复权等价开盘 6.202267、收盘 6.266987，阳线实体仅约占开盘价 1.04%。两项均未达标，因此不进入 V3 `n_completed` 和交替确认链，2019-10-16 不再据此生成第一类买点，2019-10-17 不再有相应买单。

## 三级交替证据与价格口径

瑞凌股份的 2018 起点复权等价价：2024-02-06 低点 4.836290 → 2025-03-20 高点 16.798013 → 2026-07-21 低点 8.995086，回撤 65.232469%，满足严格小于 2/3。按页面舍入值 4.84、16.8、9 计算为 65.217391%。不得与不复权 3.99、13.35、6.85 混算。

三级正式 H→L→H 中，L 的已确认空翻多证据与后续 H 对前一三级 H 的严格突破，可建立同级翻多，不再额外等待两个正式低点。确认三级 H 的二级回档低点可作为三级交替证据，保留 `source_level=2`，不伪造正式三级顶点。图表和默认策略共用该地标，结构筛选沿用同一输出。

旧正式高点/回档链到 2026-08-26 才完整可知。新增正 N 轧空路径允许使用当时已确认的源级 a 端点，而不等待 a 高点升级成正式三级顶点。旧版瑞凌 7 月 21 日 b 低点曾由 8 月 4 日正 N 在 8 月 7 日轧空时确认；新规则须先检查突破棒强制质量，即使确认交替，也不能用同一 N 入场。图标仍定位原 b 低点，确认日期不能倒填。

## 正 N 轧空确认空多交替（所有 V3 方案）

保留原有确认路径，新增二级、三级路径：a 起点为正式低点，a 高点至少为当时已确认的源级端点，且已严格突破该低点之前的同级末跌高。发展端点不冒充正式同级顶点；仅使用 N 攻击日历史截面的证据，同一起点选择最新 a 高点。

b 保持高于 a 起点，并满足以下任一条件：

- `b 最低价 ≥ a 高点 − (a 高点 − a 起点) × 2/3`。
- `b 时间 > a 时间`，且 `b 最低收盘价 < a 高点 − (a 高点 − a 起点) / 2`。这两个比较均不含等于。

随后出现合格正 N，轧空或强轧空确认时发布 `squeeze_alternation_confirmed`，将 b 标为已确认的空多交替低点。确认 N 仅完成交替确认，不能借用新许可入场；后续另一正 N 才可使用。时间仍按交易 K 线索引之差，b 截止首次最低价；收盘区间不包含 a 高点当天。

若尚未收盘严格突破 a 高点，最低价先严格跌破 b，发布 `squeeze_alternation_invalidated`，撤销对应入场许可，图标显示“已失效”。触及 b 不算跌破。收盘先严格突破 a，则发布 `squeeze_alternation_breakout`，之后不再按这条“突破前先破 b”条件判失效。原整段起点失守及交易风控仍生效。N 攻击后、轧空确认前发生的收盘突破也会保留，避免漏记突破后误判失效；同日上下同时穿越而无法确定先后时按失效处理。

确认、突破、失效是分别带日期的历史事实，后续失效不删除原确认，不回改过去成交。图表和策略使用同一份事件；正式趋势顶点继续按原递推规则绘制。

## 三级 a/b/c 结构候选

a 为服务端已确认的三级空翻多整段 `L0 → H0`，b 为 H0 之后的回调。在新正 N 的攻击前，使用 H0 后至该 N 回档点期间的首次最低价作为 b 端点；不能把等待 N 或等待轧空确认的时间算进 b。时间以交易 K 线索引之差计量，a 为 `H0.index − L0.index`，b 为 `B.index − H0.index`。

以下两条条件取 **或**（第二条按用户最终更正采用严格小于）：

1. b 最低价 `≥ H0 − (H0 − L0) × 2/3`，等于允许。
2. b 时间 `> a 时间`，且 b 最低收盘价 `< H0 − (H0 − L0) × 1/2`；时间相等或收盘恰等于半幅均不通过。最低收盘统计 H0 **之后**至 b 低点当日的全部 K 线，不用最终收盘替代期间最低收盘，不用 a 高点当日的收盘制造 b 证据。

仍须保持 b 低点高于 a 起点，a 锚点在 N 攻击时已知，之后新正 N 获得轧空、强轧空或已确认轧空回压恢复。此时发布 `tertiary_c_candidate`，表示 b 可能结束、c 可能启动。此后的收盘严格突破 a 高点单独发布 `tertiary_c_breakout`；最低价跌破该候选的 b 低点发布 `tertiary_c_invalidated`。同日既破 b 又收上 a 的 OHLC 歧义先按候选失效处理；等于 a 高点及仅上影突破均不算收盘突破。

这组 c 段事件保留为结构观察。新增空多交替路径另以同源 `squeeze_alternation_*` 事件接入交替地标和 V3 许可；c 候选、LONG 和实际成交仍分别表达。回放按各事件的可用日期呈现，不把未来突破或失效结论写进历史启动候选。Web“三级 a/b/c 观察”图层可开关，点击标记可查看 a/b 锚点、三分与半幅参考价、耗时、正 N 日期及盘态确认。

## 二吐完成后的转浪目标

所有 V3 方案在合格正 N 已确认轧空或强轧空、价格满足二吐且持续守住该 N 的轧空低时，启动转浪观察。每个目标绑定原 N 的攻击日期，其他 N 不覆盖它的锚点。二吐完成称为“三合一”的测幅条件；不据此自动认定五波推动，也不声称已识别九浪、十三浪或第五浪延伸。1.618、2.618 是原文的波浪解释，不新增为固定入场门槛。

按用户确认的命名区分两条路径：

- **叠箱五顶**：二吐后不回继续上涨。设 N 起点为 `L0`，突破棒虚拟高点为 `X`，原 N 幅度 `H = X − L0`，二吐 `T2 = L0 + 3H`。二吐后的交易日收盘严格超过此前最高价，五顶目标为 `X + 5H`，等价于 `T2 + 3H`。原 N 幅度保持冻结。
- **堆箱五顶**：二吐后回调守住轧空低再攻击，目标为 `B低 + 3H`。B 低只取回调开始时已知最高价所在交易日之后的最低价；不能拿同棒低点或后续尚未确认的低点计算。
- **五顶满足后才推演十满**：以当时已观察到的五顶段高点 `F` 和原起涨点 `L0` 放大箱高 `G = F − L0`。直接续涨的叠箱十满为 `F + G`；回调后再攻击的堆箱十满为 `新B低 + G`。`F` 使用当时实际观察到的高点，允许高于原五顶目标；开始回调时重新冻结当时已知的该段最高价，不用未来最终高点。十满满足后按同样放大方法记录后续延伸目标。

日线执行口径是明确的工程约定：收盘低于前收盘视为回调开始，并暂停之前的活跃目标；B 低至少已在前一交易日出现，当前最低价不低于前日低点、阳线收盘严格突破前日高点，才视为局部再攻击。它是日线代理条件，不冒充已提供微浪数据。后续再次出现回调，则重新冻结当时可知的 A 高和后续 B 低；此前目标保留在历史事件中，但不继续作为活跃目标。

触及目标算满足；触及轧空低仍算守住，最低价严格跌破才失效。失效后同一 N 不复活。若同日既破位又到目标，失效优先；若同日回调且上影达到旧目标，按暂停处理，不推断高低发生先后。A 高当天的低点不能当作其后的 B 低。新目标在收盘确认后才成立，该棒只能用收盘判定是否已满足，不能用此前上影补记命中；已经提前公布的目标才允许用后续最高价判定。大幅跳空只确认已公布的阶段，再根据当前已知高点放大下一阶段，不能一次补记此前从未发布的十满或延伸目标。

`wave_projection_ready / stack / pullback / push / target_reached / invalidated` 审计事件记录可用日期、原 N、状态、A/B 锚点、固定箱高、轧空低和目标。`projection_label` 分别显示叠箱、堆箱、等待或失效。推演持续到轧空低失守，不受原入场候选 TTL 到期截断；历史回放仅能看见当时已确认的事件。

点击原 N 字标记时，一并展示该 N 的五顶、十满目标及其叠箱/堆箱路径，标明“已满足、推演中、回调暂停、已失效”和各自可用日期。已满足的五顶保留，暂停的十满仍作为历史参考显示，不冒充活跃目标。目标线从各自生效日开始，不能从原 N 日期倒画；选择 N 时价格轴覆盖远端目标，取消或关闭参考线后恢复。

入场仍优先采用尚未满足的等浪、一饱、二吐，耗尽后保留原有最近一层转浪目标；远端五顶/十满用作结构推演，不替换较近目标以抬高盈亏比。原交替、突破棒、轧空、量能和执行风控仍须满足，同一 N 不重复发出 LONG，不自动加仓。

V3 全部方案设置 `exit_on_target=false`：等浪、一饱、二吐、五顶、十满是测幅与推演节点，单纯触及目标不生成卖单。二吐满足后继续按当时可知结构观察叠箱/堆箱，不能把尚未形成的后续目标当作持仓条件。逆 N、末升低收盘破位、结构未定等策略 EXIT、结构止损、尾盘分批减仓、弱反弹清仓和最长持仓风控继续有效；卖出仍须保存对应决定依据。目标继续参与入场费用后盈亏比和开盘目标耗尽检查，关闭目标清仓不改变这些门槛。默认执行及 V1/V2 保留目标到达次开盘退出；V3 配置升级为 v10 以隔离缓存。

验证：`tests/test_wave_projection.py` 覆盖叠箱、堆箱、等值边界、同棒歧义、失效不可复活、大幅跳空、超过候选 TTL 后继续推演与逐日前缀一致性。

## 页面操作与准确率

### 首次破位减仓与弱反弹退出

V3 各方案启用 `staged_exit_enabled` 和 `staged_exit_intraday`。持仓期间使用当日之前已确认的最近局部回踩 K（最低价严格低于左右相邻 K），其后须有高点高于参照 K 的最高价。14:30 至 15:00 的已完成五分钟线若显示当日累计最低价严格跌破参照低点、最新五分钟收盘价未跌破参照收盘，目标累计减仓 35%；两者分别严格跌破时，目标累计减仓 65%。比例均相对于首次减仓前该股票的持仓。已经卖出 35% 后，只补至 65%，不会再卖余仓的 65%。

**五分钟回测成交口径**：在线日线、五分钟线及复权因子固定使用 AKShare / 新浪，周、月等周期由同源日线聚合。通达信模式只使用本地日线、除权表和原生 lc5 分钟文件，不再混入 BaoStock。原始五分钟线须通过完整 48 个时段、日线 OHLC 和总成交量校验，成交计算统一使用当日复权因子。14:30 后已完成五分钟线触发减仓，以后一根五分钟线开盘价加滑点、费用模拟成交（`intraday_5m_next_open`）。V3 启用 `missing_minute_daily_fallback`：当日缺少完整同源分钟线时，使用当日最终日线低点、收盘判断 35%/65% 减仓，以当日收盘加滑点和费用撮合；记录 `same_day_close`、`minute_fallback` 和回退日期。其他日期仍优先五分钟；OHLCV 矛盾等损坏数据继续报错。入场和其他日线退出仍用次开盘；T+1、整手和流动性约束继续有效。

`support_break_reduction` 与 `closing_reduction_intent` 共享 35% / 65% 判定，后者只接受带时区的尾盘观察。2026-09-20 实测瑞凌完整分钟历史为 2026-07-24 至 09-18；按用户授权启用逐日日线回退后，2018-01-02 至 2026-09-07 全区间回测完成，9 个日期采用日线判断。回退不改变原始行情来源，不伪造分钟时间。真实券商通道未接入。

冻结回踩 K 后至破位日前最高价 H 与破位日最低价 L，反弹门槛为 `L + (H − L) × 2/3`。后续按最高价判断，严格突破则取消本次弱反弹清仓；相等不算突破。未突破且已出现反弹后，收盘再破 L 则清余仓。原有止损等风险退出继续有效。

已核验瑞凌股份 `lecture_v3`、关闭量能过滤、2018-01-01 起算：2025-05-15 比较 05-09 形成双破位，14:30 五分钟收线可知目标 65%，下一五分钟线开盘原始价 9.97 元，加 5 bps 滑点后模拟原始成交价约 9.965015 元。示例账户 9000 原始股按整手卖出 5800 股，实际平仓比例 64.44%，余 3200 股。05-16 高点 12.985430 超过完整精度门槛 12.964459，不触发弱反弹清仓；05-23 原有止损只清余仓。实际数量会随此前成交与配置改变，不能硬编码股票或日期。

卖出节点、详情及“复制信息”显示实际平仓比例：`本次卖出数量 /（本次卖出数量 + 成交后剩余数量）`，分母是卖出前该股票持仓；清余仓显示 100%，数据缺失显示不可计算。目标累计比例单独说明，避免把整手取整后的成交写成精确 65%。分批卖出分摊入场费、保留同一交易链 ID，`position_closed` 标识是否全部清仓。

在“策略 / 幅度方案”中选择一组后，当前股票回测和买点扫描都使用该方案。点击“对比五组幅度”，在相同股票、起止日期、成本场景下逐组调用同一个回测引擎，完成一组即展示一行。点击该行“查看 B/S”加载对应账本；点击买入标记可复核 L0、H0/H1、回撤低点/最低收盘、比例和门槛。

对比展示：买点数、买入成交数、已平仓数、扣费胜率、账户净收益、最大回撤。

- 本界面的“准确率”特指 **扣费后盈利的已平仓交易数 / 已平仓交易数**，不是分类模型准确率或全部买点未来上涨概率。
- 未平仓不进入胜率；零平仓显示“无平仓样本”，不是 0%。盈亏为零不算盈利。
- 净收益和回撤包含未平仓估值，不能和只统计平仓的胜率混为一谈。
- 计算错误单独显示，不伪装成零样本。取消只停止继续调度；已在服务端开始的单股计算可能仍完成并缓存。
- 切换股票、日期、成本或数据来源清除旧对比；只切换五组之一可保留同截面比较表。

当前功能是逐股、样本内的五方案比较，不是全市场组合优化、自动选优或样本外有效性证明。不同参数可能产生完全相同的信号，这只说明该股票/区间没有落在相应边界之间的候选，不代表参数未生效。

### 首次减仓后的倒 N（V12）

V3 已实际执行支撑减仓（35% 或 65%）后，独立的已确认倒 N 信号将累计减仓补至首次减仓前持仓的 90%，按确认日后的可交易次开盘撮合。计算卖出量为 `原持仓 × 90% − 已卖出量`，按当日复权因子换算整手，故余仓可能略高于 10%。重复倒 N 不再重复卖出；未发生支撑减仓时，保持原倒 N 退出行为。结构止损、期限、其他退出及组合风险信号仍可清仓，不受保留一成限制。

V13 修正确认当日漏报：C 的源 K 线在过去、B 此前已知时，允许在确认 C 的当天收盘识别首次双破倒 N。此前强制从 C 确认后的下一棒检查，会把真实首次破位跳过，再因已在颈线下方而永远漏报。正 N 入场和旧版默认时序保持原口径。
