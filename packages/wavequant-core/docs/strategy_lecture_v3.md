# V3：整段幅度双买点与四组方案对比

本版本实现用户最新定义，旧 V2 保留作历史对照。不改变底层折线和一、二、三级趋势线画法。一级及以上任一已确认趋势结构可提供买点背景，不要求三级同时满足。这里只定义研究规则，不把价格形态解释为可验证的主力意图。

## 锚点与时序

- L0：翻空为多对应下跌段的最低点，即整个翻多上涨段的起点，不是局部 N 字前一低点。
- H0：翻空为多这一波的高点。
- A：随后已确认的空多交替低点。
- H1：空多交替之后，收盘突破 H0，再上涨形成的最高点；只能使用 N 攻击之前已观察到的最高价，不能使用未来最终最高点。
- Cmin：H1 所在 K 棒至当前信号确认日之间的最低收盘价。

折线极值发生时间和被确认时间分开记录。必须在 N 攻击前已经确认翻空为多、空多交替，不能事后把买点标回尚未确认的日期。

## 第一类：深回撤后的正 N 轧空

1. 已完成翻空为多、空多交替。
2. 整个 L0 起点至信号确认期间，实际最低价不得小于 L0；触及等于 L0 允许。
3. 回撤比例 `r1 = (H0 - A) / (H0 - L0)`。
4. 选择 `r1 > 1/2` 或 `r1 > 2/3`，严格大于，等于门槛不通过。第一类不再被旧规则的“小于 2/3”约束。
5. 之后出现新的正 N，并确认轧空或强轧空。

在 N 攻击日固定所属类别：此前尚未完成收盘突破 H0，则按第一类检查；N 攻击当天突破 H0 仍属于第一类。等待抵抗/轧空确认期间刚好突破 H0，不会把这个既有候选误删；结构已经失效则仍拒绝。

## 第二类：完全多头后的浅回撤正 N 轧空（优先）

1. 空多交替后，后续某日收盘大于 H0，确认完整多头；仅上影越过不算收盘突破。
2. 再上涨至已知最高 H1，随后回撤形成 N 低点，再出现新正 N 攻击。
3. 时序必须为：交替确认 < 收盘突破 H0 ≤ H1 < N 回撤低点 < N 攻击 ≤ 轧空确认。
4. `r2 = max(0, H1 - Cmin) / (H1 - L0)`。
5. 选择 `r2 ≤ 1/3` 或 `r2 ≤ 1/2`，等于上限允许。
6. 正 N 后确认轧空或强轧空。若同时有多级候选，优先第二类，再优先较高趋势级别。

r2 不使用局部 N 波幅作分母，不用最低价替代收盘价；但最低价跌破 L0 仍是独立结构失效条件。最低收盘覆盖 H1 当棒和整个等待确认期间，防止用后来收盘恢复掩盖曾经超限。将 H1 当棒收盘纳入是日线无法获知盘中顺序时的保守约定。

## 四组可选方案

| 策略 ID            | 第一类深回撤 | 第二类收盘回撤上限 |
| ------------------ | ------------ | ------------------ |
| lecture_v3（默认） | > 1/2        | ≤ 1/3              |
| lecture_v3_d67_c33 | > 2/3        | ≤ 1/3              |
| lecture_v3_d50_c50 | > 1/2        | ≤ 1/2              |
| lecture_v3_d67_c50 | > 2/3        | ≤ 1/2              |

门槛使用精确分数比较，避免浮点数使“刚好 1/3”误判。不同方案进入策略配置、信号/成交缓存键和选股上下文，不能互相混用旧结果。

这两类只是入场结构条件，既有量能、盈亏比、仓位、成交约束仍保留（V3 继承量比 1.2、最低预期盈亏比 1.5）。所以形态通过不等于一定发出 LONG，LONG 也不等于一定成交。原退出逻辑保留。

## 页面操作与准确率

在“策略 / 幅度方案”中选择一组后，当前股票回测和买点扫描都使用该方案。点击“对比四组幅度”，在相同股票、起止日期、成本场景下逐组调用同一个回测引擎，完成一组即展示一行。点击该行“查看 B/S”加载对应账本；点击买入标记可复核 L0、H0/H1、回撤低点/最低收盘、比例和门槛。

对比展示：买点数、买入成交数、已平仓数、扣费胜率、账户净收益、最大回撤。

- 本界面的“准确率”特指 **扣费后盈利的已平仓交易数 / 已平仓交易数**，不是分类模型准确率或全部买点未来上涨概率。
- 未平仓不进入胜率；零平仓显示“无平仓样本”，不是 0%。盈亏为零不算盈利。
- 净收益和回撤包含未平仓估值，不能和只统计平仓的胜率混为一谈。
- 计算错误单独显示，不伪装成零样本。取消只停止继续调度；已在服务端开始的单股计算可能仍完成并缓存。
- 切换股票、日期、成本或数据来源清除旧对比；只切换四组之一可保留同截面比较表。

当前功能是逐股、样本内的四方案比较，不是全市场组合优化、自动选优或样本外有效性证明。不同参数可能产生完全相同的信号，这只说明该股票/区间没有落在相应边界之间的候选，不代表参数未生效。

## 验证入口

- `tests/test_whole_wave_entry.py`：比例、边界、整体锚点、时序、确认等待、因果前缀与参数隔离。
- `web/tests/ratio-comparison.test.mjs`：方案枚举、统计口径、上下文隔离。
- `web/tests/ratio-comparison.e2e.cjs`：真实通达信回测、四组结果、账本复盘、上下文清理、取消、失败状态。
- `scripts/validate_whole_wave.py --output <新的报告目录>`：固定此前已使用的 11 股票 × 4 方案，2018-01-01 至 2026-09-07；逐笔重算公式，检查前缀一致性并保留完整账本。

11 股票是工程回归样本，合并平仓胜率只是独立账户交易描述，不是投资组合收益，不代表全市场或未见样本表现。商业化或实盘前仍需要独立样本、滚动样本外验证、样本量与成本/容量压力检查。
