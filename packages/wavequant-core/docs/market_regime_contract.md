# 六大盘态：N 字后的抵抗与延续

依据用户提供的六态文字、配图，以及既有突破／跌破和 N 形定义。对应实现 `wavequant/domain/market_state/market_regime.py`，规则版本 `six_regimes_v1_close_record_defense_breach`。

这是可复现的**形态研究口径**，不是讲义已经证明的交易规律。特别是“抵抗成功”、延续确认和强势防守的数值判据，是本项目明确选择的工程解释；不能把识别六态等同于证明收益或识别真实主力意图。

## 1. 分层与时间

`price_action` 提供突破／跌破及抵抗证据 → `n_shape` 完成正／倒 N 并冻结防守位 → `market_regime` 观察抵抗结果和六态。量能与买卖条件在更上层，不倒过来修改基础形态。

这里的“笔”指传入周期内一根已经收盘的 K 棒，不是自动识别的波段笔。日线次笔是该股票下一根可用日线，不是次一自然日；停牌、缺失记录和周期一致性由上游校验。

| 时间          | 可以得出的信息                              | 不可以提前得出的信息             |
| ------------- | ------------------------------------------- | -------------------------------- |
| 当笔 t        | 已确认 A/B/C 之后完成 N；冻结轧空低／杀多高 | 次笔有无抵抗、六态结论           |
| 次笔 t+1      | 列出的抵抗形态、局部防守是否失守            | 六态确认，即使当日已经新高／新低 |
| 第三笔 t+2 起 | 根据已有抵抗与收盘延续证据确认六态          | 强行要求第三笔一定给出结论       |
| 后续笔        | 继续等待，或产生新的确认／失效事件          | 回写早期 K 线为已确认            |

盘坚／盘跌图中的回调／反弹可能持续多根 K 棒，因此没有固定三棒截止期限，也不自动凭第 N 天仍未确认宣告失败。

## 2. 冻结价位与严格比较

- 正 N 防守 D：完成棒虚拟低点 `min(L[t], C[t-1])`，即轧空低。
- 倒 N 防守 D：完成棒虚拟高点 `max(H[t], C[t-1])`，即杀多高。
- 波段边界 W：调用者必须选择 N 起点 A（`WaveBoundary.ORIGIN`）或 N 回调／反弹点 C（`PULLBACK`）。不是事后从两个价位中挑一个能让结果好看的值。
- 正向延续：当棒**收盘严格大于从 t 到前棒的所有最高价**。
- 反向延续：当棒**收盘严格小于从 t 到前棒的所有最低价**。
- 防守失守：正向 L < D，反向 H > D。波段边界同样用极值判断。相等是触及，仍算守住。
- 强势滚动防守：每棒比较其 L／H 与**前棒的虚拟低／高**；并要求从 t 起逐棒收盘严格同向推进。

延续使用“收盘过历史极值”，比仅用盘中创新高／新低更严格。该规则固定，不与较宽松的规则混报测试结果。它不要求当前棒完全无上下影，也没有凭空规定跳空幅度或长实体比例。

N 字的双锚点实／虚完成口径不变；这里更严格的收盘新纪录仅用于 N **完成后**的盘态确认。

## 3. 抵抗出现与抵抗结果

直接复用 `price_action.observe_resistance` 的列举形态：正向看开高收黑、直接开低、长上影；反向看开低收红、直接开高、长下影。基础层的严格开盘比较和原始证据字段原样保留，不引入第二套不一致的抵抗识别器。

长影比例必须显式配置 `ShadowPolicy`，或传 `None` 保留未知。示例使用 0.5 只为演示，不是讲义给定值，也不是推荐参数。

- `detected=True`：至少一种抵抗证据明确出现。
- `detected=False`：在当前政策下未识别出列举形态；不代表市场上绝对没有对手盘。
- `detected=None`：非零影线未配置“长”的阈值，不能确定。
- 抵抗失败：此前已有抵抗，整个事件尚未破 D，后来收盘确认同向新纪录。
- 抵抗局部成功：已有抵抗且 D 被攻破，但 W 始终未破。此时只记局部成功；尚需之后的延续，才确认盘坚／盘跌。

将“攻破 N 防守”作为局部成功的分界，是为了让普通与盘整类盘态互斥。讲义没有完整规定这个分界：小幅回调也可能被主观分析者称为抵抗成功。本实现不会因此直接把它叫盘坚，而是在 D 未破的情况下，延续后归入轧空。未来若采用“收盘跌回颈线”等另一种口径，应新增版本并独立比较，不能悄悄改规则。

如果整个事件没有已知抵抗，但出现未知影线，则不能确认强态。已明确观察到抵抗之后，其他棒存在未知影线不妨碍用防守与延续证据确认普通／盘整态。

## 4. 六态的可执行判据

以下条件均要求 W 从未失守、当前至少是第三笔、当前收盘确认同向新纪录。

| 盘态   | 抵抗证据                     | 防守与路径要求                                 |
| ------ | ---------------------------- | ---------------------------------------------- |
| 强轧空 | t+1 至当前全部明确未检出抵抗 | D 未破；逐棒收盘上涨；逐棒守住前棒虚拟低点     |
| 轧空   | 当前之前已出现空头抵抗       | D 始终未破；当前向上延续，抵抗失败             |
| 盘坚   | 当前之前已出现空头抵抗       | D 在当前之前曾被跌破；W 始终守住；当前向上延续 |
| 强追杀 | t+1 至当前全部明确未检出抵抗 | D 未破；逐棒收盘下跌；逐棒守住前棒虚拟高点     |
| 追杀   | 当前之前已出现多头抵抗       | D 始终未破；当前向下延续，抵抗失败             |
| 盘跌   | 当前之前已出现多头抵抗       | D 在当前之前曾被突破；W 始终守住；当前向下延续 |

“该回不回／该弹不弹”在代码中拆为未检出抵抗、连续推进、滚动虚拟防守三个可查条件；单凭没有抵抗并不足以确认强态。跳空长红／长黑是讲义中的常见表现，不作为必备条件。80%／20% 未经样本验证，不写入概率或买卖评分。

原文追杀中的“持续出现上涨”与上下文及配图冲突，按“持续出现下跌”处理。代码采用完全镜像的多空判据，不利用文字笔误制造反向交易条件。

## 5. 待定、失效和路径歧义

- 没有完成 N：不生成六态事件；返回 N 层自身状态，未知拐点价位不泄露。
- 只有抵抗、没有收盘延续：待定，不等同于失败或成功的最终盘态。
- 没有抵抗，但路径不连续或滚动虚拟防守失守：待定，不硬归强态或普通态。
- 首次抵抗与收盘延续在同一棒：等待后棒，不凭日线推断抵抗先后。
- D 首次失守与收盘新纪录在同一棒：可记录局部失守，但盘整态等后棒重新确认。
- W 失守与新纪录在同一棒：优先结构失效，不猜测盘中先后。
- W 一旦失守，这个 N 事件保持失效，即使随后恢复也不复活。只有另一个独立、已知的 N setup 才能启动新事件。
- 正 N 失效不自动等于倒 N 完成，也不自动产生空方三态；反之亦然。

一个事件中一旦出现过抵抗、非连续推进或相关防守失守，就不再“抹掉过程”恢复为强态。可能的确认序列是强轧空 → 轧空 → 盘坚；中间往往有待定棒，最终也可能失效。新一轮强态需要新的 N 事件，而不是偷偷重置计数。

## 6. 调用与返回

```python
from wavequant.domain.market_state.market_regime import (
    RegimePolicy, WaveBoundary, observe_market_regime,
)
from wavequant.domain.market_structure.price_action import ShadowPolicy

# bars 是同股票、同周期、同复权口径的已收盘 Bar 序列。
# setup 是 n_shape.NSetup，包含来源和事先确认的 A/B/C 引用。
result = observe_market_regime(
    bars, setup, timeframe="1d",
    policy=RegimePolicy(
        shadow_policy=ShadowPolicy(0.5),  # 显式实验值，不是推荐阈值
        wave_boundary=WaveBoundary.ORIGIN,
    ),
    asof_index=len(bars)-1,
)
current = result.latest  # N 尚未完成时为 None
```

`result.frames` 为从完成 N 当笔开始的不可变逐棒快照。每棒包含时间、阶段、本棒确认的 `regime`、完整抵抗证据、抵抗结果、首次抵抗／失守时间、续攻阈值、滚动虚拟防守、最近确认的盘态与时间。

`regime=None` 不等于无趋势：它表示**本棒没有产生确认事件**。`last_confirmed_regime` 仅是历史事实，不是无条件维持的当前有效状态；使用方必须同时检查 `phase` 和确认时间。失效后的后续帧仍返回价格事实，但不再产生本事件的盘态确认。

只验证和读取 `asof_index` 及之前的数据。完整输入按 asof 查询的结果，与实际截断输入完全一致；新增未来数据不修改过去 `frames`。函数一次扫描可见前缀；如需整段历史应一次取 `frames`，不要对每一天重复全量计算。

运行独立六态演示：

```powershell

.venv\Scripts\python.exe -m unittest discover -s tests -p test_market_regime.py -v
```

## 7. 接入范围与验收边界

测试覆盖六态镜像、至少三笔、多棒回调、状态迁移、未知影线、严格相等、跳空虚拟防守、波段边界选择、同棒冲突、失效不可复活、历史前缀不变、输入校验和无量能依赖。

本次是基础规则单元验证，不是通达信盈利回测。可消费现有通达信加载后的 `Bar`，但必须另由结构层提供因果确认的 N 拐点；模块不会从全样本事后挑选好看的波峰波谷。

旧 `foundations.three_bar_state`、已有策略与历史报告保持不变。旧 `foundation-audit` 仍核验旧代理，不能称作本模块的市场实测。未来迁移量能／买卖条件与全市场标注时，应显式消费本接口并另出报告，处理成交时点、T+1、涨跌停、费用等执行约束；收盘才知道的盘态不能假定在同一收盘价必然成交。
