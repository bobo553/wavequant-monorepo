# 2026-10-15 补充：实体跳空独立确认

普通/特殊空翻多之后，回撤守住起涨低点且最低点已由当时折线确认，可以通过下列同时成立的条件结束空多交替：当日开盘严格高于前日实体上沿；成交量严格大于前日且前日成交量为正；阳线实体至少为开盘价的 2%，并至少占当日高低振幅一半；收盘严格突破回撤低点至昨日的最高价。短浅回撤仍需原时间/高点突破约束。只比较实体跳空，允许影线重叠；无需等待未来 N 成立，且不会生成一个虚构 N。

低点发生日和实际确认日分别记录，资格只从确认日生效；折线和一二三级调用同一确认函数，来源修订仍撤回。普通新确认接入现有买点上下文，确认本身不等于买入成交。生命周期版本为 `six_state_body_gap_alternation_v8`，交易历史版本为 `body_gap_alternation_confirmation_v127`。以下旧版说明保留为历史记录。

# 短暂跌破后再次空翻多

适用于折线（level=0）及一级、二级、三级。同级突破读取本级已确认点，N顶点读取当时已确认的折线点；收盘跌破天数读取同口径日线收盘价。不得混用原始价与复权价，不使用最终趋势图回填历史。

## 规则

1. 已有真正突破形成的空翻多，记录其原低点。仅有“底部疑虑”不能作为种子。普通空多交替已经完成的种子不再用于以后任意一次下跌。
2. 观察过程中，最低价严格低于原低点，暂停该路径的买入资格。允许连续收盘跌破0至3根：盘中跌破、当天收盘收回也成立；第四根收盘仍低于时，本次特殊观察作废。按实际交易日计数，不按日历天计数。仅触及原低点不触发。
3. 收盘严格收回原低点之上后，继续观察同级结构。反弹但收盘仍在原低点之下、收盘等于原低点，都不确认恢复。等于原低点会中断“连续低于”的计数，但不会确认恢复。审计记录首次盘中破位、收回日、连续收盘跌破根数及当日价格。
4. 收回之后，本级相邻的高点、低点、新高点形成严格突破：新高大于旧高，旧高在突破日之前已确认。新低点位于本次跌破之后。将此次突破确认为新的空翻多，以中间低点作为新的防守位。
5. 从新起涨低点至突破可知时，行情最低价不能已经跌破新防守位；后续仍须守住该位。守低只是必要条件，须再满足以下既有交替结束规则之一：已确认回撤严格小于上涨幅度的2/3；更深的较高回撤低点之后出现已确认高点重突破；折线正N成立并出现轧空、强轧空或符合既有恢复条件；正N防守未破且整理后出现符合既有规则的放量跳空突破。浅回撤同时满足既有时间限制：收盘回撤浅且B耗时不足A一半时，还要等待收盘突破A高点。N分支仍通过既有B段空间、时间、防守及突破条件，不以任意放量阳线替代确认。
6. 只有守低和上述确认同时成立才发布空多交替结束事件，随后接现有资格、折线N、B/S与账户链路。观察特殊交替的N在资格开放前计算结构证据，不产生订单，避免“有资格才能算N、算N才能有资格”的循环。图表结构起点是规则认定的回撤低点发生日；交易许可从确认当天开始，确认前不得补买点。是否买入仍由当前策略判断。

尚未完成交替时，同一腿的高点可以向右或向上延伸。只有原突破高点依据和新起涨低点完全不变、没有插入另一段回撤、且新高价格/位置/确认时间不倒退，才更新高点并保留特殊属性。基准低点、突破依据或原始种子被修订时仍撤销，不能用“高点延伸”掩盖不同结构。

已有资格之后的翻转低点破位退出规则继续生效，不因为本特殊规则给已有持仓或已关闭区间增加三天宽限。

## 代码入口与缓存

- `trend_lifecycle._upgrade_bull_fact`：将已发布的末跌高突破升级证据转为六态翻多事实；不能只读取用于展示的`observations`。起涨低点、被突破高点必须匹配本级真实点，并采用本级确认时钟。缺证据、价格不一致、只有文字标签或未来引用均不接受。同一高点的升级事实和展示注释去重，避免旧远端低点覆盖新起涨低点。
- `trend_lifecycle.advance_bull_recovery`：逐交易日推进连续收盘跌破与恢复计数。
- `TrendLifecycle._advance_bull_recovery`：同一实现接收各级自己的已确认点，判定再次突破及后续回撤，发布统一六态事件。
- `bull_alternation_confirmation.confirm_recovery_alternation`：守新低之后统一调用既有交替结束条件；N顶点严格取折线，目标和成立条件沿用原实现。资格尚未开放时只观察未完成的特殊周期，受策略结构窗口和N有效期限制。
- `recovery_entry_history.merge_recovery_entry_history`：将已发布确认事实适配到买点上下文，确认N可参与确认当天判断，来源失效及时撤销，不重新推算特殊规则。
- `trend_lifecycle._continued_bull_impulse`：保留同腿高点延伸的特殊状态，避免3月初突破发展到4月高点时退回普通交替。
- `TradingEligibility.observe`：消费同一事件，控制资格，不再计算第二套特殊形态。
- 检查点同时保存观察种子、跌破日、连续根数、收回日、新突破、回撤和N来源证据，以及折线首次可知时钟。生命周期版本升为`six_state_recovery_shared_alternation_v7`，交易历史版本升为`recovery_shared_alternation_confirmation_v126`并纳入确认参数；不续接旧规则检查点。来源证据被修订或路径关闭时撤销对应观察。

## 华北制药样例的预期解释

2018-07-26的原空翻多低点为2018-06-22的3.95。当前回测日线2018-10-19最低3.898401727861721、收盘4.05874730021593，属于0根收盘跌破的当日收回。用户已明确将此纳入规则。2019-01-04开始的同级突破持续发展到2019-04-11，突破依据为2018-11-22本级高点，新防守位为2019-01-04低点。随后2019-08-06回撤低点守住该位，应作为新资格区间的结构起点，而非2019-10-31或2019-12-31。

只读读取已有600812计算缓存，二级历史行145已保存2018-07-26高点（2018-08-07确认），行321已保存2019-04-11高点（2019-04-30确认），行427已保存2019-08-06低点（2019-10-09确认）。两处高点的`observations`为空，但`upgrade_evidence`包含方向、起涨低点、被突破高点和确认点。上一版只读`observations`，因此没有建立特殊观察种子，仍走到后面的普通交替。新适配入口修复这一来源遗漏，不放宽相邻点和突破时钟约束。

这些日期是旧规则产物的诊断证据，不写入算法。最新规则不再把2019-10-09的同级低点确认直接当作许可，也不预设2019-08-12或2019-08-19必然买入；必须以守低加既有规则的实际证据确定新确认日。已有N的成立规则保留。整理跳空分支仍要求当日最低价和开盘价均高于前日最高价，不能仅凭“高开”标签满足。
