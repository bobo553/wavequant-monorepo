# 新华文轩二级与三级趋势线（601811）

以 AkShare 日线、2018-01-02 至 2026-09-21、lecture_v3 回测为复现口径。原结果的一条连续二级正式线有 38 个点，另追加 11 条交替确认段。其中 2024-03-13 高点 17.7351 至 2026-06-29 低点 14.4642 的补充段跨越九个已有正式二级点，直接连线造成图上的长紫线覆盖。2022-08-30→10-11 等几条补充段又与原二级相邻边完全重复。

交替确认段现在只在同一条既有正式边中、价格和高低类型严格交替且确认日期不早于该边起点可知日时并入二级路径。若事件跨越已确认二级点，不额外叠画另一条二级边；同一对端点不重复绘制。新华文轩最终为一条有 48 个点的正式二级路径，五个新确认段按真实端点并入，长跨段被抑制。三级归纳使用这条图上显示的二级路径。

原三级归纳在 2020-03-30 识别下降方向时，把 2018-10-19 的首个全局最低点 8.3160 当作锚；首点没有前置高点，因此突破键始终为空，后续再多结构也不能确认三级点。遇到这一边界，归纳改从当时最近的已确认同类极值及其前置键开始。真实回测得到四段正式三级线：2019-03-13→2021-02-04、2021-04-20→2021-07-30、2022-01-10→2022-03-23、2022-08-30→2022-10-11。2023-05-05 高点 25.89 仍处于三级发展路径，不是正式三级顶点；发展路径保持虚线，并按可知日期展示。

回归覆盖真实二级点位与交替事件、严格交替及时间顺序、首次锚点没有键的情况、历史截面、原有西点药业三级确认与浏览器图层。截图或数据源不同截止日时应按所选截至日重算。

完整历史接口中的成交订单由原来的 103 条变为 107 条；新增的一笔 2025-07-07 买入及其后三笔卖出与恢复的三级结构同时出现。因此趋势线修正还需要按新结果复核历史回测成交，不能只按旧图层缓存判断。
