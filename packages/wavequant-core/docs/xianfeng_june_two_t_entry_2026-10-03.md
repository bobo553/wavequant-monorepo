# 先锋新材六月二饱入场核对

## 复现与目标来源

先锋新材 `sz.300163`，2026-06-09 开 6.58、高 7.30、低 6.54、收 6.94、成交量 78,682,213 股。

原正 N 起点为 2026-04-29 的 4.15，完成日 05-18、箱顶 5.20、箱高 1.05，二饱为 `5.20 + 2 × 1.05 = 7.30`。05-25 轧空确认时已经公布目标，因此 06-09 可以使用它。

旧 v83 正式 AkShare 单股回测中，06-09 仍生成 `system_mature_shallow_squeeze` LONG，并于当日收盘模拟 BUY/filled 300 股、6.94347 元。入场选择了 05-25 完成的较新 N，防守 5.64、一饱 8.62；原 N 的二饱约束没有覆盖这种新买点。请求参数为 V3/base、2018-01-01 起、量能过滤关、可选净盈亏比过滤关、浅回撤开、资金 100000、仓位上限 1。修正前的 06-09 正式历史前缀已保存核对。

## v84 入场规则

- 只使用当日已知的正 N 与轧空目标；形成目标的同一天只看已观察收盘，之后可按最高价识别触及。触及等值算到位，收盘必须严格大于二饱。
- 首次触及需要干净的强势阳线。沿用既有强 A 的实体标准：实体至少为开盘价的 3%，且占当根振幅至少 60%。还要求没有既有价格行为定义中的低开抵抗、高开收阴或长上影抵抗。
- 次笔未站上或出现抵抗，从次笔开始观望；不借次日行情回改首次决策。未确认突破前，后续再次触及旧目标仍需干净强势收盘。
- 远离旧二饱、整根 K 线在其下方的新波段不因旧目标永久禁买。原防守失效或突破确认后，旧目标退休。
- 门禁位于所有买入通道之前，覆盖 C 浪、新正 N、层级突破与独立浅回撤，也覆盖加仓。较新 N 的远目标不能取消原目标的抵抗。

06-09 的实体为 0.36、振幅为 0.76，实体占比约 47.37%，没有达到 60%；收盘 6.94 也低于二饱 7.30，因此当日直接观望，不需要等待 06-10 的阴线证据。其上影同样约占 47.37%，未达到原 50% 减仓阈值；新增入场确认与原减仓阈值分别生效。

## 退出与因果边界

06-10 原保护规则仍保留：首次二饱日上影严格超过 40%，次日收阴、低点和收盘双破，且量超过最近阴线参考，可对已有持仓当日清仓。即使没有新的 BUY，保护 EXIT 信号也允许存在；实际 SELL 以持仓为前提。
