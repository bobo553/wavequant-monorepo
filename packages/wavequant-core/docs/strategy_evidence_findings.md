## 下一阶段应做什么

1. 优先补历史 ST／停复牌／退市与当时股票池资料，以及严格折线所需真实次级行情。当前分钟目录为空，不能从日线推断高低点先后顺序。
2. 给真实行情中的突破、N、趋势交替、轧空事件做独立标注，先检验理论映射是否可靠，再解释收益。
3. RR=1.0 只能作为已看过历史后选出的观察候选。若开展新的独立未来验证，应在观察前冻结规则、股票池、成本与结束条件，完整记录该验证范围内的试验；不把此前未知的历史试验数硬填成 1。
4. 未来验证需积累有代表性的独立机会，并按预先声明的统计功效与经济价值要求判断。30 笔只是本轮排除极稀疏结果的门槛，不是达到后即可宣布有效。

本轮提升的是可检验性、失败定位与研究纪律。结果没有证明策略有效，也没有证明它永远无效；当前应保持未验证状态。
