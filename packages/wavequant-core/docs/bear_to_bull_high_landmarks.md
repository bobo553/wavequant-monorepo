# 空翻多确认高点

图上的“空翻多高点”不是当前窗口最高价，也不等同于随后升级形成的正式高点。它是某一级正式低点完成“翻空为多”确认时，确认链中实际突破该级冻结关键位的来源高点。

## 计算规则

1. 只消费一级的真实 `翻空为多` 观察事件，以及二级、三级已经确认的正式趋势点；发展中路径不产生地标。
2. 每个地标都必须同时具备确认低点、冻结末跌高和确认高点，而且确认高点必须严格高于冻结末跌高。价格相等只是触碰，低于关键位或证据缺失都不成立。
3. 一级不能用普通 `down -> up` 波向切换代替关键位突破，只读取 `_annotate` 生成并保存了冻结关键位的事件；二级、三级从正式低点的 `flip`、`broken_key` 和 `confirmed_by` 读取同一组证据。
4. `time` 表示高点发生日，`available_at` 取正式低点与确认高点两者可知日的较晚者。历史回放只能在 `available_at` 当日及以后显示。
5. 地标 ID 由趋势级别、高低点来源坐标和可用日构成，不依赖会随截面重建的 stroke 路径编号。

每个 `bear_to_bull_highs` 元素包含确认高点自身字段，以及：

- `trend_level`、`source_level`：当前趋势级别及其来源级别；
- `confirmed_low`：这次空翻多所确认的正式低点；
- `broken_key`：当时被冻结并被严格突破的末跌高；该字段不允许缺失；
- `source_path`：本次截面的诊断路径，仅用于追踪，不作为稳定业务 ID；
- `source_available_at`、`available_at`：来源高点可知日和完整确认链可知日。

## 展示边界

Web 只按当前图窗、回放截止日和启用的趋势级别筛选 Core 返回值，在高点价格处绘制 `Ⅰ/Ⅱ/Ⅲ 空翻多高点` 紧凑标识。独立开关只控制这些标识，不改变趋势线、末跌高、策略信号或回测结果。

中大力德的二级示例为 `2022-08-03 H70 49.56`：它确认 `2022-05-27 L9 13.16`，突破的一级冻结末跌高为 `2022-05-24 H69 18.28`，完整证据到 `2022-08-09` 才可知。因此 `2022-08-08` 回放不得显示，`2022-08-09` 起可以显示。该地标与 H70 后续在 `2023-02-06` 升级为正式二级高点是两个不同事件。
