# 未完成 C 浪的跨结构入场约束

适用范围：全局 V3 日线、加仓与 5 分钟入场回放。维护位置：`unfinished_c_wave.py`。版本：v72。行情验证：2026-10-01。

## 原因与规则

新 N 或更新后的 A/B 会生成新的 C 目标；此前缺少独立的旧 C 状态，新结构可能绕过尚未完成的旧压力。本规则冻结首次可知 C 的 A/B、0.618 和 1 倍目标，未买入的已确认 C 观察同样跟踪。

| 条件                                       | 后续买入与加仓                                                  |
| ------------------------------------------ | --------------------------------------------------------------- |
| 尚未触及旧 0.618                           | 本规则不拦截；其他入场规则仍执行                                |
| 已触及旧 0.618，未到旧 1 倍且未跌破 C 起点 | 所有 V3 通道禁买、禁加仓；新正 N、新 C 和更新目标不能覆盖旧压力 |
| 强势重新站上旧 0.618                       | 仍未完成旧 C，不单独解除禁买                                    |
| 实际最低价严格跌破 C 起点（冻结 B 低）     | 旧 C 周期结束，允许重新筛选新买点；等低不解除，也不自动买入     |
| 达到冻结的旧 1 倍目标                      | 旧 C 完成，允许重新筛选；仍须通过其他条件                       |

初次定义 C 的确认当天不把它当作自己的“上一笔 C”，但当天仍须检查其他旧 C。重复观察同一 A/B 不覆盖冻结值，也不复活已结束的旧周期。多个旧 C 独立跟踪，任一有效旧压力都可拦截；拒绝说明选择最近触及的有效旧 C，并按确认日期、目标、N 日期确定同日顺序。

确认当日仅使用收盘判断目标触及，后续使用已观察最高价。分钟回放只使用已完成分钟及此前日线，不借用最终日线高低、收盘或成交量。

## 两种后续发展

1. **只到 0.618 后走弱**：可能回落一个 A 幅度，持续禁买，直到实际跌破 C 起点。A 幅度只作风险参考，不是必跌预测，也不直接触发卖出。
2. **守住 C 起点继续向 1 倍发展**：按“触及 0.618 → 回撤且守 C 起点 → 重新上涨向 1 倍续推”记录三个阶段。日线收低于前收开始回撤观察；之后收高于前收记录续推，并持续跟踪回撤最低价。第二段上涨 0.618×A 的参考位为回撤低点加 0.618×A，旧 1 倍目标始终冻结。

用户没有给出回撤固定比例，因此不设置额外比例门槛。当前按达到旧 1 倍才结束第二种周期；中途强阳与第二段参考位都不直接产生买单。第二段参考与旧 1 倍可能不同，不能重算旧目标来制造“完成”。所有阶段与周期结束均有可知日期的审计事件及 Web 说明。

盘中买入确认的 C 额外保留其冻结 A/B，并向后续分钟回放传递；即使最终日线实体变弱，后续日线收盘买点也不能忘记这笔 C。确认之后剩余分钟的高低，只在当日行情完成后用于识别 C 的后续 1 倍到达或起点跌破，不倒灌到更早的盘中决定。已验证的较早分钟成交不按当日稍后的风险回溯取消。
