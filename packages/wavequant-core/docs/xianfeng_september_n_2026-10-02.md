# 先锋新材 2025-09-29 正 N 测幅核对

## 漏识别原因与修复

结构为 09-23 起点低 3.25 → 09-24 颈线高 3.43 → 09-26 回踩低 3.29 → 09-29 完成突破。09-26 是阳线外包前一根阴线，当天高 3.44 越过虚颈线，但收 3.39 尚未越过颈线 K 收 3.41。原算法把 C 棒回踩后的攻击高点计入 A/B/C 的颈线极值验证，提前拒绝结构。

修复仅在显式讲义外包约定、颈线此前已知、C 当天确认且实体方向与 N 一致时，把 C 棒的攻击极值归入后续攻击。仅虚突破当天保持形成中；09-29 同时满足实、虚突破才完成。逐根防守包含首次试探日，冻结为 3.29，箱顶仍取完成日 3.53。倒 N 按价格镜像采用相同规则；严格研究路径、十字星、相反实体、未来才确认的 C、中间更高颈线及失守 C 均保持拒绝。
