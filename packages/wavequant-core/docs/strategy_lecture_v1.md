# 当前策略：讲义因果版 V1

版本：`lecture_v1 / lecture_causal_squeeze_v1`。仅离线研究、只做多，不发送实盘委托。

本次重构解决的是“显示折线与策略结构来源分离、严格版遇所有包含线就重置”的问题。原来的虚线、母子连接及一二三级实线画法不改；新增收盘确认适配层，将同一个讲义递推器的可确认转折用于策略。旧严格版和日线代理版保留为独立对照，不覆盖旧实验，不借用旧实验的收益、置信区间或验证结论。

## 2. 因果结构约定

1. 按现有讲义连接规则递推。已知方向的母子线不再一律清空历史结构；子母三点使用用户给定的阴阳顺序。
2. 仅取已确认的几何高／低转折，排除起始种子点、末端发展点，以及不对应原 K 棒真实高／低价的几何接缝。
3. 同一根母棒内部的高低点保留绘图顺序，但不能拿来拼成三个不同交易日的日线 N。
4. 外包十字星或初始方向无法确定等仍显式中断，不伪造次级行情。
5. 每根收盘保存当时快照；转折发生日与可知日分离。后续行情可延伸图形，但不得把信号倒填到尚未确认的日期。

这是“讲义顺序约定”的可检验模型，不等同于观察到了当日真实高低先后。图上连接补线也不自动成为策略证据。

## 3. 多头许可：先交替，再买轧空

顺序必须满足：

`冻结空头结构 → 翻空为多 → 空多交替 → 多头确认 → 新正 N 攻击 → 轧空确认／恢复 → LONG`

- 在已确认空头结构中，冻结波段低点及其左侧最近负反转高点（末跌高），不能跟随未来行情改画关键位。
- 收盘从末跌高下方穿越到上方，记录“翻空为多”。
- 突破后上涨段及其后回档转折确认，回档比例严格小于 `2/3`，记录“空多交替”。不足 `1/3` 可表述为弱势回档，但不是另加一道必须满足的门槛。
- 当前结构必须呈现高点、低点抬高，确认多头。
- N 的攻击日必须晚于多头确认日，且攻击日与信号日属于同一段多头许可。不能在后来确认多头后，回头使用更早的 N 买入。
- 冻结底部被破、末升低收盘跌破、空头结构重新出现、未完成许可前冻结结构被替换、结构中断，均可撤销许可。未突破的冻结背景有 120 根窗口约束。

## 4. N 与六大盘态的具体买点

### 正 N 完成

使用三个按时间排序且位于不同 K 棒的已确认点 `A低 → B高 → C低`，要求 `A < C < B`。结构窗口为 120 根，候选观察期限为 60 根。

沿用既有图 003 的双阈值实现：攻击当根 `close > B棒收盘价`（实过）且 `high > B棒最高价`（虚过），并有新穿越事件；不是在两个阈值上方停留就重复识别。C 在确认前或等待攻击期间被更低价格延伸时，不把旧 C 的测幅硬套到新形态。

`轧空低 = min(攻击棒最低价, 前棒收盘价)`。

倒 N 对称：实破前颈线棒收盘价、虚破前颈线棒最低价；`杀多高 = max(攻击棒最高价, 前棒收盘价)`，用于风险观察，不开空仓。

### 两类入场通道

1. **轧空／强轧空确认。** 攻击棒只是当笔，下一棒观察抵抗，最早第三棒确认。轧空要求先出现抵抗、随后抵抗失败，守住轧空低并由收盘创攻击后的新高；强轧空要求没有识别到抵抗、连续收盘上涨、守住各棒虚拟低及攻击防守位，并由收盘创新高。盘坚、盘跌、追杀、强追杀一律不作为做多入场盘态。
2. **守住轧空低后的回档恢复。** 必须已经有一次确认的轧空／强轧空，之后防守位和波段边界未破。前棒收盘低于此前确认棒收盘，当前棒不落尾、收阳且收盘突破前棒最高价，才产生新的恢复证据。仅仅沿用几天前的“轧空标签”不买。

抵抗按原模块检测：多方攻击后开高收阴、直接开低、长上影等；影线占当根振幅至少 50%。无已列举形态不等于证明市场上“完全没有空方”。

每次 N 攻击最多发出一个通过全部门槛的 LONG；前期因盈亏比等未通过，不消耗该次机会。洗盘再攻击是附加标签，不是第三种放宽通道。

### 两通道共同硬门槛

- 已获得上述多头许可，且当前属于同一多头阶段。
- N 回档比例 `(B-C)/(B-A) < 2/3`。
- 攻击棒相对量 `攻击量 / 前20根平均量 >= 1.2`，历史不足或平均量无效则拒绝。
- 结构防守价低于信号收盘价，并存在尚未达到、仍高于收盘价的目标。
- 选择最近尚未达到的等浪／1P／2T 目标，不跳过较近目标来人为提高盈亏比。
- 收盘预检：`(目标-收盘)/(收盘-防守价) >= 1.5`。
- 同日有 EXIT 时，退出优先，不再生成 LONG。

正 N 测幅沿用现有“攻击棒虚拟极值箱锚”版本：`X = max(攻击棒最高价, 前棒收盘价)`，等浪 `C+B-A`，1P `2X-A`，2T `3X-2A`。它与以原颈线 B 为箱锚是不同假设，版本中明确选用 X；并非宣称任意一种是唯一正确的讲义解释。

## 5. 信号与真实模拟成交分开

收盘 LONG 不立即画 B。下一根开盘须再次通过：

- 可买、未持仓、仓位数量上限、开盘未跌到失效位、向上跳空不超过参考收盘 5%。
- 按现金、单股权重、价格风险预算、流动性四者最小值确定数量，再按原始股数每手 100 股取整。
- 按开盘滑点价格、实际可买数量及双边预计费用重算净盈亏比，仍须不低于 1.5。
- 不足一手就取消并记录原因，不买分数手、不自动加大风险、不自动放宽仓位。

当前基础场景：独立账户初始资金 100 万元，单股权重上限 20%，每笔价格风险预算为权益 0.5%，最多 5 个持仓，流动性参与上限为模型估算成交量的 1%；单边佣金 3 bps、最低 5 元、滑点 5 bps，沿用现有税费模块。0.5% 是价格风险的定量预算，不是含跳空、费用后的损失保证。个股账户只使用一只股票，不等于多股共享组合。

日线与成交使用同一因果复权等价价格，原始价等于等价价除以当日因子，数量同步换算。支持沪深主板研究假设；没有历史 ST、退市与完整逐笔成交条件，不能声称覆盖全 A 股真实可交易性。

## 6. 退出策略

- 新倒 N 完成，产生 `inverse_n_risk_exit`。
- 收盘跌破此前已知末升低，产生 `last_rise_low_close_broken`。
- 未定义结构中断，产生 `strict_structure_unresolved`（保留兼容事件名，不表示新版仍对所有包含线中断）。
- 当日最低价触及已有防守价，记录结构止损；最高价到达持仓目标，记录目标退出。两者同日出现时止损优先。
- 持仓索引差达到 40 根时记录期限退出。
- 有持仓时，后来的合格 LONG 只允许抬高防守价，不加仓、不放宽止损；新防守位从下一根生效。

退出是收盘观察后，下一根可卖开盘执行，并遵守 T+1。跌停等不可卖时递延，保留原始决策日期、理由和当时防守位。不是假定盘中恰好按止损价成交；期末不强制平仓。B/S 只标真实模拟成交，LONG/EXIT 是另外的信号标识。

## 7. 本次验证结果（2026-09-09）

范围：原有封存研究样本 10 只，加用户指出的上海机场；通达信区间 2018-01-01 至 2026-09-07，共 23,107 根股票日线。采用固定样本、固定参数，11 股 × 4 组 = 44 个独立回测，包括旧严格版、代理版、新版基础成本、新版双倍佣金／滑点场景。

| 指标（基础成本，11 股合计） | 旧严格版 | 日线代理版 | 讲义因果版 V1 |
| --------------------------- | -------: | ---------: | ------------: |
| 结构中断根数                |    4,170 |          0 |            43 |
| 已确认正 N                  |      103 |        479 |           734 |
| 多头许可确认次数            |       12 |         89 |           139 |
| 候选入场评估次数            |       17 |      1,867 |         2,829 |

新版 2,829 次候选评估中，2,828 次拒绝：趋势许可未齐备 1,739 次；不是轧空盘 987 次；N 早于多头许可 57 次；收盘盈亏比不足 19 次；阶段不一致 9 次；相对量不足 9 次；回档过深 7 次；无有效风险收益目标 1 次。次数不是股票数，也不是独立交易样本数。

唯一 LONG 为贵州茅台 2022-07-05 的轧空恢复：6 月 8 日翻多，6 月 15 日交替／多头确认，6 月 24 日正 N 攻击。相对量约 1.2399、N 回档约 30.43%、收盘盈亏比约 1.5641。7 月 6 日一手名义金额约 203,301.60 元，价格风险约 9,681.26 元，超过该账户 5,000 元风险预算，且一手名义金额也超过 20 万元单股权重上限，因此取消。首个归因是 `risk_budget_below_one_lot`，不是漏画 B。

新版基础及双倍成本场景均无成交，账户收益均为零，不能据此证明风险低或策略有效。代理版茅台一次平仓账户收益约 +0.9399%，五粮液一次约 -0.6574%，不可拿来冒充新版绩效，也不可把独立账户收益直接相加当作组合收益。

36 个真实数据前缀检查通过，包括新信号前／当／后日期；追加未来数据未改写此前信号。462 项 Python 测试、31 项前端单测、23 组 Chromium 验收通过。最终浏览器证据位于 `results/visualization_v1/2026-09-09T08-05-53-488Z/`，含新版规则截图和导出的账本。

以上是已看过历史数据上的探索性检查，不是盲测、样本外盈利证据或全市场扫描结论。下一阶段若要评估有效性，需要冻结版本，在未使用的时间段／独立股票池验证交易数量、净收益及稳健性，不应继续围绕这些样本调到正收益。

## 8. 使用与复现

刷新工作台，选择“讲义因果版 V1 · 新策略”，运行当前股票回测；展开“当前策略”查看规则，导出 JSON 获得版本、完整参数、行情指纹、信号、委托和成交证据。选择“原封存组合”会切回旧封存策略；新版不会冒用旧组合历史。

右侧“符合买点”显示所选日期／窗口的新 LONG，并提供买点条件诊断。诊断分别统计股票数和重复评估次数；零匹配不再只有一个数字。历史匹配不会自动当作当前可买或已成交。

复现命令（必须使用新的输出目录，避免覆盖）：

```powershell
.venv/Scripts/python.exe -m wavequant.interfaces.research_tools.validate_lecture_profile --tdx-root D:/TDX --output results/lecture_v1_validation_new_run
.venv/Scripts/python.exe -m unittest discover -s tests -q
```

本次最终数据报告：`results/lecture_v1_validation_final_20260909/report.json`；逐股账本在其同级策略／成本／股票路径，`artifacts.json` 保存文件校验和。旧 CLI 封存实验协议的默认值未擅自切换，复现新版使用上面的独立入口。
