# 已确认空多交替低点

图上的“空多交替低点”是空翻多成立后，第一段已确认且符合回档条件的同级低点。它不是当前窗口最低价，也不是看到高点后立即向右寻找的任意低价。

## 计算规则

1. 前置高点必须已经严格突破当时冻结的末跌高，价格相等不算突破。
2. 低点必须来自趋势标注器显式生成的 `空多交替` 观察；`回档未通过交替条件`、发展中点和浏览器推测点均不输出。
3. 回档低点必须发生在空翻多高点之后，同时高于原空头低点和本次上攻的回档起点，并低于空翻多高点。
4. 回档比例为 `(空翻多高点 - 交替低点) / (空翻多高点 - 回档起点)`，必须大于 `0` 且严格小于 `2/3`；等于 `2/3` 不成立。
5. `time` 是低点发生日；`available_at` 取低点、空翻多高点、冻结关键位、原空头低点、回档起点和观察事件可知日的最晚值。历史回放只在该日及以后显示。

每个 `bear_bull_alternation_lows` 元素包含低点自身字段，以及：

- `confirmed_flip_high`：此前完成空翻多的确认高点；
- `confirmed_bear_low`：空翻多之前已经确认的空头低点；
- `broken_key`：被确认高点严格突破的冻结末跌高；
- `retracement_origin`、`retracement_ratio`：本次回档的计算起点与比例；
- `source_path`、`source_available_at`、`available_at`：来源路径与因果可用日期。

## 展示边界

Web 只按图窗、回放截止日、趋势级别和独立开关筛选 Core 返回值，在低点价格下方绘制 `Ⅰ/Ⅱ/Ⅲ 空多交替低点`。标记不会修改趋势线、末跌高、空翻多高点、策略信号或回测结果。

中大力德一级示例为 `2022-08-30 L71 29.75`：此前 `2022-08-03 H70 49.56` 严格突破 `2022-05-24 H69 18.28`，确认原空头低点 `2022-05-27 L70 13.16`；回档比例约 `54.42%`，并在 `2022-09-01` 完成确认。因此 `2022-08-31` 的历史回放不得显示，`2022-09-01` 起可以显示。
