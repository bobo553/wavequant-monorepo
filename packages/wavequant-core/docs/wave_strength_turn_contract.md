# 多空力道、三分／六分与盘势正负扭转

实现：`wavequant/domain/market_state/wave_strength.py`、`wavequant/domain/market_state/market_turn.py`。依据用户本次提供的图 010／011 和正文。新增独立可验证定义，不改动旧 `force_profile`、`turning_evidence` 或历史策略。

## 1. 比例究竟量什么

固定同层级已确认波段起点 A、终点 B、反向终点 C。

- 下跌 A 高 → B 低后的反弹：`r=(C−B)/(A−B)`。
- 上涨 A 低 → B 高后的回档：`r=(B−C)/(B−A)`。

分子是反向运动，分母是紧邻原波段，而非整个窗口最高减最低或另一段涨跌幅。`observe_wave_strength` 消费已确认 `ReversalPoint`，核验来源价格、时间及各段极值；第三点尚未确认时返回未知，不用未来完成的低点回标今日力度。`measure_strength` 是仅做几何的低层接口，没有自行确认拐点的能力。

强反弹表示多方反击强、原空方压力被对抗；强回档表示空方反击强、原多方承受压力。**回档越深不是原多头越强。** 输出 `counter_strength` 与 `original_trend_reading` 分开，均不是未来走势保证。

## 2. 图 010 与图 011 的坐标差异

图 010 的反弹位置由低向高，价格高度比就是反弹比 r。

图 011 的标尺也是由低向高，但回档从高向下量，因此价格高度比是 **1−r**。图上约 67% 的价格位置对应约 33% 的回档，正好是弱势回档所在位置，不应读成“回档 67% 是弱势”。

返回 `ratio`、`height_from_wave_low` 和五个比例对应的实际价格 `levels`，使图上价位与回档比可直接核对。价格超出原波段时，高度可以超过 1 或小于 0，不截断来掩盖超越。

## 3. 三分力道：保留原文缺口

下表是 `EXACT_FRACTIONS` 口径。文字的“附近”没有误差带，本实现没有擅自发明 48%—52% 等范围。

| 反向比例 r    | 下跌后的反弹               | 上涨后的回档                     |
| ------------- | -------------------------- | -------------------------------- |
| 0             | 尚无反向运动               | 尚无反向运动                     |
| 0 < r < 1/3   | 原文未明确命名             | 弱势回档，原上涨相对强           |
| r = 1/3       | 严格文字边界未归类         | 严格文字边界未归类               |
| 1/3 < r < 1/2 | 弱势反弹                   | 原文未明确命名                   |
| r = 1/2       | “超过”不含等于，保留边界   | 按“达到一半”归中势，明确工程解释 |
| 1/2 < r < 2/3 | 中势反弹                   | 中势回档                         |
| r = 2/3       | 反弹正文“超过／以下”留边界 | 按“达到 2/3”归强势回档           |
| r > 2/3       | 强势反弹                   | 强势回档，原上涨相对弱           |

“中势回档在一半附近”在本版操作化为 `[1/2, 2/3)`，不是声称原稿有完整的严格区间。未覆盖区间返回 `UNSPECIFIED`，冲突边界返回 `BOUNDARY`，而非强行填进强中弱。

r=1 表示完整回吐，r>1 表示越过原起点，另由 `extent` 标记。强反向标签不等于已完成反向 N、交替或新趋势。

## 4. 六分力道与小数版本

必须显式选择 `StrengthScale`：

- `EXACT_FRACTIONS`：1/6、1/3、1/2、2/3、5/6。
- `PRINTED_PERCENTAGES`：0.167、0.333、0.5、0.667、0.833，按正文印刷小数处理。

计算使用由输入十进制报价构造的有理数，`exact_ratio` 保留比值，等于分界时 `sixth_boundary` 指出精确分界，不用浮点容差把附近价位吞进边界。六个开区间编号 1—6；分界点单列；零反向为 0；完整回吐／越过起点单列，不硬装进第六区间。

六分法只细化比例，没有提供新的买卖或“主力强弱评分”公式，本实现不编造六个胜率等级。

## 5. 正反转、翻多翻空、交替与扭转不是同义词

| 层级               | 已有或新增的含义                                                           |
| ------------------ | -------------------------------------------------------------------------- |
| 正／负反转         | 折线一段由跌转涨／由涨转跌，带源棒和确认棒                                 |
| 翻空为多／翻多为空 | 突破末跌高／跌破末升低                                                     |
| 空多／多空交替     | 关键位翻转后，后续反向幅度满足已定义条件                                   |
| 盘势正／负扭转     | 指定六态背景下，第一反向力道或关键位产生疑虑，再看第二反向力道和次级趋势线 |

它们可以出现在不同时间，不因为某一个低点正反转就自动给正扭转，也不因为比例很强就自动给轧空。

## 6. 四点结构与两次反向比例

正扭转结构：A 高 → B 低 → C 反弹高 → D 回档低。

- 第一比率 `r1=(C−B)/(A−B)`：相对末跌段的反弹。
- 第二比率 `r2=(C−D)/(C−B)`：相对该次反弹的回档。

负扭转镜像：A 低 → B 高 → C 回档低 → D 反弹高。

- 第一比率 `r1=(B−C)/(B−A)`：相对末升段的回档。
- 第二比率 `r2=(D−C)/(B−C)`：相对该次回档的反弹。

**第二次比例的分母已换成 B—C 段**，不能继续拿原始 A—B 作分母。A/B/C/D 同层级且位于严格不同源棒；波段 B 在第一反向极值 C 出现前已经确认。确认时间不倒序，几何仍需符合实际源行情极值。

## 7. 六态背景与关键位

`TurnSetup` 必须提供带来源、股票、周期和冻结时间的 `RegimeContext`：

- 正扭转：盘跌／追杀；本版将强追杀作为追杀的强子类允许。
- 负扭转：盘坚／轧空；本版将强轧空作为轧空的强子类允许。

可用 `context_from_regime` 从已有六态结果的最近确认事件建立快照；拒绝没有确认事件或已经结构失效的结果。该旧接口本身不带 symbol/timeframe，桥接时必须由调用者声明且保证身份一致。待定棒上的最近确认仍只是历史事件，不能称为当天新确认六态；冻结快照记录当前选择时间，不能拿后来盘态补造早期背景。

关键位直接使用结构层的 `KeyLevel`：正扭转给末跌高压力，负扭转给末升低支撑；必须在第一反向之前已知。波段背景和关键位不可来自未来。若背景选择时收盘已在关键位另一侧，要求提供更早上下文，不把持续占位伪装为新破位。

## 8. 疑虑 → 幅度组合 → 次级线确认

`TurnPolicy` 显式选择第一／第二阈值，以及关键位、趋势线的盘中或收盘口径。

### 正扭转

1. C 已确认，r1 严格超过第一阈值：正扭转疑虑。
2. D 已确认，`0 < r2 < 第二阈值`：反弹强、后续回档非强的幅度组合。
3. 组合已知之后，突破冻结的次级下降线：确认本版正扭转。

本版按“翻空为多之前”解释为早期扭转路径。如果末跌高先于或同棒于次级线确认被突破，返回 `MAJOR_FLIP`，转交已有关键位翻转层，不再把它包装成领先于翻多的早期扭转。若先确认扭转，后来才破末跌高，不抹掉先前确认。

### 负扭转

1. C 已确认且 r1 严格超过阈值，**或**已经跌破冻结末升低：负扭转疑虑。
2. D 已确认且 `0 < r2 < 第二阈值`：后续反弹非强的组合。
3. 组合已知之后，跌破冻结的次级上升线：确认本版负扭转。

保留原文“或跌破末升低”分支，不因第一回档比率较小就漏掉它。只有破位但没有后续确认反弹及次级线条件，仍不是最终扭转确认。

### 阈值差异与不确定边界

`TurnThreshold.TWO_THIRDS` 是精确 2/3；`PERCENT_67` 是精确 0.67，两个阶段分别指定。三分／六分显示比例的选择与扭转触发阈值是两个不同参数，不暗中绑定。

例如反弹 66.87% 超过 2/3，但未超过 67%；两个协议可能给不同疑虑结果，应分别记录。回档分类在 r=2/3 可称强势，但本版“超过阈值”疑虑触发仍严格使用 >，两种问题不能混淆。

“非强势反弹”在纯逻辑上可能包含 r2=2/3，而“非强势回档”又可能不含。为避免措辞不一致，本版两方向统一采用严格小于作为确认门槛，相等返回 `BOUNDARY`，这是更保守的工程协议，不宣称原文唯一解释。

三分法未命名的某些小比例区间仍可满足数值上的“小于阈值”；幅度组合只声明这个不等式，不把未命名区间偷偷重标为中势／弱势。

## 9. 次级浪最后两高／两低的连线

`freeze_minor_line` 消费明确属于所选次级结构的已确认拐点：

- 正扭转取最后两个高点，必须后高低于前高，形成下降线。
- 负扭转取最后两个低点，必须后低高于前低，形成上升线。
- 点不够返回未知；同源棒、横线、错误斜率或错误方向拒绝。不从更早高低点中挑一组有利斜率。
- 选线时间 `selected_at_index` 不早于两锚点的确认时间；选定后不随未来拐点偷偷换线。

对锚点 `(i1,p1)`、`(i2,p2)`，第 i 棒线价为：

`line(i)=p1+(p2−p1)×(i−i1)/(i2−i1)`。

横轴是同一输入序列的交易棒索引，不是自然日。前收比较 `line(i−1)`，今收／今极值比较 `line(i)`；不能拿今日线价充当昨日线价。穿越是相对斜线的事件，即使斜线随时间移动也可能产生穿越，不等同于价格突破固定水平压力。

正向要求前收 <= 昨线，今观察价 > 今线；负向镜像。相等只触及；此前已经收在线外不重复触发。非正价格的过远外推不产生有效股票趋势线突破。

**数据边界：** 本实现不自动下载或识别分钟级次级浪。宏观四点、次级锚点和观察 K 棒必须显式映射到同一个价格、时间索引轴。`source` 保存来源声明，不验证声明真的是次级行情；缺少次级点时传 `None` 保持 `WAIT_LINE`。不能把日线数组的第 10 根与分钟数组第 10 根混用。

## 10. 因果时序、同棒歧义与失效

本版要求幅度组合和次级线在攻击棒之前都已知，才允许确认。组合确认前或确认同棒已经越线，不回标；若此后始终在线外，也不会仅凭占位补发确认。需要新的真实越线。

D 确认后，正向若再出现低于 D 的低点，或反向出现高于 D 的高点，原冻结四点需要更新：返回 `COUNTER_EXTENDED`。同棒既延伸 D 又越线，先记录延伸，不猜高低先后。后续应按新拐点建立新 setup，不能静默把 D 移走。

若此前已确认，后来 D 被延伸，保留原 `line_break` 时间但当前阶段记失效；使用者需同时看状态和确认时间。所有输出是不可变观察对象，完整输入按 asof 查询与截断输入相同，未来点不会提前暴露。

## 11. 与其他层的边界

折线提供确认拐点，结构层提供末跌高／末升低，六态提供背景，力道层给比例，次级连线给额外确认。N 字、主控 K 防守、洗盘模板各有自己的条件，不因“扭转确认”就被自动认为也完成了。

这里只做价格观察，不创建 `Signal`、不生成订单、不改旧策略。负扭转可供只做多股票系统进行持仓风险审核，`opens_short_position=False`，不新开空仓。后续买卖仍须独立处理量能、费用、T+1、成交与风险约束。

