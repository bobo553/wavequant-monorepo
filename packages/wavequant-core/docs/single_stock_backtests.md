# 个股独立回测

## 口径

当前快照所有股票逐一建立独立现金账户，从各自首个可用日到所选回放日回测。初始资金、单次风险、20% 单股仓位上限、佣金、滑点、交易约束全部使用原实验的 `strategy` 和各场景 `execution` 配置，不为产生交易改参数。

这是全区间历史诊断，不是新的样本外测试。独立账户收益不可直接相加作为组合收益。严格版仍为默认策略，日线代理版仅作研究对照；三级趋势线没有加入入场条件。

## 数据与执行

- 只读取原封存快照并校验摘要。信号生成只接收回放日前的价格前缀；按原引擎收盘观察、后续开盘撮合，保留 T+1、整手、仓位、容量、费用及拒单规则。
- 每只股票独立运行原 `run_portfolio` 引擎，不是把组合交易过滤后冠以“个股回测”。买卖点仅由 `filled` 委托生成；LONG/EXIT 信号、取消、延迟委托分别展示。
- 未平仓按期末估值，不强制卖出。未平仓记录不带未来卖出信息；零成交胜率显示未知，收益 0% 是闲置账户记账结果，不是策略通过。
- 指标、净值、回撤、仓位、交易表、委托表和导出文件均跟随“结果口径”。默认个股独立，可切回原封存组合。原组合结果没有被覆盖。
- 全股票汇总遵循同一回放截止日；上市前无行情与零交易不同，分别标注。重复查询有有界内存缓存，不缓存未来数据充当过去结果。
