# 一侧相等的子母折线回测（2026-10-02）

## 规则

截图中的八种阴阳组合仍按每根阳线低→高、阴线高→低连接，并合并相邻同向段。讲义母子线与子母线均允许仅一侧极值相等：母子线的另一侧必须严格缩入，子母线的另一侧必须严格扩展。两侧全等不构成包含关系。子母线共享极值的零长度连接省略后，拐点保留在后出现的母线上。十字星仍不推断日内高低顺序。

这个规则只作用于讲义路径及使用它的因果拐点。`observe_bar_relations` 的严格内包／外包标志和严格研究折线的次级证据边界保持原定义。
