# 通达信全股票列表与精简图层

启动：`pnpm --filter wavequant-api dashboard`。如需覆盖路径，执行 `pnpm --filter wavequant-api python -- -m wavequant_api.cli --root ../../../packages/wavequant-core/results/operations_v1 --tdx-root D:/TDX --port 8765`。

数据源可切换：默认“通达信 · 全部 A 股行情”，原“个股独立回测 · 封存样本”和“原封存组合”保留。不能把全股票目录误认为已全市场回测。

- 名称取 `T0002/hq_cache/{sh,sz,bj}s.tnf`；日线目录取 `vipdoc/{sh,sz,bj}/lday/*.day`。覆盖沪深北 A 股，排除指数、基金、债券、B 股等其他产品。目录中无日线的股票显示但禁用，损坏记录单独标记，缺名称显示“名称待补充”，不猜名称。
- 目录只读取日线首尾记录及文件大小；选股时才读取完整历史。列表首批 100 只，可搜索全部目录并加载更多；选中的股票始终可见。缓存按文件大小和修改时间区分，通达信安装目录只读。
- `/api/tdx-catalog` 返回名称、代码、市场、历史覆盖及可读状态。`/api/tdx-view?symbol=...&asof=...` 返回原始不复权行情和交易日列表；`/api/tdx-theory` 从截至日期的行情前缀计算讲义绘图。路径和查询参数严格校验，不接受浏览器提供文件路径。
- 全目录浏览使用原始不复权日线，除权缺口会影响形态，不输出回测指标、买卖信号或成交记录。不调用原本限定成熟非 ST 主板的交易模型来伪造科创板、创业板、北交所回测。
- 所有折线、一二三级趋势线不再绘制 H/L 和子母编号；底层节点、点击取证、线条及连续衔接保持不变。黄色退出信号的 SDK 大小从 1 调整为 0.45，其他信号/成交大小不变。
- 右侧股票列表在窄屏下移至图表下方；仍可独立滚动与搜索。

原封存数据与策略不被该浏览器覆盖。目录内名称是当前缓存，不是历史证券主数据；本地目录可能含旧代码或退市历史，不能宣称覆盖当日全部上市股票。
